Exponential & logarithmic functions

2 questions, hardest first · revise the topic

2024 VCAA Exam 1 · Question 6 Open in the exam PDF (p. 7) ↗

Solve \(2\log_3(x-4) + \log_3(x) = 2\)

state average 38% of marks

Answer and marking points

Solve for x (4 marks · state average 1.5 / 4, 38%)

  • Combines: \(\log_3\left(x(x-4)^2\right) = 2\)
  • \(x^3 - 8x^2 + 16x - 9 = 0\)
  • Factorises: \((x-1)(x^2 - 7x + 9) = 0\)
  • Only \(x = \frac{7 + \sqrt{13}}{2}\) satisfies \(x > 4\)

Answer / notes: \(x = \frac{7 + \sqrt{13}}{2}\). Reject \(x = 1\) and \(\frac{7 - \sqrt{13}}{2}\) because the log needs x > 4.

2023 VCAA Exam 2 · Section B · Question 3 Open in the exam PDF (p. 16) ↗

\(g(x) = 2^x + 5\): limit, derivative, tangents through the origin; \(h(x) = 2^x - x^2\): inflection, decreasing interval, Newton’s method

state average 44% of marks

Answer and marking points

a. \(\lim_{x \to -\infty} g(x)\) (1 mark · state average 0.7 / 1, 70%)

  • \(5\)

Answer / notes: 5

b. k with \(g^{\prime}(x) = k \times 2^x\) (1 mark · state average 0.9 / 1, 90%)

  • \(k = \log_e 2\)

Answer / notes: \(k = \log_e 2\)

c.i. Tangent at \((a, g(a))\) (1 mark · state average 0.5 / 1, 50%)

  • \(y = 2^a\log_e 2\,(x - a) + 2^a + 5\)

Answer / notes: Point–gradient form.

c.ii. Tangent to g through the origin (3 d.p.) (2 marks · state average 0.6 / 2, 30%)

  • Sets \(0 = -a\,2^a\log_e 2 + 2^a + 5\), giving \(a \approx 2.618\)
  • \(y \approx 4.255x\)

Answer / notes: Substitute (0, 0) into the general tangent, solve for a, then find the gradient.

d. Point of inflection of h (2 d.p.) (1 mark · state average 0.6 / 1, 60%)

  • \(\approx (2.06, -0.07)\)

Answer / notes: \(h^{\prime\prime}(x) = (\log_e 2)^2 2^x - 2 = 0\)

e. Largest interval on which h is strictly decreasing (2 d.p.) (1 mark · state average 0.4 / 1, 40%)

  • \([0.49, 3.21]\)

Answer / notes: Between the two roots of h′, with square brackets (the endpoints are included).

f. Newton’s method from \(x_0 = 0\): \(x_1, x_2, x_3\) (3 d.p.) (2 marks · state average 1.2 / 2, 60%)

  • \(x_1 \approx -1.443\)
  • \(x_2 \approx -0.897,\ x_3 \approx -0.773\)

Answer / notes: −1.443, −0.897, −0.773

g. Why a solution of \(\log_e(2)2^x - 2x = 0\) is a bad starting point (1 mark · state average 0.2 / 1, 20%)

  • That equation is \(h^{\prime}(x) = 0\), so the tangent is horizontal and Newton’s formula divides by zero

Answer / notes: A stationary point makes the tangent horizontal, so it never meets the x-axis.

h. Positive n for which \(n^x - x^n\) has a local minimum on the x-axis (2 marks · state average 0.2 / 2, 10%)

  • Requires \(f(x) = 0\) and \(f^{\prime}(x) = 0\) at the same x, giving \(x = \frac{n}{\log_e n}\)
  • \(n = e\)

Answer / notes: \(n = e\): the curve \(e^x - x^e\) touches the axis at x = e. An exact answer was required.

2023 VCAA Exam 2 · Section B · Question 2 Open in the exam PDF (p. 12) ↗

Observation wheel modelled by h(t) = −60cos(bt) + c; then it stops and restarts at double speed

state average 45% of marks

Answer and marking points

a. Show \(b = \frac{\pi}{15}\) and \(c = 75\) (2 marks · state average 1.5 / 2, 75%)

  • Period 30: \(\frac{2\pi}{b} = 30 \Rightarrow b = \frac{\pi}{15}\)
  • \(h(0) = -60 + c = 15 \Rightarrow c = 75\)

Answer / notes: Use the period and the lowest height.

b. Average height from A (bottom) to B (level with the centre) (2 d.p.) (2 marks · state average 0.9 / 2, 45%)

  • \(\frac{1}{7.5}\int_0^{7.5} h(t)\,dt\)
  • \(= 75 - \frac{120}{\pi} \approx 36.80\) m

Answer / notes: A quarter turn takes 7.5 minutes. ≈ 36.80 m

c. Average rate of change of height from A to B (1 mark · state average 0.5 / 1, 50%)

  • \(\frac{75 - 15}{7.5} = 8\) m/min

Answer / notes: 8 m/min

d.i. k and m in the piecewise model (1 mark · state average 0.4 / 1, 40%)

  • \(k = 135,\ m = 2\)

Answer / notes: It stops at the top (135 m) and restarts at double speed.

d.ii. All possible values of n (2 marks · state average 0.4 / 2, 20%)

  • Continuity at t = 20: \(h(40 + n) = 135\), so \(\cos\left(\frac{\pi(40 + n)}{15}\right) = -1\)
  • \(n = 30j - 25,\ j \in Z\)

Answer / notes: \(n = 5 + 30j\) for integer j. A general solution was required.

d.iii. Sketch w with the coordinates of the endpoints (3 marks · state average 1.2 / 3, 40%)

  • Rising cosine from \((0, 15)\) to \((15, 135)\)
  • Flat from \((15, 135)\) to \((20, 135)\)
  • Half a (faster) cycle down to \((27.5, 15)\)

Answer / notes: Three pieces joined continuously, with endpoints (0, 15) and (27.5, 15).

2023 VCAA Exam 2 · Section B · Question 5 Open in the exam PDF (p. 21) ↗

\(g(x) = \frac12 f(2 - x)\) with \(f(x) = e^x + e^{-x}\): transformations, restricted inverses, areas with inverses, a family of curves

state average 35% of marks

Answer and marking points

a. Complete the sequence of transformations from f to g (2 marks · state average 1.2 / 2, 60%)

  • Then translation 2 units right (or just translate 2 right, since f is even)

Answer / notes: Dilation ½ from the x-axis, reflect in the y-axis, then translate right 2. Order matters.

b. Domain and range of the inverse of the increasing branch \(g_1\) (2 marks · state average 1.0 / 2, 50%)

  • Domain \([1, \infty)\)
  • Range \([2, \infty)\)

Answer / notes: The domain and range of the inverse are swapped from g₁ (turning point (2, 1)).

  • \(P \approx (1.27, 1.27),\ Q \approx (4.09, 4.09)\)

Answer / notes: Solve g(x) = x. Both points lie on y = x.

c.ii. Area bounded by g and the two inverses (2 d.p.) (2 marks · state average 0.6 / 2, 30%)

  • \(2\int_{1.27}^{4.09}\left(x - g(x)\right)dx\)
  • \(\approx 5.56\)

e. Smallest k for which h meets the inverse of \(h_1\) (2 d.p.) (1 mark · state average 0.0 / 1, 0%)

f. Area between h and the inverse of \(h_1\) when k = 5 (2 d.p.) (2 marks · state average 0.3 / 2, 15%)

  • Intersections at x ≈ 1.45 and x ≈ 8.78
  • Area \(\approx 43.91\)

Answer / notes: Integrate \(|h - h_1^{-1}|\) between the two intersection points.
