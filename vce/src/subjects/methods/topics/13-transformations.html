The three moves

TransformationMappingEffect on the rule \(y = f(x)\)
Dilation by factor \(a\) from the \(x\)-axis (parallel to the \(y\)-axis)\((x, y) \to (x, ay)\)\(y = a f(x)\)
Dilation by factor \(b\) from the \(y\)-axis (parallel to the \(x\)-axis)\((x, y) \to (bx, y)\)\(y = f\!\left(\tfrac{x}{b}\right)\)
Reflection in the \(x\)-axis\((x, y) \to (x, -y)\)\(y = -f(x)\)
Reflection in the \(y\)-axis\((x, y) \to (-x, y)\)\(y = f(-x)\)
Translation \(h\) right and \(k\) up\((x, y) \to (x + h, y + k)\)\(y = f(x - h) + k\)

A dilation from the \(x\)-axis pushes points away from the \(x\)-axis, so it stretches vertically. VCAA also writes “parallel to the \(y\)-axis” for the same thing. Mix these up and every mark in the question goes.

The general form, and the order that works

Standard form
\[ y = a\,f\big(n(x - h)\big) + k \]

Read it as: dilate by \(|a|\) from the \(x\)-axis (reflect in the \(x\)-axis if \(a < 0\)); dilate by \(\frac{1}{|n|}\) from the \(y\)-axis (reflect in the \(y\)-axis if \(n < 0\)); then translate \(h\) right and \(k\) up. The mapping is \((x, y) \to \left(\frac{x}{n} + h,\ ay + k\right)\).

Always factor out the coefficient of \(x\) first. \(f(2x + 6) = f(2(x + 3))\) is a translation of 3 left, not 6, when the dilation is done first. With dilations first and translations last you never go wrong.

Finding the image equation: the dash method

This is the method VCAA's solutions use, and it works for any transformation (even ones you can't picture):

  1. Write the mapping as \(x' = \ldots\) and \(y' = \ldots\).
  2. Rearrange to get \(x\) and \(y\) in terms of \(x'\) and \(y'\).
  3. Substitute into the original rule, then drop the dashes.

Find the image of \(y = \sqrt{x}\) under the transformation \((x, y) \to (-2x + 1,\ 3y - 2)\).

To find an image rule, write the old coordinates in terms of the new ones, then substitute into the original equation. This works for any combination of dilations, reflections and translations.

\(x' = -2x + 1 \Rightarrow x = \dfrac{1 - x'}{2}\), and \(y' = 3y - 2 \Rightarrow y = \dfrac{y' + 2}{3}\).

Substitute into \(y = \sqrt{x}\): \(\dfrac{y' + 2}{3} = \sqrt{\dfrac{1 - x'}{2}}\).

\(y = 3\sqrt{\dfrac{1 - x}{2}} - 2\), with domain \(x \le 1\).

Describe a sequence of transformations that maps \(y = e^x\) onto \(y = 3e^{2x - 4} + 1\), and give the mapping.

Write the image as \(y = af(n(x - h)) + k\): \(a\) dilates from the \(x\)-axis, \(n\) dilates from the \(y\)-axis by factor \(\frac1n\), and \(h, k\) translate. Factor the coefficient of \(x\) out of the bracket first.

Factor the exponent: \(y = 3e^{2(x - 2)} + 1\). So \(a = 3,\ n = 2,\ h = 2,\ k = 1\).

Dilation by factor 3 from the \(x\)-axis; dilation by factor \(\frac12\) from the \(y\)-axis; translation 2 units right and 1 unit up.

Mapping \((x, y) \to \left(\frac{x}{2} + 2,\ 3y + 1\right)\). Check with the dash method: \(x = 2x' - 4\), \(y = \frac{y' - 1}{3}\), giving \(\frac{y' - 1}{3} = e^{2x' - 4}\). ✓

The function \(f\) has domain \([-2, 4]\) and range \([0, 6]\), and \(f(2) = 5\). For \(g(x) = -f(2x) + 3\), find (a) the domain and range of \(g\), and (b) the image of the point \((2, 5)\).

Transform the domain by solving for where the inside of \(f\) is allowed; transform the range by applying the outside operations in order. Points map using the same rule.

Domain: need \(2x \in [-2, 4]\), so \(x \in [-1, 2]\).

Range: \(f \in [0, 6] \Rightarrow -f \in [-6, 0] \Rightarrow -f + 3 \in [-3, 3]\).

Point: the mapping is \((x, y) \to \left(\frac{x}{2},\ -y + 3\right)\), so \((2, 5) \to (1, -2)\).

Domain \([-1, 2]\), range \([-3, 3]\); image point \((1, -2)\). Check: \(g(1) = -f(2) + 3 = -5 + 3 = -2\). ✓

The graph of \(y = f(x)\) has turning points at \((0, 0)\) and \((2, -4)\). Find a dilation from the \(y\)-axis and a translation that map them to \((1, 3)\) and \((7, -1)\) respectively.

A dilation from the \(y\)-axis scales horizontal distances, so compare the horizontal gap between the points before and after; vertical gaps do the same for a dilation from the \(x\)-axis. Then translate one point into place and check the other.

Horizontal gap: 2 before, 6 after, so dilate by factor 3 from the \(y\)-axis. Vertical gap: 4 before and after, so no vertical dilation.

After the dilation \((0, 0) \to (0, 0)\) and \((2, -4) \to (6, -4)\). Translating 1 right and 3 up gives \((1, 3)\) ✓ and \((7, -1)\) ✓.

Dilation by factor 3 from the \(y\)-axis, then a translation 1 unit right and 3 units up: \((x, y) \to (3x + 1,\ y + 3)\), so the image is \(y = f\!\left(\frac{x - 1}{3}\right) + 3\).

If the image points are in the opposite left–right order, the map needs a reflection in the \(y\)-axis; opposite up–down order needs a reflection in the \(x\)-axis. E.g. \(A(1, 2)\), \(B(3, -2)\) to \(A'(4, 2)\), \(B'(0, -2)\): \(A\) was left of \(B\) and is now right of it, and the gap doubles, so reflect in the \(y\)-axis, dilate by 2 from the \(y\)-axis and translate 6 right: \((x, y) \to (6 - 2x,\ y)\), image \(y = f\!\left(\frac{6 - x}{2}\right)\).

The graph of \(y = g(x)\), where \(g(x) = 2f(3x - 6) + 1\), is the image of \(y = f(x)\). Find the transformation that maps \(g\) back to \(f\).

Write the mapping from \(f\) to \(g\) with the dash method, then make \(x\) and \(y\) the subjects: that reverses the mapping. In words, undo the steps in reverse order.

\(f \to g\): \(y' = 2y + 1\) and \(3x' - 6 = x\), so \((x, y) \to \left(\frac{x + 6}{3},\ 2y + 1\right)\).

Reverse: \(x = 3x' - 6\), \(y = \frac{y' - 1}{2}\), so \(g \to f\) is \((x, y) \to \left(3x - 6,\ \frac{y - 1}{2}\right)\).

Dilate by factor 3 from the \(y\)-axis, then translate 6 units left; translate 1 unit down, then dilate by factor \(\frac12\) from the \(x\)-axis. Check: \(f(x) = \frac{g\left(\frac{x + 6}{3}\right) - 1}{2}\).

Families of functions with a parameter

A rule with a parameter, such as \(y = x^2 - 2kx + 3\), describes a whole family of graphs. Typical questions ask where a feature (a turning point, an intercept) lies as \(k\) varies, or which values of \(k\) give a property (one-to-one, no \(x\)-intercepts, a given number of solutions).

For \(y = x^2 - 2kx + 3\), find the turning point in terms of \(k\) and the curve it lies on as \(k\) varies. For which \(k\) are there no \(x\)-intercepts?

Complete the square to read off the turning point. Its coordinates are given in terms of \(k\); eliminating \(k\) between them gives the curve all the turning points lie on.

Turning point \((k,\ 3 - k^2)\).

\(x = k\) and \(y = 3 - k^2\), so \(y = 3 - x^2\).

Turning point \((k, 3 - k^2)\), on the parabola \(y = 3 - x^2\). No \(x\)-intercepts when the turning point is above the axis: \(3 - k^2 > 0\), so \(-\sqrt3 < k < \sqrt3\) (the same as \(\Delta = 4k^2 - 12 < 0\)).

(a) For which \(k\) is \(f(x) = x^3 + kx^2 + 3x\) strictly increasing for all \(x\)? (b) Find the points that every member of \(y = kx^2 - (k + 2)x + 2\) passes through. (c) How many stationary points does \(g(x) = x^3 - 3kx\) have, as \(k\) varies?

(a) Strictly increasing everywhere means \(f'(x) \ge 0\) for all \(x\) (zero only at isolated points), so the quadratic \(f'\) has \(\Delta \le 0\). (b) Collect the \(k\) terms: a point is on every member when the coefficient of \(k\) is 0. (c) Count solutions of \(g'(x) = 0\).

(a) \(f'(x) = 3x^2 + 2kx + 3\); \(\Delta = 4k^2 - 36 \le 0 \Rightarrow -3 \le k \le 3\).

(b) \(y = k(x^2 - x) + 2 - 2x\). Independent of \(k\) when \(x^2 - x = 0\): \(x = 0, y = 2\) and \(x = 1, y = 0\).

(c) \(g'(x) = 3x^2 - 3k = 0 \Rightarrow x^2 = k\).

(a) \(-3 \le k \le 3\) (the ends are included: \(f'\) touches 0 once). (b) \((0, 2)\) and \((1, 0)\). (c) Two if \(k > 0\), one (a stationary point of inflection at the origin) if \(k = 0\), none if \(k < 0\).

For which values of \(k\) does the graph of \(f(x) = e^x + k\) intersect the graph of its inverse?

\(f\) is increasing, so \(f\) and \(f^{-1}\) can only meet on \(y = x\). The boundary case is where \(y = f(x)\) just touches \(y = x\): solve \(f(x) = x\) and \(f'(x) = 1\) together.

\(e^x = 1 \Rightarrow x = 0\); then \(e^0 + k = 0 \Rightarrow k = -1\). CAS: solve(e^(x)+k=x and e^(x)=1,{x,k}).

Lowering the curve (smaller \(k\)) makes it cross \(y = x\) twice; raising it lifts it clear of the line.

\(k \le -1\) (one meeting point at \(k = -1\), two for \(k < -1\)). The same "touch \(y = x\)" idea finds the smallest or largest parameter in Section B questions on inverses.

  • Horizontal changes act “backwards”. \(f(x - 3)\) moves right 3; \(f(2x)\) squashes by factor \(\frac12\) (dilation factor \(\frac12\) from the \(y\)-axis, not 2).
  • Order matters when dilations and translations mix. “Translate 1 right, then dilate by 2 from the \(y\)-axis” gives \(f\!\left(\frac{x}{2} - 1\right)\), not \(f\!\left(\frac{x - 1}{2}\right)\).
  • Sequences aren't unique. \(y = (2x)^2 = 4x^2\): a dilation by \(\frac12\) from the \(y\)-axis gives the same graph as a dilation by 4 from the \(x\)-axis. Similarly \(e^{x - 2} = e^{-2}e^x\).
  • Transform the asymptotes too. The image of \(y = \log_e x\) under a translation 3 left has asymptote \(x = -3\).

The graph of \(y = \log_e x\) is dilated by factor 3 from the \(y\)-axis, then translated 2 units up. The image is

  1. \(y = 3\log_e x + 2\)
  2. \(y = \log_e\!\left(\frac{x}{3}\right) + 2\)
  3. \(y = \log_e(3x) + 2\)
  4. \(y = \log_e\!\left(\frac{x + 2}{3}\right)\)

Dilation from the \(y\)-axis by factor 3 replaces \(x\) with \(\frac{x}{3}\). The translation up adds 2.

Under the mapping \((x, y) \to (x + 2, -y)\), the image of \(y = x^3\) is

  1. \(y = -(x + 2)^3\)
  2. \(y = (x - 2)^3\)
  3. \(y = -x^3 + 2\)
  4. \(y = -(x - 2)^3\)

\(x = x' - 2\) and \(y = -y'\): \(-y' = (x' - 2)^3\), so \(y = -(x - 2)^3\).

The graph of \(y = x^2\) is dilated by factor \(\frac12\) from the \(y\)-axis. The same image is produced by

  2. a dilation by factor 4 from the \(x\)-axis

  1. \(x = 2,\ y = -3\)
  2. \(x = -3,\ y = -2\)
  3. \(x = -2,\ y = -3\)
  4. \(x = -2,\ y = 3\)

Image \(y = \frac{1}{x + 2} - 3\). Asymptotes move with the graph.

The graph of \(y = f(x)\) is reflected in the \(y\)-axis and then translated 1 unit right. The image is

  1. \(y = f(-x - 1)\)
  2. \(y = -f(x - 1)\)
  3. \(y = f(-x) + 1\)
  4. \(y = f(1 - x)\)

Reflect: \(y = f(-x)\). Then translate right 1 by replacing \(x\) with \(x - 1\): \(y = f(-(x - 1)) = f(1 - x)\). Option A is what you get if you translate first and then reflect: that's the order trap.

Find the rule of a transformation that maps the graph of \(y = 3e^{2x - 4} + 1\) back onto \(y = e^x\).

A student translates \(y = f(x)\) 1 unit right and then dilates by factor 2 from the \(y\)-axis, and writes the image as \(y = f\!\left(\frac{x - 1}{2}\right)\). Find their mistake.

After the translation: \(y = f(x - 1)\). The dilation then replaces \(x\) with \(\frac{x}{2}\): \(y = f\!\left(\frac{x}{2} - 1\right) = f\!\left(\frac{x - 2}{2}\right)\).

Their answer, \(f\!\left(\frac{x - 1}{2}\right)\), is what you get if you dilate first then translate.

Summary

  • \(y = af(n(x - h)) + k\): mapping \((x, y) \to \left(\frac{x}{n} + h,\ ay + k\right)\).
  • “From the \(x\)-axis” = vertical; “from the \(y\)-axis” = horizontal.
  • Dash method: express \(x, y\) in terms of \(x', y'\) and substitute.
  • Domains, ranges, points and asymptotes all transform with the graph.
