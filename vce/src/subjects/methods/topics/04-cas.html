Typed in a Calculator page on the TI-Nspire CX II CAS. Each example has a checked output, so you can test your syntax against an answer you already know; in the printed bound reference, each row also gives the notes page for that question type. On paper, always write the equation you solved and the answer in the form asked, not just “by CAS”.

  • Type the multiplication. kx is one variable called “kx”: type k·x. And x(x+1) is read as a function: type x·(x+1).
  • Old definitions leak. A new Problem for each question is safest; ClearAZ clears only single-letter names. Define stores the expression as it was, so redefine anything built from f after changing f.
  • nSolve, fMax and fMin return one value. Restrict the domain to find each one, and for periodic models add the period to list every time in the domain.
  • Check every solution against the domain. solve can return endpoint or extra roots (e.g. t = 0 where two models both start): keep only the ones the question allows.
  • Trig without a domain gives general solutions with n1 (any integer): add |0≤x≤2·π.
  • normCdf and invNorm take σ, not the variance, and invNorm wants the area to the left.
  • Rounding. If Pr = 0.2 “correct to 1 decimal place”, the true value is in [0.15, 0.25). Don’t solve = 0.2 exactly for an integer like n or k: tabulate the candidates with seq and keep every one in the interval. Store unrounded values (→) and round only at the end.
  • CAS answers come in their own form. Convert to the exact form asked, and write the setting-out a marker needs.
