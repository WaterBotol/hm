Typed in a Calculator page on the TI-Nspire CX II CAS. The examples come from this guide’s topic pages, so each output can be checked against an answer you already know. On paper, always write the equation you solved and the answer in the form asked, not just “by CAS”.

  • Type the multiplication. kx is one variable called “kx”: type k·x. And x(x+1) is read as a function: type x·(x+1).
  • Old definitions leak. A new Problem for each question is safest; ClearAZ clears only single-letter names. Define stores the expression as it was, so redefine anything built from f after changing f.
  • nSolve and fMax return one value. Restrict the domain to find each one, and for periodic models add the period to list every time in the domain.
  • Trig without a domain gives general solutions with n1 (any integer): add |0≤x≤2·π.
  • normCdf and invNorm take σ, not the variance, and invNorm wants the area to the left.
  • Rounding. “0.2 correct to 1 decimal place” means the value is in [0.15, 0.25): test the integers either side with seq.
  • CAS answers come in their own form. Convert to the exact form asked, and write the setting-out a marker needs.
