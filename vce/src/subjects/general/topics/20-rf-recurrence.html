The recurrence relation

A recurrence relation gives the starting value of a sequence and a rule for getting each term from the one before. Every model in this unit (depreciation, interest, loans, annuities, investments) is one recurrence relation:

First-order linear recurrence relation (on the formula sheet)
\[ u_0 = a, \qquad u_{n+1} = R\,u_n + d \]

\(u_0\) is the starting value, \(u_n\) the value after \(n\) steps, \(R\) multiplies the current value and \(d\) is added (or subtracted, if negative) each step.

\(u_0\) is the value before anything happens: the purchase price, the amount borrowed, the opening balance. \(u_3\) is the value after 3 steps (3 years, 3 months, 3 payments), not the third value written down (that is \(u_2\)).

Generating terms

A sequence is defined by \(u_0 = 200\), \(u_{n+1} = 1.1u_n - 15\). Find \(u_1\), \(u_2\) and \(u_3\).

Apply the rule one step at a time, always to the previous term.

\(u_1 = 1.1(200) - 15 = 205\); \(u_2 = 1.1(205) - 15 = 210.5\).

\(u_3 = 1.1(210.5) - 15 = 216.55\).

\(u_1 = 205\), \(u_2 = 210.5\), \(u_3 =\) 216.55.

Type the starting value and press enter. Then type 1.1 × Ans − 15 and press enter repeatedly: each press gives the next term. Count presses carefully: the first press gives \(u_1\). To find when a sequence first passes a value, keep pressing and count.

Special cases with rules

CaseRecurrenceRule for the nth termGraph of terms
Linear growth or decay (\(R = 1\))\(u_{n+1} = u_n + d\)\(u_n = u_0 + nd\)points on a straight line
Geometric growth or decay (\(d = 0\))\(u_{n+1} = R\,u_n\)\(u_n = R^n u_0\)points on a curve

For growth by \(r\%\) per step, \(R = 1 + \frac{r}{100}\). For decay by \(r\%\) per step, \(R = 1 - \frac{r}{100}\).

A town's population of 8500 grows by 3% each year. Write a recurrence relation for the population after \(n\) years and use a rule to find the population after 10 years.

Growth by a percentage of the current value is geometric: \(d = 0\) and \(R = 1 + \frac{3}{100}\).

\(P_0 = 8500\), \(P_{n+1} = 1.03P_n\).

\(P_{10} = 1.03^{10} \times 8500 = 11\,423.2\ldots\)

About 11 423 people.

Reading R and d in context

Turn the words into the recurrence relation (or the recurrence relation into words) piece by piece.

WordsRecurrence relation
A fish population of 2000 increases by 6% each year, and 150 fish are removed at the end of each year.\(F_0 = 2000,\ F_{n+1} = 1.06F_n - 150\)
A savings account opens with \$500 and \$40 is deposited every week (no interest).\(S_0 = 500,\ S_{n+1} = S_n + 40\)
A machine worth \$12 000 loses 15% of its value each year.\(V_0 = 12\,000,\ V_{n+1} = 0.85V_n\)

Writing \(R = 0.06\) or \(R = 6\) is the classic error. The new value is the old value plus 6% of it: \(1 + 0.06 = 1.06\). A 15% decrease is \(1 - 0.15 = 0.85\).

Practice

If \(u_0 = 50\) and \(u_{n+1} = 2u_n - 30\), then \(u_2\) is

  1. 70
  2. 100
  3. 110
  4. 140

\(u_1 = 70\), \(u_2 = 2(70) - 30 = 110\).

A sequence starts at 1000 and decreases by 40 each step. A rule for \(u_n\) is

  1. \(u_n = 1000 - 40n\)
  2. \(u_n = 1000 \times 0.96^n\)
  3. \(u_n = 40 - 1000n\)
  4. \(u_n = 960n\)

Linear decay (\(R = 1\), \(d = -40\)): \(u_n = u_0 + nd\).

A colony of 500 bees grows by 8% each month. The recurrence relation is

  1. \(B_0 = 500,\ B_{n+1} = 0.08B_n\)
  2. \(B_0 = 500,\ B_{n+1} = B_n + 8\)
  3. \(B_0 = 500,\ B_{n+1} = 8B_n\)
  4. \(B_0 = 500,\ B_{n+1} = 1.08B_n\)

Growth by 8% of the current value: \(R = 1.08\).

For \(u_0 = 4000\), \(u_{n+1} = 0.9u_n + 300\), the sequence

  1. increases forever
  2. decreases towards 3000
  3. decreases to 0
  4. stays at 4000

The value stops changing when \(u = 0.9u + 300\), i.e. \(u = 3000\). Starting above that, the terms decrease towards 3000 (\(u_1 = 3900\), \(u_2 = 3810\), …).

Write a recurrence relation for a herd of 120 cattle that grows by 10% each year, with 20 cattle sold at the end of each year. Find the size of the herd after 2 years.

\(H_0 = 120\), \(H_{n+1} = 1.1H_n - 20\). [1]

\(H_1 = 112\), \(H_2 = 1.1(112) - 20 = 103.2\), so about 103 cattle. [1]

The value of a coin collection is modelled by \(V_0 = 2500\), \(V_{n+1} = 1.04V_n + 100\), where \(n\) is in years. Explain what 1.04 and 100 represent, and find after how many years the value first exceeds \$3500.

1.04: the value grows by 4% each year; 100: \$100 worth of coins is added each year. [1]

\(V_1 = 2700\), \(V_2 = 2908\), \(V_3 = 3124.32\), \(V_4 = 3349.29\), \(V_5 = 3583.26\): after 5 years. [1]

Summary

  • \(u_0 = a\), \(u_{n+1} = Ru_n + d\): starting value, multiplier, amount added each step.
  • \(R = 1\): \(u_n = u_0 + nd\) (straight line). \(d = 0\): \(u_n = R^n u_0\) (curve).
  • Growth: \(R = 1 + \frac{r}{100}\). Decay: \(R = 1 - \frac{r}{100}\).
  • Enter \(u_0\), then type R × Ans + d and press enter repeatedly (first press gives \(u_1\)).
