Shortest paths by inspection

For a small network, you can often see the shortest path. Check every reasonable route, and watch for routes with more edges that are still shorter.

Dijkstra's algorithm

Dijkstra's algorithm
  1. Give the start vertex the label 0. Every other vertex is unlabelled (∞).
  2. Make the smallest temporary label permanent (that vertex is done).
  3. From that vertex, update each neighbour: if (permanent label + edge weight) is smaller than its current label, replace it.
  4. Repeat steps 2 and 3 until the destination (or every vertex) is permanent.

The direct-looking edge isn't always best: S to A directly is 4, but S–B–A is 3. A label can drop several times before it becomes permanent, so never lock a vertex in until it's the smallest temporary label.

Dijkstra's algorithm works on digraphs too: only update along arrows leaving the permanent vertex. In multiple choice, inspection is usually faster; save the full table for written questions that ask for it.

Summary

  • Label the start 0; repeatedly make the smallest temporary label permanent and update its neighbours with (label + edge) if smaller; stop when the destination is permanent.
  • Backtrack from the destination using the vertex each final label came from.
  • The shortest distance from the start to every other vertex.
  • Only update along arrows leaving the vertex just made permanent.
