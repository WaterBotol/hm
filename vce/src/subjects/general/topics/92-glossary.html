Definitions written the way VCAA uses them. Click the link after each for the full explanation.

Data analysis

Categorical variable
Data that names a group: nominal (no order, e.g. eye colour) or ordinal (ordered, e.g. small/medium/large). Data types
Numerical variable
Data that is a count or measurement: discrete (counted) or continuous (measured). Data types
Five-number summary
Minimum, \(Q_1\), median, \(Q_3\), maximum: the values a boxplot is drawn from. Summary statistics
Outlier
A value below \(Q_1 - 1.5 \times \text{IQR}\) or above \(Q_3 + 1.5 \times \text{IQR}\). Summary statistics
Standardised score (z-score)
The number of standard deviations a value is above (positive) or below (negative) the mean. Normal model
Explanatory variable
The variable used to explain or predict changes in the other; it goes on the horizontal axis. Associations
Response variable
The variable whose values are being explained or predicted; it goes on the vertical axis. Associations
Pearson's correlation coefficient (r)
A number from −1 to 1 measuring the strength and direction of a linear association. Scatterplots
Coefficient of determination (r²)
The proportion of the variation in the response variable explained by the variation in the explanatory variable. Least squares
Least squares line
The line that minimises the sum of the squared residuals. Least squares
Residual
Actual value − predicted value: the vertical distance from a point to the line. Residuals
Interpolation / extrapolation
Predicting inside / outside the range of the data. Extrapolation is unreliable. Least squares
Causation
A change in one variable directly producing a change in the other. Correlation alone never shows it. Scatterplots
Seasonality
A regular pattern in a time series that repeats over a fixed calendar period. Time series
Seasonal index
How a season compares with an average season: actual ÷ deseasonalised. An index of 1.2 means 20% above average. Seasonal indices
Smoothing
Replacing each value with a moving mean or median to reduce fluctuations and show the trend. Time series

Recursion and financial modelling

Recurrence relation
A rule giving each term from the one before, plus a starting value: \(u_0 = a\), \(u_{n+1} = Ru_n + d\). Recurrence
Flat rate depreciation
The value falls by a fixed percentage of the purchase price each year (a straight line). Depreciation
Unit cost depreciation
The value falls by a fixed amount per unit of use (e.g. per kilometre). Depreciation
Reducing balance depreciation
The value falls by a fixed percentage of its current value each year. Depreciation
Effective interest rate
The annual rate that, compounded once a year, gives the same interest as the nominal rate compounded more often. Interest
Reducing balance loan
A loan where interest is charged on the balance and regular payments reduce it. Loans
Interest-only loan
Payments equal the interest each period, so the balance never falls. Loans
Annuity
A lump sum invested to pay a regular income until it runs out. Annuities
Perpetuity
An annuity that pays only the interest, so it lasts forever. Annuities
Annuity investment
An investment with regular additional deposits. Investments

Matrices

Order
The size of a matrix, rows × columns. Matrix arithmetic
Identity matrix
A square matrix with 1s on the leading diagonal and 0s elsewhere: \(AI = IA = A\). Matrix arithmetic
Determinant
A number calculated from a square matrix; for 2 × 2, \(ad - bc\). Zero means no inverse. Inverses
Singular matrix
A square matrix with determinant 0, so it has no inverse. Inverses
Permutation matrix
A square binary matrix with exactly one 1 in each row and column; it rearranges rows or columns. Binary matrices
Dominance matrix
A binary matrix where element \((i, j)\) is 1 if \(i\) beat \(j\). Binary matrices
Transition matrix
A matrix of the proportions moving between states each period: columns are “from”, rows are “to”. Transition
Regular transition matrix
One where some power has no zero elements; it reaches the same steady state from any start. Transition
Steady state
The state matrix that no longer changes noticeably from one period to the next. Transition
Leslie matrix
A matrix for an age-structured population: birth rates in the first row, survival rates below the leading diagonal. Leslie

Networks and decision mathematics

Degree
The number of edge ends at a vertex (a loop counts 2). Graphs
Bridge
An edge whose removal disconnects a graph. Graphs
Planar graph
A graph that can be drawn with no edges crossing. Graphs
Isomorphic graphs
The same graph drawn differently: same vertices, edges and connections. Graphs
Trail / path
A walk with no repeated edges / no repeated vertices. Travel
Circuit / cycle
A closed trail / closed path. Travel
Eulerian trail
A trail using every edge exactly once. Travel
Hamiltonian path
A path visiting every vertex exactly once. Travel
Spanning tree
A subgraph that is a tree and includes every vertex. Trees
Cut
A line separating the source from the sink in a flow network. Flow
Bipartite graph
Two groups of vertices with edges only between the groups. Matching
Dummy activity
A zero-time activity that shows a dependency in an activity network. Critical path
Float
How long a non-critical activity can be delayed without delaying the project: LST − EST. Critical path
Critical path
The longest path through an activity network; its activities have zero float. Critical path
