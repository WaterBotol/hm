Trees and spanning trees

A tree is a connected graph with no cycles. A spanning tree of a graph is a subgraph that is a tree and includes every vertex.

Tree facts
\[ \text{a tree with } n \text{ vertices has } n - 1 \text{ edges} \]

Add any edge to a tree and you make a cycle. Remove any edge and it falls apart: every edge of a tree is a bridge.

A minimum spanning tree (MST) is the spanning tree with the smallest total weight. It solves minimum connector problems: connecting every town, house or computer with the least total cable, pipe or road.

Prim's algorithm

Prim's algorithm
  1. Start at any vertex.
  2. Add the cheapest edge that joins a vertex already in the tree to one that isn't yet.
  3. Repeat until every vertex is in the tree (\(n - 1\) edges). If edges tie, pick either.

Use Prim's algorithm, starting at A, to find the minimum spanning tree and its total cost.

At each step, list the edges leaving the tree and take the cheapest.

From {A}: AB 4, AC 3. From {A, C}: AB 4, CB 2, CE 6. From {A, B, C}: BD 5, BE 8, CE 6.

From {A, B, C, D}: DF 3, DE 4, CE 6, BE 8. From {A, B, C, D, F}: DE 4, EF 5, CE 6, BE 8.

Edges AC, BC, BD, DF and DE (5 edges for 6 vertices). Total \(3 + 2 + 5 + 3 + 4 = \) $17 000.

The MST connects everything as cheaply as possible overall. It does not give the shortest route between two particular vertices: in the tree above, A to E is \(3 + 2 + 5 + 4 = 14\), but the road A–C–E is only 9. Shortest paths need Dijkstra's algorithm.

If two edges tie, there may be more than one MST, but they all have the same total weight. If a question says one edge must be included, put it in first, then continue Prim's from there. The total may go up.

Summary

  • A connected graph with no cycles; \(n - 1\) edges.
  • Start anywhere; repeatedly add the cheapest edge joining the tree to a new vertex; stop after \(n - 1\) edges.
  • Minimum connector problems (connect everything cheapest). It doesn't give shortest paths between two vertices.
  • Not always unique when weights tie, but the total weight is fixed, whatever the starting vertex.
