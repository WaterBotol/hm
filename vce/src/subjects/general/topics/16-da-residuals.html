Residuals

A residual is the vertical distance from a data point to the least squares line: how far the actual value is from the value the line predicts.

Residual value (on the formula sheet)
\[ \text{residual value} = \text{actual value} - \text{predicted value} \]
ResidualPoint isThe line
positiveabove the lineunderestimates the actual value
negativebelow the lineoverestimates the actual value
zeroon the linepredicts it exactly

For the least squares line, the residuals always add to zero: the points above the line balance the points below it.

The least squares line \(\text{score} = 45.0 + 3.64 \times \text{hours}\) is fitted to data on study time. A student who studied 8 hours scored 78. Find the residual and interpret it.

Predict first, then subtract the prediction from the actual value.

Predicted: \(45.0 + 3.64 \times 8 = 74.12\).

Residual = \(78 - 74.12 = 3.88\).

3.88: the student scored 3.88 marks more than the line predicts (the point is above the line).

Residual = actual − predicted, never the other way round. A common exam question gives the residual and asks for the actual value: actual = predicted + residual.

Residual plots

A residual plot graphs each residual against its explanatory value, with a horizontal line at zero. It magnifies any departure from a straight line that is hard to see on the scatterplot.

Residual plot showsConclusion
Random scatter around zero, no patternA linear model is appropriate (supports linearity)
A clear curve (U-shape or arch)The association is non-linear; try a data transformation
A fan shape (spread grows across the plot)Predictions are less reliable for larger x-values

“The residual plot shows a random scatter of points around zero, which supports the assumption that the association is linear.” Or: “The residual plot shows a clear curved pattern, which suggests the association is non-linear, so a linear model is not appropriate.” A high \(r^2\) on its own does not show the association is linear.

A line predicting house price ($000) from floor area (m²) is \(\text{price} = 120 + 2.4 \times \text{area}\). A house of 180 m² has a residual of −38. What was its actual price?

Rearrange: actual = predicted + residual.

Predicted: \(120 + 2.4 \times 180 = 552\) ($000).

Actual: \(552 + (-38) = 514\).

$514 000. The line overestimated this house's price by $38 000.

Practice

The predicted value of a data point is 64 and its actual value is 59. Its residual is

  1. 5
  2. −5
  3. 123
  4. 0.92

\(59 - 64 = -5\).

A residual plot shows a clear arch shape. This indicates that

  1. the association is strong and linear
  2. r is close to 0
  3. a linear model is not appropriate
  4. there are outliers

A pattern in the residuals means the association is non-linear.

A least squares line has \(r^2 = 0.94\), but the residual plot is clearly U-shaped. The best conclusion is

  1. the association is non-linear, despite the high r²
  2. the linear model is excellent because r² is high
  3. the residuals were calculated incorrectly
  4. 94% of the points lie on the line

The residual plot is the check for linearity. A high r² can occur with curved data.

The residuals of four of the five points in a least squares fit are 2.1, −0.8, −3.0 and 0.6. The fifth residual is

  1. 0
  2. −1.1
  3. 2.3
  4. 1.1

The residuals add to zero: \(2.1 - 0.8 - 3.0 + 0.6 = -1.1\), so the fifth is 1.1.

The line \(\text{time} = 4.2 + 1.8 \times \text{distance}\) predicts delivery time (min) from distance (km). A 10 km delivery took 25 minutes. Find the residual.

Predicted: \(4.2 + 1.8 \times 10 = 22.2\) min. [1]

Residual: \(25 - 22.2 = 2.8\) min. [1]

The residual plot for a linear model shows points randomly scattered above and below zero with no pattern. What does this suggest?

It supports the assumption that the association is linear, so the linear model is appropriate. [1]

Summary

  • Residual = actual − predicted. Positive: point above the line (underestimate); negative: below the line (overestimate).
  • Zero.
  • Random scatter supports a linear model; a clear curve means the association is non-linear (try a transformation).
  • Actual = predicted + residual.
