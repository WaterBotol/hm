Factorising over C

Over \(\mathbb{C}\), every quadratic factorises, because sums of squares become differences of squares: \(z^2 + a^2 = z^2 - (ai)^2 = (z - ai)(z + ai)\).

Factorise \(z^2 - 4z + 13\) over \(\mathbb{C}\).

Complete the square to get (something)\(^2\) + (positive number), then write the positive number as \(-(\text{imaginary})^2\) and use the difference of squares.

\(z^2 - 4z + 13 = (z - 2)^2 + 9 = (z - 2)^2 - (3i)^2\).

\(= (z - 2 - 3i)(z - 2 + 3i)\). Roots \(z = 2 \pm 3i\).

The conjugate root theorem

Real coefficients ⇒ conjugate pairs
\[ P(z) \text{ has real coefficients and } P(\alpha) = 0 \ \Rightarrow\ P(\bar\alpha) = 0 \]

So non-real roots of real polynomials come in conjugate pairs, and each pair gives a real quadratic factor: \((z - \alpha)(z - \bar\alpha) = z^2 - 2\operatorname{Re}(\alpha)z + |\alpha|^2\).

The theorem needs real coefficients. For \(z^2 - iz + 2 = 0\) the roots are \(2i\) and \(-i\), not a conjugate pair.

Given that \(1 + 2i\) is a root of \(P(z) = z^3 - 5z^2 + 11z - 15\), find all roots.

The coefficients are real, so \(1 - 2i\) is also a root, giving a real quadratic factor. Divide (or compare coefficients) to find the last linear factor.

Quadratic factor: \(z^2 - 2z + 5\).

\(z^3 - 5z^2 + 11z - 15 = (z^2 - 2z + 5)(z - 3)\). (Check: constant \(5 \times -3 = -15\) ✓, \(z^2\): \(-3 - 2 = -5\) ✓.)

Roots: \(z = 1 + 2i,\ 1 - 2i,\ 3\).

The fundamental theorem of algebra

FTA
\[ \text{A polynomial of degree } n \ge 1 \text{ with complex coefficients has exactly } n \text{ roots in } \mathbb{C} \text{ (counted with multiplicity)} \]

So it factorises completely into \(n\) linear factors over \(\mathbb{C}\). A real polynomial of odd degree must have at least one real root.

Solve \(z^4 + 5z^2 + 4 = 0\) over \(\mathbb{C}\).

It's a quadratic in \(z^2\). Factorise, then factorise each sum of squares.

\((z^2 + 1)(z^2 + 4) = 0\).

\(z = \pm i\) or \(z = \pm 2i\). Factorised: \((z - i)(z + i)(z - 2i)(z + 2i)\).

Show that \(z = i\) is a root of \(P(z) = z^3 + (1 - i)z^2 + (1 - i)z - i\) and hence solve \(P(z) = 0\).

This polynomial has complex coefficients, so the conjugate root theorem doesn't apply. Substitute to check the root, divide by \(z - i\), then solve the remaining quadratic.

\(P(i) = -i + (1 - i)(-1) + (1 - i)i - i = -i - 1 + i + i + 1 - i = 0\) ✓.

Divide: \(P(z) = (z - i)(z^2 + z + 1)\). (Expand to check: \(z^3 + z^2 + z - iz^2 - iz - i\) ✓.)

\(z^2 + z + 1 = 0 \Rightarrow z = \dfrac{-1 \pm \sqrt3 i}{2}\). Roots: \(i,\ -\frac12 \pm \frac{\sqrt3}{2}i\).

Quadratics with complex coefficients

The quadratic formula still works; you may need the square root of a complex number (see complex numbers, or use polar form).

Solve \(z^2 - (3 + i)z + (2 + 2i) = 0\).

Find the discriminant, take its square root by solving \((x + yi)^2 = \Delta\), and finish with the formula.

\(\Delta = (3 + i)^2 - 4(2 + 2i) = 8 + 6i - 8 - 8i = -2i\).

\(\sqrt{-2i}\): \((x + yi)^2 = -2i \Rightarrow x^2 = y^2,\ 2xy = -2\): \(\pm(1 - i)\).

\(z = \dfrac{3 + i \pm (1 - i)}{2}\): \(z = 2\) or \(z = 1 + i\).

Typical marks: 1 for using the conjugate root (stating the coefficients are real), 1 for the quadratic factor, 1 for the remaining factor/roots. "Factorise over C" means linear factors; "factorise over R" means real quadratics may remain.

Practice

Over \(\mathbb{C}\), \(z^2 + 6z + 10\) factorises as

  1. \((z + 3 - i)(z + 3 + i)\)
  2. \((z - 3 - i)(z - 3 + i)\)
  3. \((z + 3)^2 + 1\)
  4. \((z + 1)(z + 10)\)

\((z + 3)^2 + 1 = (z + 3)^2 - i^2\). C isn't factorised.

A cubic with real coefficients has roots \(2\) and \(3 - i\). Its third root is

  1. \(-2\)
  2. \(-3 + i\)
  3. \(3 + i\)
  4. \(3i\)

Conjugate root theorem.

The polynomial \(z^2 - 2iz - 2\) has roots

  1. \(1 + i\) and \(1 - i\)
  2. \(\pm\sqrt2\)
  3. \(i \pm 1\) and their conjugates
  4. \(1 + i\) and \(-1 + i\)

\((z - i)^2 - 1 = 0 \Rightarrow z = i \pm 1\). Not a conjugate pair: the coefficients aren't real.

A real polynomial of degree 5 must have

  1. 5 real roots
  2. at least one real root
  3. exactly one real root
  4. no real roots

Non-real roots pair up, so an odd number of roots must include a real one.

If \(z = 2 - i\) is a root of \(z^2 + bz + c = 0\) with \(b, c \in \mathbb{R}\), then \((b, c)\) is

  1. \((-4, 5)\)
  2. \((4, 5)\)
  3. \((-4, 3)\)
  4. \((-2, 5)\)

Let \(P(z) = z^4 - 2z^3 + 6z^2 - 2z + 5\). Verify that \(P(i) = 0\), and hence factorise \(P(z)\) over \(\mathbb{C}\).

\(P(i) = 1 + 2i - 6 - 2i + 5 = 0\). [1]

\(P(z) = (z^2 + 1)(z^2 - 2z + 5)\). [1]

\(= (z - i)(z + i)(z - 1 - 2i)(z - 1 + 2i)\). [1]

Summary

  • Complete the square; \(A^2 + B^2 = (A - Bi)(A + Bi)\).
  • Real coefficients: roots in conjugate pairs; pair → \(z^2 - 2\operatorname{Re}(\alpha)z + |\alpha|^2\).
  • Degree \(n\) ⇒ exactly \(n\) roots over \(\mathbb{C}\); odd-degree real polynomials have a real root.
  • Complex coefficients: use the factor theorem and the quadratic formula; no conjugate shortcut.
