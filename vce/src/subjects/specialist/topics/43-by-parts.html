The formula

Integration by parts
\[ \int u\,\frac{dv}{dx}\,dx = uv - \int v\,\frac{du}{dx}\,dx \qquad \int_a^b u\,v'\,dx = \big[uv\big]_a^b - \int_a^b u'\,v\,dx \]

It's the product rule \((uv)' = u'v + uv'\) integrated and rearranged.

Choose \(u\) to be the part that gets simpler when differentiated, and \(\frac{dv}{dx}\) the part you can integrate. A common order for \(u\) is LIATE: Logs, Inverse circular, Algebraic (polynomials), Trig, Exponentials.

Polynomial × exponential or trig

Find \(\displaystyle\int x e^{2x}\,dx\).

Let \(u = x\) (it differentiates to 1) and \(v' = e^{2x}\) (easy to integrate).

\(u = x,\ u' = 1;\ v' = e^{2x},\ v = \frac12 e^{2x}\).

\(\frac12 xe^{2x} - \int\frac12 e^{2x}dx = \frac12 xe^{2x} - \frac14 e^{2x} + c\).

Evaluate \(\displaystyle\int_0^{\pi/2} x\cos x\,dx\).

\(u = x\), \(v' = \cos x\). Evaluate the \(uv\) term at the terminals, then the remaining integral.

\(v = \sin x\): \(\big[x\sin x\big]_0^{\pi/2} - \int_0^{\pi/2}\sin x\,dx\).

\(= \frac\pi2 - \big[-\cos x\big]_0^{\pi/2} = \frac\pi2 - (0 + 1)\).

\(= \frac{\pi}{2} - 1\).

Log and inverse circular functions on their own

Write the integrand as (function) × 1 and take \(v' = 1\).

Find \(\displaystyle\int \log_e x\,dx\).

You can't integrate \(\log_e x\) directly, but you can differentiate it. So \(u = \log_e x\), \(v' = 1\).

\(u' = \frac1x,\ v = x\): \(x\log_e x - \int x\cdot\frac1x\,dx\).

\(= x\log_e x - x + c\).

Find \(\displaystyle\int \tan^{-1}x\,dx\).

\(u = \tan^{-1}x\), \(v' = 1\). The leftover integral is a substitution giving a log.

\(x\tan^{-1}x - \int\frac{x}{1 + x^2}dx\).

\(= x\tan^{-1}x - \frac12\log_e(1 + x^2) + c\).

Repeated and cyclic integration by parts

Find \(\displaystyle\int x^2e^x\,dx\).

Each application reduces the power of \(x\) by one, so do it twice.

\(x^2e^x - \int 2xe^x\,dx\).

\(\int 2xe^x\,dx = 2xe^x - 2e^x\).

\(x^2e^x - 2xe^x + 2e^x + c = e^x(x^2 - 2x + 2) + c\).

Find \(I = \displaystyle\int e^x\sin x\,dx\).

Parts twice brings back the original integral. Call it \(I\) and solve the equation for \(I\). Keep the same choice (exponential as \(v'\)) both times.

\(u = \sin x,\ v' = e^x\): \(I = e^x\sin x - \int e^x\cos x\,dx\).

\(\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + I\).

\(I = e^x\sin x - e^x\cos x - I\).

\(I = \frac12 e^x(\sin x - \cos x) + c\).

Sign errors in the \(-\int v\,u'\) term are the classic slip, especially with trig (\(\int\sin x = -\cos x\)). In the cyclic method, switching which function is \(u\) on the second round undoes the first step and gives \(I = I\).

VCAA often scaffolds: "Show that \(\frac{d}{dx}(x\log_e x) = \log_e x + 1\) and hence find \(\int\log_e x\,dx\)". That's integration by parts in disguise: integrate both sides and rearrange.

Practice

For \(\displaystyle\int x\sin(3x)\,dx\) by parts, the best choice is

  1. \(u = \sin 3x,\ v' = x\)
  2. \(u = x\sin 3x,\ v' = 1\)
  3. \(u = x,\ v' = \sin 3x\)
  4. \(u = 3x,\ v' = \sin x\)

Differentiating \(x\) simplifies it; \(\sin 3x\) integrates easily.

\(\displaystyle\int x e^{-x}\,dx\) is

  1. \(-xe^{-x} - e^{-x} + c\)
  2. \(xe^{-x} - e^{-x} + c\)
  3. \(-xe^{-x} + e^{-x} + c\)
  4. \(\frac12 x^2e^{-x} + c\)

\(u = x,\ v = -e^{-x}\): \(-xe^{-x} + \int e^{-x}dx = -xe^{-x} - e^{-x}\).

\(\displaystyle\int_1^e \log_e x\,dx\) equals

  1. \(e\)
  2. \(e - 1\)
  3. \(0\)
  4. \(1\)

\([x\log_e x - x]_1^e = (e - e) - (0 - 1) = 1\).

Given \(\frac{d}{dx}(x\sin x) = \sin x + x\cos x\), \(\displaystyle\int x\cos x\,dx\) equals

  1. \(x\sin x - \sin x + c\)
  2. \(x\sin x + \cos x + c\)
  3. \(x\sin x - \cos x + c\)
  4. \(\sin x + x\cos x + c\)

Integrate both sides: \(x\sin x = -\cos x + \int x\cos x\,dx\).

Find \(\displaystyle\int x\log_e x\,dx\).

\(u = \log_e x,\ v' = x\): \(\frac{x^2}{2}\log_e x - \int\frac{x^2}{2}\cdot\frac1x dx\). [1]

\(= \frac{x^2}{2}\log_e x - \frac{x^2}{4} + c\). [1]

Evaluate \(\displaystyle\int_0^1 \sin^{-1}x\,dx\).

\(\big[x\sin^{-1}x\big]_0^1 - \int_0^1\frac{x}{\sqrt{1 - x^2}}dx\). [1]

\(= \frac\pi2 - \big[-\sqrt{1 - x^2}\big]_0^1 = \frac\pi2 - (0 + 1)\). [1]

\(= \frac\pi2 - 1\). [1]

Find \(\displaystyle\int e^{2x}\cos x\,dx\).

\(I = \frac12 e^{2x}\cos x + \frac12\int e^{2x}\sin x\,dx\) (\(u = \cos x\)). [1]

\(\int e^{2x}\sin x\,dx = \frac12 e^{2x}\sin x - \frac12 I\). [1]

\(I = \frac12 e^{2x}\cos x + \frac14 e^{2x}\sin x - \frac14 I\). [1]

\(I = \frac{e^{2x}}{5}(2\cos x + \sin x) + c\). [1]

Summary

  • \(\int uv' = uv - \int u'v\); \(u\) simplifies on differentiating (LIATE).
  • \(\log_e x\), \(\tan^{-1}x\), \(\sin^{-1}x\) alone: use \(v' = 1\).
  • Polynomial degree \(n\): parts \(n\) times. \(e^{ax}\times\) trig: cyclic, solve for \(I\).
