De Moivre’s theorem

De Moivre
\[ (r\operatorname{cis}\theta)^n = r^n\operatorname{cis}(n\theta), \quad n \in \mathbb{Z} \]

It follows from "moduli multiply, arguments add" applied \(n\) times.

Prove that \((\operatorname{cis}\theta)^n = \operatorname{cis}(n\theta)\) for all \(n \in \mathbb{N}\).

The inductive step multiplies \(\operatorname{cis}(k\theta)\) by \(\operatorname{cis}\theta\) and uses the compound angle formulas to combine them.

Base \(n = 1\): \((\operatorname{cis}\theta)^1 = \operatorname{cis}\theta\). True.

Assume \((\operatorname{cis}\theta)^k = \operatorname{cis}(k\theta)\).

\((\operatorname{cis}\theta)^{k+1} = \operatorname{cis}(k\theta)\operatorname{cis}\theta = (\cos k\theta\cos\theta - \sin k\theta\sin\theta) + i(\sin k\theta\cos\theta + \cos k\theta\sin\theta)\).

\(= \cos((k + 1)\theta) + i\sin((k + 1)\theta) = \operatorname{cis}((k + 1)\theta)\). By induction, true for all \(n \in \mathbb{N}\). \(\blacksquare\) (For negative \(n\), use \(\frac{1}{\operatorname{cis}\theta} = \operatorname{cis}(-\theta)\).)

Powers

Find \((1 - i)^{10}\) in Cartesian form.

Convert to polar, apply De Moivre, then reduce the argument to the principal range before converting back.

\(1 - i = \sqrt2\operatorname{cis}\left(-\frac\pi4\right)\).

\((1 - i)^{10} = (\sqrt2)^{10}\operatorname{cis}\left(-\frac{10\pi}{4}\right) = 32\operatorname{cis}\left(-\frac{5\pi}{2}\right) = 32\operatorname{cis}\left(-\frac\pi2\right)\).

\(= 32(0 - i) = -32i\).

Find the smallest positive integer \(n\) such that \((\sqrt3 + i)^n\) is real and negative.

\((\sqrt3 + i)^n = 2^n\operatorname{cis}\frac{n\pi}{6}\). It's real and negative when the argument is an odd multiple of \(\pi\).

Need \(\frac{n\pi}{6} = \pi, 3\pi, \dots\), i.e. \(n = 6, 18, \dots\)

Smallest: \(n = 6\), giving \(2^6\operatorname{cis}\pi = -64\).

Roots

Solving \(z^n = r\operatorname{cis}\theta\)
\[ z = r^{1/n}\operatorname{cis}\left(\frac{\theta + 2k\pi}{n}\right), \quad k = 0, 1, \dots, n - 1 \]

There are exactly \(n\) distinct roots. They lie on a circle of radius \(r^{1/n}\), equally spaced \(\frac{2\pi}{n}\) apart: the vertices of a regular \(n\)-gon.

Solve \(z^3 = -8i\), giving answers in polar form, then in Cartesian form.

Write \(-8i\) in polar form, add multiples of \(2\pi\) to the argument, divide by 3, and choose \(k\) values that land in \((-\pi, \pi]\).

\(-8i = 8\operatorname{cis}\left(-\frac\pi2 + 2k\pi\right)\). So \(z = 2\operatorname{cis}\left(-\frac\pi6 + \frac{2k\pi}{3}\right)\).

\(k = -1, 0, 1\): arguments \(-\frac{5\pi}{6}, -\frac\pi6, \frac\pi2\).

\(z = 2\operatorname{cis}\left(-\frac{5\pi}{6}\right) = -\sqrt3 - i\), \(z = 2\operatorname{cis}\left(-\frac\pi6\right) = \sqrt3 - i\), \(z = 2\operatorname{cis}\frac\pi2 = 2i\). They form an equilateral triangle on the circle \(|z| = 2\).

Roots of unity

The \(n\)th roots of unity solve \(z^n = 1\): \(z = \operatorname{cis}\frac{2k\pi}{n}\). If \(\omega = \operatorname{cis}\frac{2\pi}{n}\), the roots are \(1, \omega, \omega^2, \dots, \omega^{n-1}\).

Sum of the roots
\[ 1 + \omega + \omega^2 + \dots + \omega^{n-1} = 0 \quad (n \ge 2) \]

Because \(z^n - 1 = (z - 1)(z^{n-1} + \dots + z + 1)\), and \(\omega \ne 1\) is a root. Geometrically, the polygon's vertices balance at the origin.

Once you have one root of \(z^n = w\), get the rest by rotating by \(\frac{2\pi}{n}\) repeatedly (multiplying by \(\omega\)). Roots of a real number come in conjugate pairs.

Divide all of \(\theta + 2k\pi\) by \(n\): the roots of \(z^4 = 16\operatorname{cis}\frac\pi3\) have arguments \(\frac{\pi}{12} + \frac{k\pi}{2}\), not \(\frac{\pi}{3} + \frac{k\pi}{2}\). And take the real \(n\)th root of the modulus: \(16^{1/4} = 2\).

Common VCAA tasks: plot the roots on an Argand diagram (draw the circle, mark equal spacing); find the area or perimeter of the polygon they form; or use one given root to find the others.

  1. \(8i\)
  2. \(16\)
  3. \(16i\)
  4. \(8\operatorname{cis}\frac{\pi}{2}\)

\(2^4\operatorname{cis}\frac{4\pi}{8} = 16\operatorname{cis}\frac\pi2 = 16i\).

The solutions of \(z^6 = 64\) lie on a circle of radius

  1. 64
  2. 2
  3. 8
  4. \(\sqrt{64}\)

\(64^{1/6} = 2\).

One root of \(z^4 = w\) is \(1 + i\). Another root is

  1. \(-1 + i\)
  2. \(1 - 2i\)
  3. \(2i\)
  4. \(\sqrt2\)

Rotate by \(\frac{2\pi}{4} = \frac\pi2\): multiply by \(i\): \(i(1 + i) = -1 + i\).

If \(\omega\) is a complex cube root of unity (\(\omega \ne 1\)), then \(1 + \omega + \omega^2\) equals

  1. 1
  2. 3
  3. \(\omega^3\)
  4. 0

Sum of the roots of \(z^3 - 1 = 0\) is 0 (and \(\omega^3 = 1\), so C is 1).

The roots of \(z^5 = 32\) are joined to form a regular pentagon. The length of each side is

  1. \(2\sin\frac{\pi}{5}\)
  2. \(2\)
  3. \(4\sin\frac{\pi}{5}\)
  4. \(4\cos\frac{\pi}{5}\)

Radius 2, central angle \(\frac{2\pi}{5}\): chord \(= 2r\sin\frac{\pi}{5} = 4\sin\frac\pi5\).

Use De Moivre’s theorem to show that \(\cos 3\theta = 4\cos^3\theta - 3\cos\theta\).

\(\cos 3\theta + i\sin 3\theta = (\cos\theta + i\sin\theta)^3\). [1]

Real part of the expansion: \(\cos^3\theta - 3\cos\theta\sin^2\theta\). [1]

\(= \cos^3\theta - 3\cos\theta(1 - \cos^2\theta) = 4\cos^3\theta - 3\cos\theta\). [1]

Summary

  • \((r\operatorname{cis}\theta)^n = r^n\operatorname{cis}n\theta\); reduce arguments to \((-\pi, \pi]\).
  • \(z^n = r\operatorname{cis}\theta\): \(z = r^{1/n}\operatorname{cis}\frac{\theta + 2k\pi}{n}\), \(n\) roots evenly spaced on a circle.
  • Roots of unity sum to 0; rotate one root by \(\frac{2\pi}{n}\) to get the next.
