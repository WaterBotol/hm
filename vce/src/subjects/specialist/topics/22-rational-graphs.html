A checklist for sketching

  1. Domain and vertical asymptotes: where the denominator is zero (and the numerator isn't).
  2. Intercepts: \(y\) at \(x = 0\); \(x\) where the numerator is zero.
  3. End behaviour: horizontal or oblique asymptote, from the degrees or from division.
  4. Stationary points (\(f'(x) = 0\)) and their nature; inflection points (\(f''\) changes sign).
  5. Behaviour either side of each vertical asymptote (sign of \(f\) just left and right).
End behaviour of \(\frac{P(x)}{Q(x)}\)
\[ \deg P < \deg Q:\ y = 0 \qquad \deg P = \deg Q:\ y = \tfrac{\text{leading coeff of } P}{\text{leading coeff of } Q} \qquad \deg P = \deg Q + 1:\ \text{oblique asymptote from division} \]

Sums of ordinates: \(y = x + \frac{1}{x}\) and friends

Sketch \(y = x + \dfrac{4}{x}\), showing asymptotes and stationary points with their nature.

For large \(|x|\) the \(\frac4x\) part vanishes, so the graph approaches the line \(y = x\). Near \(x = 0\) the \(\frac4x\) part dominates. Differentiate for the turning points.

Asymptotes: \(x = 0\) (vertical), \(y = x\) (oblique). No intercepts (\(x^2 + 4 = 0\) has no real roots).

\(y' = 1 - \frac{4}{x^2} = 0 \Rightarrow x = \pm 2\). Points \((2, 4)\) and \((-2, -4)\).

\(y'' = \frac{8}{x^3}\): positive at \(x = 2\) (local minimum), negative at \(x = -2\) (local maximum).

Two branches: for \(x > 0\), a U-shape with minimum \((2, 4)\) rising toward \(y = x\) and up the \(y\)-axis; for \(x < 0\), the rotated copy (the function is odd) with maximum \((-2, -4)\). No inflection points.

Rational functions with a quadratic denominator

Sketch \(y = \dfrac{1}{x^2 - 1}\).

It's the reciprocal of the parabola \(y = x^2 - 1\): where the parabola is zero there are asymptotes; where it has a minimum of \(-1\) the reciprocal has a maximum of \(-1\); as the parabola grows, the reciprocal shrinks to 0.

Vertical asymptotes \(x = \pm1\); horizontal asymptote \(y = 0\); \(y\)-intercept \((0, -1)\); even function.

\(y' = 0\) only at \(x = 0\): local maximum \((0, -1)\).

Between \(-1\) and \(1\): an upside-down U below the axis peaking at \((0, -1)\), dropping to \(-\infty\) at the asymptotes. Outside: positive branches falling from \(+\infty\) toward \(y = 0\).

Reciprocal sketching rules for \(y = \frac{1}{f(x)}\): zeros of \(f\) become vertical asymptotes; \(f > 0 \Rightarrow \frac1f > 0\); local max of \(f\) becomes local min of \(\frac1f\) (and vice versa) at the same \(x\); where \(f = \pm1\) the graphs meet; where \(|f| \to \infty\), \(\frac1f \to 0\).

Oblique asymptotes and inflection points

For \(f(x) = \dfrac{x^2 + 3}{x - 1}\), find the asymptotes and the stationary points.

Divide to reveal the oblique asymptote, which also makes differentiation easier.

\(x^2 + 3 = (x + 1)(x - 1) + 4\), so \(f(x) = x + 1 + \dfrac{4}{x - 1}\). Asymptotes \(x = 1\) and \(y = x + 1\).

\(f'(x) = 0 \Rightarrow (x - 1)^2 = 4 \Rightarrow x = 3\) or \(x = -1\).

\((3, 6)\) is a local minimum and \((-1, -2)\) a local maximum (since \(f''(x) = \frac{8}{(x - 1)^3}\) is positive at 3, negative at \(-1\)). No \(x\)-intercepts.

Find the exact coordinates of the points of inflection of \(y = \dfrac{1}{x^2 + 3}\).

Inflection points are where the second derivative changes sign. Use the quotient or chain rule twice, then solve \(y'' = 0\) and check the sign change.

\(y' = \dfrac{-2x}{(x^2 + 3)^2}\).

\(y'' = \dfrac{-2(x^2 + 3)^2 + 2x\cdot 2(x^2 + 3)\cdot 2x}{(x^2 + 3)^4} = \dfrac{6x^2 - 6}{(x^2 + 3)^3}\).

\(y'' = 0\) at \(x = \pm1\), and it changes sign there. Points of inflection \(\left(\pm1, \frac14\right)\).

\(f''(x) = 0\) doesn't guarantee an inflection point: check that \(f''\) changes sign. For \(y = x^4\), \(f''(0) = 0\) but it's a minimum. And a function can change concavity across an asymptote without having an inflection point there (the point isn't on the graph).

"Sketch" means: correct shape, all asymptotes labelled with equations, intercepts and stationary points labelled with coordinates (exact unless told otherwise), and correct behaviour near the asymptotes. Exam 2 questions often add a parameter, e.g. "for what values of \(k\) does \(y = x + \frac{k}{x}\) have stationary points?" (only \(k > 0\)).

Practice

The asymptotes of \(y = \dfrac{2x + 1}{x - 3}\) are

  1. \(x = 3,\ y = 0\)
  2. \(x = -\frac12,\ y = 2\)
  3. \(x = 3,\ y = 2\)
  4. \(x = 3,\ y = 2x + 1\)

Denominator zero at 3; equal degrees give \(y = \frac21\).

The oblique asymptote of \(y = \dfrac{x^2 - 2x + 5}{x}\) is

  1. \(y = x - 2\)
  2. \(y = x\)
  3. \(y = x + 5\)
  4. \(y = -2\)

\(y = x - 2 + \frac5x\).

How many vertical asymptotes does \(y = \dfrac{x - 2}{x^2 - 4}\) have?

  1. 2
  2. 0
  3. 3
  4. 1

\(\frac{x - 2}{(x - 2)(x + 2)} = \frac{1}{x + 2}\) for \(x \ne 2\): an asymptote at \(x = -2\) and a hole (point discontinuity) at \(x = 2\).

The graph of \(y = x + \dfrac{k}{x}\), where \(k\) is a real constant, has two stationary points when

  1. \(k < 0\)
  2. \(k > 0\)
  3. \(k \ne 0\)
  4. \(k = 1\) only

\(y' = 1 - \frac{k}{x^2} = 0 \Rightarrow x^2 = k\): two solutions only if \(k > 0\).

The graph of \(y = \dfrac{1}{(x - 1)^2 + 4}\) has a local maximum at

  1. \((1, 4)\)
  2. \((-1, \frac14)\)
  3. \((1, \frac14)\)
  4. \((0, \frac15)\)

The reciprocal of a parabola with minimum \((1, 4)\) has a maximum \((1, \frac14)\).

For \(y = 2x + \dfrac{8}{x}\), state the asymptotes and find the stationary points.

Asymptotes \(x = 0\) and \(y = 2x\). [1]

\(y' = 2 - \frac{8}{x^2} = 0 \Rightarrow x = \pm2\). [1]

Local min \((2, 8)\), local max \((-2, -8)\). [1]

Let \(f(x) = \dfrac{x^2}{x^2 - 4}\). Find the asymptotes, intercepts and stationary points, and describe the graph.

\(f(x) = 1 + \frac{4}{x^2 - 4}\): asymptotes \(x = \pm2\), \(y = 1\). [1]

Only intercept \((0, 0)\). [1]

\(f'(x) = \frac{-8x}{(x^2 - 4)^2} = 0\) at \(x = 0\); \(f'\) is positive just left of 0 and negative just right, so \((0, 0)\) is a local maximum. [1]

Even function: a cap below the axis on \((-2, 2)\) peaking at the origin; outside, branches above \(y = 1\) coming down from \(+\infty\). [1]

Find the values of \(a\) for which \(y = \dfrac{x}{x^2 + a}\) has no vertical asymptotes, and for \(a = 1\) find the stationary points.

No vertical asymptotes when \(x^2 + a = 0\) has no real solutions: \(a > 0\). [1]

\(a = 1\): \(y' = \frac{(x^2 + 1) - 2x^2}{(x^2 + 1)^2} = \frac{1 - x^2}{(x^2 + 1)^2} = 0 \Rightarrow x = \pm1\). [1]

Local max \((1, \frac12)\), local min \((-1, -\frac12)\). [1]

Summary

  • Vertical asymptotes from the denominator; divide to find horizontal or oblique asymptotes.
  • Sums of ordinates like \(x + \frac kx\): oblique asymptote \(y = x\), turning points where \(x^2 = k\).
  • Reciprocal of \(f\): zeros → asymptotes, max ↔ min at the same \(x\), meets \(f\) where \(f = \pm1\).
  • Inflection: \(f'' = 0\) and a sign change, at a point on the graph.
