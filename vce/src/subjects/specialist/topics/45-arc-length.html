Arc length

Length of a curve
\[ s = \int_a^b \sqrt{1 + \left(\frac{dy}{dx}\right)^2}\,dx \qquad s = \int_{t_1}^{t_2} \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt \]

From Pythagoras on a tiny piece: \(ds^2 = dx^2 + dy^2\).

Find the length of \(y = x^{3/2}\) from \(x = 0\) to \(x = 4\).

Differentiate, square, add 1, and integrate. This one is designed to give a perfect power under the root.

\(\frac{dy}{dx} = \frac32 x^{1/2}\), so \(1 + \left(\frac{dy}{dx}\right)^2 = 1 + \frac94 x\).

\(s = \int_0^4 \left(1 + \frac94 x\right)^{1/2}dx = \left[\frac{8}{27}\left(1 + \frac94 x\right)^{3/2}\right]_0^4\).

\(= \frac{8}{27}\left(10^{3/2} - 1\right) = \frac{8}{27}(10\sqrt{10} - 1) \approx 9.07\).

Use the parametric formula to find the length of \(x = 3\cos t,\ y = 3\sin t\) for \(0 \le t \le 2\pi\).

\(\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 = 9\sin^2 t + 9\cos^2 t = 9\), so the integrand is constant.

\(s = \int_0^{2\pi} 3\,dt\).

\(= 6\pi\), the circumference. ✓

Find the length of \(x = t^2,\ y = \frac23 t^3\) for \(0 \le t \le \sqrt3\).

Here \(\dot x^2 + \dot y^2 = 4t^2 + 4t^4 = 4t^2(1 + t^2)\), so the root simplifies to \(2t\sqrt{1 + t^2}\) for \(t \ge 0\), then substitute \(u = 1 + t^2\).

\(s = \int_0^{\sqrt3} 2t\sqrt{1 + t^2}\,dt\).

\(u = 1 + t^2\): \(\int_1^4 u^{1/2}\,du = \left[\frac23 u^{3/2}\right]_1^4\).

\(= \frac23(8 - 1) = \frac{14}{3}\).

\(\sqrt{1 + (y')^2} \ne 1 + y'\). Most arc-length integrals don't simplify by hand: in Exam 2, write the integral and evaluate numerically with CAS. In Exam 1, expect a perfect square like \(1 + \left(\frac{x^2}{4} - \frac{1}{x^2}\right)^2 = \left(\frac{x^2}{4} + \frac{1}{x^2}\right)^2\).

Surface area of revolution

Curved surface area
\[ \text{about the } x\text{-axis: } S = 2\pi\int_a^b y\sqrt{1 + \left(\frac{dy}{dx}\right)^2}\,dx \qquad \text{about the } y\text{-axis: } S = 2\pi\int_c^d x\sqrt{1 + \left(\frac{dx}{dy}\right)^2}\,dy \]

Each piece of curve \(ds\) sweeps out a thin band of circumference \(2\pi\times\)(radius). Parametric: \(S = 2\pi\int y\sqrt{\dot x^2 + \dot y^2}\,dt\) about the \(x\)-axis.

Show that the surface area of a sphere of radius \(r\) is \(4\pi r^2\), by rotating \(y = \sqrt{r^2 - x^2}\) about the \(x\)-axis.

The product \(y\sqrt{1 + (y')^2}\) simplifies beautifully to the constant \(r\).

\(y' = \frac{-x}{\sqrt{r^2 - x^2}}\), so \(1 + (y')^2 = \frac{r^2}{r^2 - x^2}\) and \(y\sqrt{1 + (y')^2} = \sqrt{r^2 - x^2}\cdot\frac{r}{\sqrt{r^2 - x^2}} = r\).

\(S = 2\pi\int_{-r}^{r} r\,dx = 4\pi r^2\). \(\blacksquare\)

The line \(y = \frac{x}{2}\) for \(0 \le x \le 4\) is rotated about the \(x\)-axis. Find the curved surface area.

This makes a cone of radius 2 and slant height \(\sqrt{20}\). Check the formula against \(\pi r l\).

\(\sqrt{1 + \frac14} = \frac{\sqrt5}{2}\): \(S = 2\pi\int_0^4 \frac{x}{2}\cdot\frac{\sqrt5}{2}\,dx = \frac{\sqrt5\pi}{2}\left[\frac{x^2}{2}\right]_0^4\).

\(= 4\sqrt5\pi\). Check: \(\pi r l = \pi(2)(2\sqrt5) = 4\sqrt5\pi\). ✓

Exam 2 favourites: "write down a definite integral for the length of the path" of a particle moving on a parametric curve (the distance travelled), or the surface area of a solid (a lampshade, a dish). Don't forget the \(2\pi\) and the \(y\) (the radius) in surface area.

Practice

The length of \(y = 2x + 1\) from \(x = 0\) to \(x = 3\) is

  1. \(3\)
  2. \(6\)
  3. \(3\sqrt5\)
  4. \(\sqrt{13}\)

\(\int_0^3\sqrt{1 + 4}\,dx = 3\sqrt5\) (the distance from \((0, 1)\) to \((3, 7)\)).

The arc length of \(x = e^t\cos t,\ y = e^t\sin t\) from \(t = 0\) to \(t = 1\) is given by

  1. \(\int_0^1 \sqrt2\,e^t\,dt\)
  2. \(\int_0^1 e^t\,dt\)
  3. \(\int_0^1 2e^{2t}\,dt\)
  4. \(\int_0^1 \sqrt{e^{2t}}\,dt\)

\(\dot x = e^t(\cos t - \sin t)\), \(\dot y = e^t(\sin t + \cos t)\): \(\dot x^2 + \dot y^2 = 2e^{2t}\).

The curved surface area when \(y = f(x)\), \(a \le x \le b\), is rotated about the \(x\)-axis is

  1. \(\pi\int_a^b y^2\,dx\)
  2. \(2\pi\int_a^b \sqrt{1 + (y')^2}\,dx\)
  3. \(\int_a^b 2\pi y\,dx\)
  4. \(2\pi\int_a^b y\sqrt{1 + (y')^2}\,dx\)

A is a volume; B omits the radius; C uses \(dx\) instead of \(ds\).

Find the exact length of \(y = \dfrac{x^3}{6} + \dfrac{1}{2x}\) from \(x = 1\) to \(x = 2\).

\(y' = \frac{x^2}{2} - \frac{1}{2x^2}\); \(1 + (y')^2 = \left(\frac{x^2}{2} + \frac{1}{2x^2}\right)^2\). [1]

\(s = \int_1^2\left(\frac{x^2}{2} + \frac{1}{2x^2}\right)dx = \left[\frac{x^3}{6} - \frac{1}{2x}\right]_1^2\). [1]

\(= \left(\frac43 - \frac14\right) - \left(\frac16 - \frac12\right) = \frac{17}{12}\). [1]

Find the surface area generated when \(y = \sqrt{x}\), \(0 \le x \le 2\), is rotated about the \(x\)-axis.

\(y\sqrt{1 + (y')^2} = \sqrt x\sqrt{1 + \frac{1}{4x}} = \sqrt{x + \frac14}\). [1]

\(S = 2\pi\int_0^2\sqrt{x + \frac14}\,dx = 2\pi\left[\frac23\left(x + \frac14\right)^{3/2}\right]_0^2\). [1]

\(= \frac{4\pi}{3}\left(\frac{27}{8} - \frac18\right) = \frac{4\pi}{3}\cdot\frac{13}{4} = \frac{13\pi}{3}\). [1]

Summary

  • \(s = \int\sqrt{1 + (y')^2}dx = \int\sqrt{\dot x^2 + \dot y^2}dt\).
  • Surface area: \(2\pi\int(\text{radius})\,ds\): \(2\pi\int y\sqrt{1 + (y')^2}dx\) about the \(x\)-axis.
  • Exam 1: look for perfect squares; Exam 2: set up and use CAS.
