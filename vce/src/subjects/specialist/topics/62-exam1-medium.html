2023 VCAA Exam 1 · Question 4 Open in the exam PDF (p. 5) ↗

Implicit differentiation of \(x\arcsin(y^2) = \pi\) at \(\left(6, \frac{1}{\sqrt2}\right)\), answer in the form \(-\frac{\pi\sqrt a}{b}\)

State average for the whole question: 1.8 / 3 (60%).

Find \(\frac{dy}{dx}\) at the point

  • Product and chain rule: \(\arcsin(y^2) + \frac{2xy}{\sqrt{1 - y^4}}\frac{dy}{dx} = 0\)
  • Substitutes: \(\frac\pi6 + 4\sqrt6\frac{dy}{dx} = 0\)
  • \(\frac{dy}{dx} = -\frac{\pi\sqrt6}{144}\)

\(-\frac{\pi\sqrt6}{144}\) (\(a = 6,\ b = 144\)).

State average 1.8 / 3 (60%); 37% scored full marks.

Mark distribution: 0: 25% · 1: 6% · 2: 32% · 3: 37%

2023 VCAA Exam 1 · Question 7 Open in the exam PDF (p. 7) ↗

Surface area when the parametric curve \(x = \frac{t^2}{4} - 1,\ y = \sqrt3 t\) is rotated about the \(x\)-axis

State average for the whole question: 2.2 / 4 (55%).

Find the surface area

  • \(S = 2\pi\int_0^2 y\sqrt{\dot x^2 + \dot y^2}\,dt\) with \(\sqrt{\frac{t^2}{4} + 3}\)
  • \(= \sqrt3\pi\int_0^2 t\sqrt{t^2 + 12}\,dt\)
  • \(= \frac{\sqrt3\pi}{3}\left[(t^2 + 12)^{3/2}\right]_0^2\)
  • \(\pi\left(\frac{64\sqrt3}{3} - 24\right)\)

\(\pi\left(\frac{64\sqrt3}{3} - 24\right)\).

State average 2.2 / 4 (55%); 31% scored full marks.

Mark distribution: 0: 17% · 1: 24% · 2: 13% · 3: 15% · 4: 31%

2024 VCAA Exam 1 · Question 1 Open in the exam PDF (p. 2) ↗

Cubic with complex coefficients \(3z^3 + 2iz^2 + 3z + 2i\): verify a factor, solve, plot the roots

State average for the whole question: 2.5 / 4 (62%).

Verify \(3z + 2i\) is a factor

  • Shows \(f\left(-\frac{2i}{3}\right) = 0\) or factorises \(f(z) = (3z + 2i)(z^2 + 1)\)

Grouping: \(z^2(3z + 2i) + (3z + 2i) = (3z + 2i)(z^2 + 1)\).

State average 0.8 / 1 (80%); 73% scored full marks.

Mark distribution: 0: 27% · 1: 73%

Solve \(f(z) = 0\) in Cartesian form

  • \((3z + 2i)(z^2 + 1) = 0\)
  • \(z = -\frac{2}{3}i,\ \pm i\)

\(z = i,\ -i,\ -\frac23 i\). Show that you are solving an equation, not just factorising.

State average 1.2 / 2 (60%); 48% scored full marks.

Mark distribution: 0: 30% · 1: 22% · 2: 48%

Plot the solutions on an Argand diagram

  • Three points on the imaginary axis at \(1, -1\) and \(-\frac23\)

All three lie on the imaginary axis. Read the circle spacing carefully to place \(-\frac23 i\).

State average 0.5 / 1 (50%); 49% scored full marks.

Mark distribution: 0: 51% · 1: 49%

\(f(x) = \frac{(x - 1)^2}{(x + 1)^2}\): partial-fraction form, the turning point, then a labelled sketch

State average for the whole question: 3.3 / 6 (55%).

Show \(A = 1, B = -4, C = 4\)

  • Writes \((x - 1)^2 = (x + 1)^2 - 4(x + 1) + 4\) (or equivalent) and divides

\(f(x) = 1 - \frac{4}{x + 1} + \frac{4}{(x + 1)^2}\).

State average 0.7 / 1 (70%); 63% scored full marks.

Mark distribution: 0: 37% · 1: 63%

Coordinates of the turning point

  • \(f^{\prime}(x) = \frac{4}{(x + 1)^2} - \frac{8}{(x + 1)^3} = \frac{4(x - 1)}{(x + 1)^3}\)
  • \((1, 0)\)

\((1, 0)\). Differentiating the part (a) form avoids the quotient rule.

State average 1.6 / 2 (80%); 65% scored full marks.

Mark distribution: 0: 12% · 1: 23% · 2: 65%

Sketch with asymptotes and intercepts labelled

  • Intercepts \((0, 1)\) and \((1, 0)\) labelled
  • Correct shape: both branches above the x-axis, left branch above y = 1, minimum touching at (1, 0)

Asymptotes \(x = -1\), \(y = 1\); intercepts \((0, 1)\), \((1, 0)\). This sketch was done poorly: extra asymptotes and unlabelled features were common.

2024 VCAA Exam 1 · Question 7 Open in the exam PDF (p. 10) ↗

Separable DE \(x + 2y\sqrt{x^2 + 1}\frac{dy}{dx} = 0\) with \(y(0) = -2\), \(y\) as a function of \(x\)

State average for the whole question: 2.3 / 4 (57%).

Solve the DE

  • Separates: \(\int 2y\,dy = -\int\frac{x}{\sqrt{x^2 + 1}}dx\)
  • \(y^2 = -\sqrt{x^2 + 1} + c\)
  • \(c = 5\)
  • \(y = -\sqrt{5 - \sqrt{x^2 + 1}}\) (negative root since \(y(0) < 0\))

\(y = -\sqrt{5 - \sqrt{x^2 + 1}}\). Students lost the last mark by leaving \(y^2 = \dots\) or picking the positive root.

State average 2.3 / 4 (57%); 27% scored full marks.

Mark distribution: 0: 17% · 1: 13% · 2: 21% · 3: 22% · 4: 27%

2024 VCAA Exam 1 · Question 8 Open in the exam PDF (p. 11) ↗

\(x^2y^2 + xy = 2\): show \(\frac{dy}{dx} = -\frac yx\), then points where the tangent slope is \(-1\)

State average for the whole question: 2.4 / 4 (60%).

Show \(\frac{dy}{dx} = -\frac{y}{x}\)

  • \(2xy^2 + 2x^2y\frac{dy}{dx} + y + x\frac{dy}{dx} = 0\)
  • Factorises: \(\frac{dy}{dx} = -\frac{y(2xy + 1)}{x(2xy + 1)} = -\frac yx\)

The \((2xy + 1)\) factors cancel; that factorisation is the evidence markers wanted.

State average 1.4 / 2 (70%); 54% scored full marks.

Mark distribution: 0: 15% · 1: 31% · 2: 54%

Points with slope −1

  • \(y = x\) substituted: \(x^4 + x^2 - 2 = 0\)
  • \((1, 1)\) and \((-1, -1)\)

\((x^2 + 2)(x^2 - 1) = 0\), so \((1, 1)\) and \((-1, -1)\). Remember the points must lie on the curve.

State average 1 / 2 (50%); 32% scored full marks.

Mark distribution: 0: 37% · 1: 30% · 2: 32%

2025 VCAA Exam 1 · Question 3 Open in the exam PDF (p. 4) ↗

Velocity \(v = \frac{t}{\sqrt{t^2 + k}}\): displacement by integration, initial acceleration, then a second particle 1 m ahead after 3 s

State average for the whole question: 2.9 / 5 (58%).

Show \(x = \sqrt{t^2 + k} - \sqrt k\)

  • Integrates to \(\sqrt{t^2 + k} + c\) and uses \(x(0) = 0\) to get \(c = -\sqrt k\)

Apply the initial condition explicitly: that’s where the mark is.

State average 0.7 / 1 (70%); 71% scored full marks.

Mark distribution: 0: 29% · 1: 71%

Initial acceleration

  • \(a = \frac{dv}{dt} = \frac{k}{(t^2 + k)^{3/2}}\)
  • \(a(0) = \frac{1}{\sqrt k}\)

\(\frac{1}{\sqrt k}\) m/s². A wrong derivative lost marks even with the right final value.

State average 1.4 / 2 (70%); 57% scored full marks.

Mark distribution: 0: 19% · 1: 24% · 2: 57%

Find k

  • \(3 - (\sqrt{9 + k} - \sqrt k) = 1\)
  • \(k = \frac{25}{16}\)

\(\sqrt{9 + k} = 2 + \sqrt k \Rightarrow \sqrt k = \frac54\), so \(k = \frac{25}{16}\).

State average 0.8 / 2 (40%); 28% scored full marks.

Mark distribution: 0: 49% · 1: 23% · 2: 28%

2025 VCAA Exam 1 · Question 7 Open in the exam PDF (p. 8) ↗

Induction proof of a formula for \(2^2 + 3^2 + \dots + (n + 1)^2\)

State average for the whole question: 2.6 / 4 (65%).

Induction proof

  • Base case \(n = 1\): both sides equal 4
  • States the assumption for \(n = k\)
  • Adds \((k + 2)^2\) and simplifies to \(\frac16(k + 1)\left(2(k + 1)^2 + 9(k + 1) + 13\right)\)
  • Conclusion for all n ∈ N

Both sides become \(\frac16(2k^3 + 15k^2 + 37k + 24)\). Not answered well: weak base cases and misstated assumptions were common.

State average 2.6 / 4 (65%); 29% scored full marks.
