Derivatives of the inverse circular functions

On the formula sheet
\[ \frac{d}{dx}\sin^{-1}\!\left(\frac{x}{a}\right) = \frac{1}{\sqrt{a^2 - x^2}} \qquad \frac{d}{dx}\cos^{-1}\!\left(\frac{x}{a}\right) = \frac{-1}{\sqrt{a^2 - x^2}} \qquad \frac{d}{dx}\tan^{-1}\!\left(\frac{x}{a}\right) = \frac{a}{a^2 + x^2} \]

(\(a > 0\); the first two for \(|x| < a\).) With \(a = 1\): \(\frac{1}{\sqrt{1 - x^2}}\), \(\frac{-1}{\sqrt{1 - x^2}}\), \(\frac{1}{1 + x^2}\).

Show that \(\dfrac{d}{dx}\sin^{-1}x = \dfrac{1}{\sqrt{1 - x^2}}\) for \(-1 < x < 1\).

Let \(y = \sin^{-1}x\), so \(\sin y = x\). Differentiate \(x\) with respect to \(y\), flip it, and use \(\cos y \ge 0\) on the range \([-\frac\pi2, \frac\pi2]\) to choose the positive square root.

\(x = \sin y \Rightarrow \frac{dx}{dy} = \cos y\), so \(\frac{dy}{dx} = \frac{1}{\cos y}\).

\(\cos y = \sqrt{1 - \sin^2 y} = \sqrt{1 - x^2}\) (positive, since \(y \in (-\frac\pi2, \frac\pi2)\)).

\(\dfrac{dy}{dx} = \dfrac{1}{\sqrt{1 - x^2}}\). \(\blacksquare\)

Differentiate (a) \(y = \tan^{-1}(3x)\), (b) \(y = \cos^{-1}(\sqrt x)\), (c) \(y = x\sin^{-1}x\).

Treat the inside as \(u\): \(\frac{d}{dx}\tan^{-1}u = \frac{u'}{1 + u^2}\), \(\frac{d}{dx}\cos^{-1}u = \frac{-u'}{\sqrt{1 - u^2}}\). Part (c) is a product.

(a) \(\dfrac{3}{1 + 9x^2}\).

(b) \(\dfrac{-\frac{1}{2\sqrt x}}{\sqrt{1 - x}} = \dfrac{-1}{2\sqrt{x}\sqrt{1 - x}}\), for \(0 < x < 1\).

(c) \(\sin^{-1}x + \dfrac{x}{\sqrt{1 - x^2}}\).

\(\frac{d}{dx}\tan^{-1}\left(\frac x2\right) = \frac{2}{4 + x^2}\), not \(\frac{1}{4 + x^2}\). Use the formula-sheet form carefully, or the chain rule: \(\frac{1/2}{1 + x^2/4} = \frac{2}{4 + x^2}\).

Second derivatives and concavity

Concavity
\[ f''(x) > 0:\ \text{concave up (gradient increasing)} \qquad f''(x) < 0:\ \text{concave down} \]

A point of inflection is where concavity changes: \(f''\) changes sign (usually \(f'' = 0\) there). If also \(f' = 0\), it's a stationary point of inflection.

For \(f(x) = x e^{-x}\), find where the graph is concave down and the coordinates of the point of inflection.

Differentiate twice with the product rule, factorise, and solve \(f''(x) < 0\). The sign of \(f''\) is set by the polynomial factor, since \(e^{-x} > 0\).

\(f'(x) = e^{-x} - xe^{-x} = (1 - x)e^{-x}\).

\(f''(x) = -e^{-x} - (1 - x)e^{-x} = (x - 2)e^{-x}\).

Concave down for \(x < 2\), concave up for \(x > 2\). Inflection point \((2, 2e^{-2})\).

Find and classify the stationary points of \(y = x^3 - 6x^2 + 9x + 1\).

Solve \(y' = 0\), then the sign of \(y''\) at each point tells you its nature (if \(y'' = 0\), use a sign table of \(y'\) instead).

\(y' = 3x^2 - 12x + 9 = 3(x - 1)(x - 3) = 0 \Rightarrow x = 1, 3\).

\(y'' = 6x - 12\): \(y''(1) = -6 < 0\), \(y''(3) = 6 > 0\).

Local maximum \((1, 5)\), local minimum \((3, 1)\). Inflection at \(x = 2\), point \((2, 3)\).

Graphs of a function, its derivative and its antiderivatives

  • Where \(f\) has a stationary point, \(f'\) crosses or touches the \(x\)-axis.
  • Where \(f\) has an inflection point, \(f'\) has a turning point.
  • If \(F' = f\): where \(f = 0\) (and changes sign), \(F\) has a turning point; where \(f\) has a turning point, \(F\) has an inflection point; where \(f > 0\), \(F\) is increasing.
  • Antiderivatives differ by a constant: their graphs are vertical translations of each other.

VCAA multiple choice often shows the graph of \(f'\) and asks about \(f\) (or shows \(f\) and asks about an antiderivative). Read off: sign of \(f'\) → increasing/decreasing; \(x\)-intercepts of \(f'\) → stationary points; turning points of \(f'\) → inflection points of \(f\).

Practice

\(\dfrac{d}{dx}\sin^{-1}\!\left(\dfrac{x}{3}\right)\) is

  1. \(\frac{1}{3\sqrt{9 - x^2}}\)
  2. \(\frac{1}{\sqrt{9 - x^2}}\)
  3. \(\frac{3}{\sqrt{9 - x^2}}\)
  4. \(\frac{1}{\sqrt{1 - x^2}}\)

Formula sheet with \(a = 3\).

\(\dfrac{d}{dx}\tan^{-1}(x^2)\) is

  1. \(\frac{1}{1 + x^4}\)
  2. \(\frac{2x}{1 + x^2}\)
  3. \(\frac{1}{1 + x^2}\)
  4. \(\frac{2x}{1 + x^4}\)

\(\frac{u'}{1 + u^2}\) with \(u = x^2\).

For \(f(x) = x^4\), \(f''(0) = 0\). At \(x = 0\) the graph has

  1. a local minimum
  2. a stationary point of inflection
  3. a non-stationary point of inflection
  4. a local maximum

\(f''(x) = 12x^2 \ge 0\) doesn't change sign, so no inflection; \(f'\) changes from negative to positive: a minimum.

The graph of \(y = f'(x)\) is a parabola with a minimum at \(x = 2\) and \(x\)-intercepts at \(x = 0\) and \(x = 4\). The graph of \(y = f(x)\) has

  1. a local minimum at \(x = 2\)
  2. local maxima at \(x = 0\) and \(x = 4\)
  3. a local maximum at \(x = 0\), a local minimum at \(x = 4\) and an inflection point at \(x = 2\)
  4. a local minimum at \(x = 0\) and a local maximum at \(x = 4\)

\(f'\) goes \(+\) to \(-\) at 0 (max), \(-\) to \(+\) at 4 (min); its turning point at 2 is an inflection of \(f\).

If \(y = \cos^{-1}(2x)\), then \(\dfrac{dy}{dx}\) at \(x = \frac14\) is

  1. \(-\frac{2}{\sqrt3}\)
  2. \(-\frac{4}{\sqrt3}\)
  3. \(\frac{4}{\sqrt3}\)
  4. \(-\frac{1}{\sqrt3}\)

\(\frac{-2}{\sqrt{1 - 4x^2}} = \frac{-2}{\sqrt{3/4}} = \frac{-4}{\sqrt3}\).

Find the gradient of \(y = \tan^{-1}(2x)\) at \(x = \frac12\).

\(\frac{dy}{dx} = \frac{2}{1 + 4x^2}\). [1]

At \(x = \frac12\): \(\frac{2}{2} = 1\). [1]

Show that \(y = \tan^{-1}x\) has a point of inflection at the origin.

\(y' = (1 + x^2)^{-1}\), \(y'' = \dfrac{-2x}{(1 + x^2)^2}\). [1]

\(y''(0) = 0\); \(y'' > 0\) for \(x < 0\) and \(y'' < 0\) for \(x > 0\). [1]

Concavity changes at \((0, 0)\), which is on the graph, so it's a point of inflection. [1]

Let \(f(x) = \sin^{-1}x + \sin^{-1}\sqrt{1 - x^2}\) for \(0 < x < 1\). Show that \(f'(x) = 0\) and hence find the value of \(f(x)\).

\(\frac{d}{dx}\sin^{-1}\sqrt{1 - x^2} = \dfrac{\frac{-x}{\sqrt{1 - x^2}}}{\sqrt{1 - (1 - x^2)}} = \dfrac{-x}{x\sqrt{1 - x^2}} = \dfrac{-1}{\sqrt{1 - x^2}}\) (since \(x > 0\)). [2]

So \(f'(x) = \frac{1}{\sqrt{1 - x^2}} - \frac{1}{\sqrt{1 - x^2}} = 0\), and \(f\) is constant. [1]

\(f\!\left(\frac{1}{\sqrt2}\right) = \frac\pi4 + \frac\pi4 = \frac\pi2\). [1]

Summary

  • \(\frac{d}{dx}\sin^{-1}u = \frac{u'}{\sqrt{1 - u^2}}\), \(\frac{d}{dx}\cos^{-1}u = \frac{-u'}{\sqrt{1 - u^2}}\), \(\frac{d}{dx}\tan^{-1}u = \frac{u'}{1 + u^2}\).
  • \(f'' > 0\) concave up; inflection where \(f''\) changes sign.
  • Graph of \(f'\): zeros ↔ stationary points of \(f\); turning points ↔ inflections of \(f\).
