Writing a differential equation from words

A differential equation (DE) links an unknown function to its derivatives. "The rate of change of \(Q\)" means \(\frac{dQ}{dt}\); "proportional to" means "equals a constant times".

Standard set-ups
\[ \frac{dN}{dt} = kN \ \text{(growth/decay)} \qquad \frac{dT}{dt} = -k(T - T_s) \ \text{(Newton's cooling)} \qquad \frac{dQ}{dt} = \text{rate in} - \text{rate out} \ \text{(mixing)} \]

A tank holds 100 L of water with 5 kg of salt dissolved. Brine with 0.2 kg/L of salt flows in at 4 L/min and the well-mixed solution flows out at 4 L/min. Write a DE for \(Q\), the kg of salt in the tank after \(t\) minutes.

Rate in = (concentration in) × (flow in). Rate out = (current concentration \(\frac{Q}{V}\)) × (flow out). Here the volume stays 100 L since in = out.

Rate in \(= 0.2 \times 4 = 0.8\) kg/min. Rate out \(= \frac{Q}{100}\times 4 = \frac{Q}{25}\) kg/min.

\(\dfrac{dQ}{dt} = 0.8 - \dfrac{Q}{25}\), with \(Q(0) = 5\).

If the flow rates differ, the volume changes: \(V(t) = V_0 + (\text{in} - \text{out})t\), and the outflow concentration is \(\frac{Q}{V(t)}\), not \(\frac{Q}{V_0}\).

Water leaks from a cylindrical tank of radius 2 m at a rate proportional to the square root of the depth \(h\) m. Write a DE for \(h\) in terms of \(t\).

Volume \(V = \pi r^2 h = 4\pi h\). Given \(\frac{dV}{dt} = -k\sqrt h\), use the chain rule \(\frac{dh}{dt} = \frac{dh}{dV}\cdot\frac{dV}{dt}\).

\(\frac{dV}{dh} = 4\pi\), so \(\frac{dh}{dV} = \frac{1}{4\pi}\).

\(\dfrac{dh}{dt} = -\dfrac{k\sqrt h}{4\pi}\), \(k > 0\).

Verifying a solution

To show \(y = f(x)\) satisfies a DE, differentiate and substitute into both sides. No solving needed.

Verify that \(y = e^{2x} + 3e^{-x}\) satisfies \(\frac{d^2y}{dx^2} - \frac{dy}{dx} - 2y = 0\).

Find \(y'\) and \(y''\), substitute, and show the left side simplifies to zero.

\(y' = 2e^{2x} - 3e^{-x}\), \(y'' = 4e^{2x} + 3e^{-x}\).

LHS \(= (4e^{2x} + 3e^{-x}) - (2e^{2x} - 3e^{-x}) - 2(e^{2x} + 3e^{-x}) = 0\) = RHS. ✓

Slope fields

A slope field draws a short segment of gradient \(\frac{dy}{dx}\) at each grid point. Solution curves follow the segments.

Reading a slope field: if the segments are the same along each vertical line, \(\frac{dy}{dx}\) depends only on \(x\). If they're the same along each horizontal line, it depends only on \(y\). Horizontal segments mark where \(\frac{dy}{dx} = 0\) (for \(\frac{dy}{dx} = g(y)\), these are equilibrium solutions).

A slope field has horizontal segments along the lines \(y = 0\) and \(y = 4\), positive slopes between them and negative slopes above \(y = 4\). Which DE could it represent: \(\frac{dy}{dx} = y(4 - y)\), \(\frac{dy}{dx} = x(4 - x)\) or \(\frac{dy}{dx} = y(y - 4)\)?

The pattern depends only on \(y\), ruling out the \(x\) option. Test \(y = 2\): \(2(2) = 4 > 0\) for the first, \(2(-2) < 0\) for the third.

\(\dfrac{dy}{dx} = y(4 - y)\) (logistic-type).

Euler's method

Euler's method
\[ x_{n+1} = x_n + h, \qquad y_{n+1} = y_n + h\,f(x_n, y_n) \quad \text{for } \frac{dy}{dx} = f(x, y) \]

Step along the tangent line for a distance \(h\) in \(x\). Smaller \(h\) usually gives a better approximation.

Given \(\frac{dy}{dx} = x + y\), \(y(0) = 1\), use Euler's method with \(h = 0.1\) to estimate \(y(0.2)\).

Use the gradient at the current point each time. Tabulate to avoid slips.

\(y_1 = 1 + 0.1(0 + 1) = 1.1\) at \(x_1 = 0.1\).

\(y_2 = 1.1 + 0.1(0.1 + 1.1) = 1.1 + 0.12 = 1.22\).

\(y(0.2) \approx 1.22\). (The exact value is \(2e^{0.2} - 1.2 \approx 1.243\): Euler underestimates since the curve is concave up.)

Euler's method is a VCAA favourite in Exam 1 with friendly numbers, and in Exam 2 MC. If asked whether the estimate is an over- or underestimate, use concavity: concave up → tangent lines sit below → underestimate.

Practice

The rate at which a population \(P\) decreases is proportional to the square of the population. A DE for this is

  1. \(\frac{dP}{dt} = kP\), \(k > 0\)
  2. \(\frac{dP}{dt} = -kP^2\), \(k > 0\)
  3. \(\frac{dP}{dt} = kP^2\), \(k > 0\)
  4. \(\frac{dP}{dt} = -2kP\), \(k > 0\)

"Decreases" gives the negative sign; "proportional to the square" gives \(kP^2\).

Euler's method with step size 0.5 is applied to \(\frac{dy}{dx} = 2x\), \(y(1) = 3\). The estimate of \(y(1.5)\) is

  1. 3.5
  2. 3.25
  3. 5
  4. 4

\(3 + 0.5\times 2(1) = 4\).

A slope field shows identical segments along every vertical line, with zero slope on the \(y\)-axis, positive slope for \(x > 0\) and negative for \(x < 0\). The DE could be

  1. \(\frac{dy}{dx} = x^3\)
  2. \(\frac{dy}{dx} = y\)
  3. \(\frac{dy}{dx} = x^2\)
  4. \(\frac{dy}{dx} = xy\)

Depends only on \(x\), and changes sign at \(x = 0\): \(x^3\). \(x^2\) is never negative.

A 50 L tank initially holds pure water. Brine of 0.1 kg/L enters at 3 L/min; the mixture leaves at 2 L/min. If \(Q\) kg is the salt after \(t\) min, then \(\frac{dQ}{dt} =\)

  1. \(0.3 - \frac{2Q}{50}\)
  2. \(0.3 - \frac{3Q}{50 + t}\)
  3. \(0.3 - \frac{2Q}{50 + t}\)
  4. \(0.1 - \frac{Q}{50 + t}\)

Volume grows by 1 L/min, so \(V = 50 + t\); out \(= \frac{Q}{50 + t}\times 2\).

Verify that \(y = \frac{1}{x + c}\) is a solution of \(\frac{dy}{dx} = -y^2\).

\(\frac{dy}{dx} = -\frac{1}{(x + c)^2}\). [1]

\(-y^2 = -\frac{1}{(x + c)^2}\), so LHS = RHS. [1]

Use Euler's method with step size 0.1 to estimate \(y(1.2)\) given \(\frac{dy}{dx} = \frac{y}{x}\), \(y(1) = 2\).

\(y_1 = 2 + 0.1\cdot\frac{2}{1} = 2.2\) at \(x = 1.1\). [1]

\(y_2 = 2.2 + 0.1\cdot\frac{2.2}{1.1} = 2.2 + 0.2 = 2.4\). [1]

\(y(1.2) \approx 2.4\) (here exact, since the solution \(y = 2x\) is linear). [1]

A conical tank (vertex down) has height equal to its top radius. Water flows in at 2 m³/min. Find \(\frac{dh}{dt}\) in terms of the depth \(h\).

\(r = h\), so \(V = \frac13\pi h^3\). [1]

\(\frac{dV}{dh} = \pi h^2\). [1]

\(\frac{dh}{dt} = \frac{2}{\pi h^2}\) m/min. [1]

Summary

  • "Rate" → derivative; "proportional to" → \(k\times\); mixing: rate in − rate out, with concentration \(\frac{Q}{V(t)}\).
  • Verify by differentiating and substituting, not solving.
  • Slope field: same along verticals → \(f(x)\) only; same along horizontals → \(g(y)\) only.
  • Euler: \(y_{n+1} = y_n + h f(x_n, y_n)\); concave up → underestimate.
