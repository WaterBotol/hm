Specialist Exam 1 is 1 hour (plus 15 min reading) for about 40 marks: tech-free, exact answers, and at least one proof. Allow about 1.5 minutes per mark. Do these with no CAS or calculator, then mark yourself strictly: VCAA awards method and answer marks separately, and proofs need every step. The questions start routine and finish with the styles that usually have the lowest averages.

Section 1: routine (aim for full marks)

Q1. Write \(z = 1 - \sqrt3 i\) in polar form, and hence find \(z^6\).

\(|z| = 2\), \(\operatorname{Arg} z = -\frac\pi3\): \(z = 2\operatorname{cis}\left(-\frac\pi3\right)\). [1]

\(z^6 = 64\operatorname{cis}(-2\pi) = 64\). [1]

Q2. Find the gradient of \(x^2 + xy + y^2 = 7\) at the point \((1, 2)\).

\(2x + y + x\frac{dy}{dx} + 2y\frac{dy}{dx} = 0 \Rightarrow \frac{dy}{dx} = -\frac{2x + y}{x + 2y}\). [1]

At \((1, 2)\): \(-\frac45\). [1]

Q3. Evaluate \(\displaystyle\int_2^3 \frac{1}{x^2 - 1}\,dx\).

\(\frac{1}{x^2 - 1} = \frac{1}{2(x - 1)} - \frac{1}{2(x + 1)}\). [1]

\(\frac12\big[\log_e|x - 1| - \log_e|x + 1|\big]_2^3 = \frac12\left(\log_e\frac24 - \log_e\frac13\right)\). [1]

\(= \frac12\log_e\frac32\). [1]

Q4. Evaluate \(\displaystyle\int_0^1 xe^{-x}\,dx\).

\(u = x\), \(v' = e^{-x}\): \(\big[-xe^{-x}\big]_0^1 + \int_0^1 e^{-x}dx\). [1]

\(= -e^{-1} + \big[-e^{-x}\big]_0^1 = -e^{-1} - e^{-1} + 1\). [1]

\(= 1 - \frac2e\). [1]

Q5. Find the vector resolute of \(\underset{\sim}{a} = 3\underset{\sim}{i} - \underset{\sim}{j} + 2\underset{\sim}{k}\) in the direction of \(\underset{\sim}{b} = 2\underset{\sim}{i} + 2\underset{\sim}{j} + \underset{\sim}{k}\).

\(\underset{\sim}{a}\cdot\underset{\sim}{b} = 6 - 2 + 2 = 6\). [1]

\(\underset{\sim}{b}\cdot\underset{\sim}{b} = 9\). [1]

\(\frac23(2\underset{\sim}{i} + 2\underset{\sim}{j} + \underset{\sim}{k})\). [1]

Section 2: standard

Q6. Solve \(z^3 = 8i\), giving the solutions in Cartesian form.

\(8i = 8\operatorname{cis}\frac\pi2\), so \(z = 2\operatorname{cis}\left(\frac\pi6 + \frac{2k\pi}{3}\right)\). [1]

Arguments \(\frac\pi6, \frac{5\pi}{6}, -\frac\pi2\). [1]

\(z = \sqrt3 + i,\ -\sqrt3 + i,\ -2i\). [1]

Q7. Solve \(\frac{dy}{dx} = xy^2\), given \(y(0) = 1\). State the maximal domain of the solution containing \(x = 0\).

\(\int y^{-2}dy = \int x\,dx \Rightarrow -\frac1y = \frac{x^2}{2} + c\); \(c = -1\). [1]

\(y = \frac{2}{2 - x^2}\). [1]

Domain \((-\sqrt2, \sqrt2)\). [1]

Q8. The region between \(y = \frac{1}{\sqrt{1 + x^2}}\), the axes and \(x = 1\) is rotated about the \(x\)-axis. Find the exact volume.

\(V = \pi\int_0^1\frac{1}{1 + x^2}dx\). [1]

\(= \pi\big[\tan^{-1}x\big]_0^1\). [1]

\(= \frac{\pi^2}{4}\). [1]

Q9. A particle moves in a line with \(v = e^{-x}\), starting at \(x = 0\) when \(t = 0\). Find its acceleration in terms of \(x\), and \(x\) in terms of \(t\).

\(a = v\frac{dv}{dx} = e^{-x}(-e^{-x}) = -e^{-2x}\). [1]

\(\frac{dt}{dx} = e^x \Rightarrow t = e^x + c\), \(c = -1\). [1]

\(x = \log_e(t + 1)\). [1]

Q10. Evaluate \(\displaystyle\int_0^{\pi/2}\sin^3x\,dx\).

\(\int_0^{\pi/2}(1 - \cos^2x)\sin x\,dx\); let \(u = \cos x\). [1]

\(= \left[-\cos x + \frac{\cos^3x}{3}\right]_0^{\pi/2}\). [1]

\(= 0 - \left(-1 + \frac13\right) = \frac23\). [1]

Q11. Given that \(1 + i\) is a root of \(P(z) = z^3 - 4z^2 + 6z - 4\), factorise \(P(z)\) over \(\mathbb{C}\).

\(1 - i\) is also a root (real coefficients), so \(z^2 - 2z + 2\) is a factor. [1]

\(P(z) = (z^2 - 2z + 2)(z - 2)\). [1]

\(= (z - 1 - i)(z - 1 + i)(z - 2)\). [1]

Section 3: hardest styles

Q12. Prove by induction that \(7^n - 1\) is divisible by 6 for all \(n \in \mathbb{N}\).

Base: \(n = 1\): \(7 - 1 = 6\), divisible by 6. [1]

Assume \(7^k - 1 = 6m\) for some integer \(m\). [1]

\(7^{k+1} - 1 = 7\cdot7^k - 1 = 7(6m + 1) - 1 = 42m + 6 = 6(7m + 1)\). [1]

So true for \(n = k + 1\); by induction true for all \(n \in \mathbb{N}\). [1]

Q13. Find the complex numbers \(z\) satisfying both \(|z - 2| = |z + 2i|\) and \(|z| = 2\).

\((x - 2)^2 + y^2 = x^2 + (y + 2)^2 \Rightarrow y = -x\). [1]

\(x^2 + y^2 = 4 \Rightarrow 2x^2 = 4\), \(x = \pm\sqrt2\). [1]

\(z = \sqrt2 - \sqrt2 i\) or \(z = -\sqrt2 + \sqrt2 i\). [1]

Q14. Find the length of the curve \(y = \frac23x^{3/2}\) from \(x = 0\) to \(x = 3\).

\(y' = x^{1/2}\), so \(1 + (y')^2 = 1 + x\). [1]

\(s = \int_0^3(1 + x)^{1/2}dx = \left[\frac23(1 + x)^{3/2}\right]_0^3\). [1]

\(= \frac23(8 - 1) = \frac{14}{3}\). [1]

Q15. Find the Cartesian equation of the plane through \(A(1, 0, 1)\), \(B(2, 1, 0)\) and \(C(0, 1, 2)\), and its distance from the origin.

\(\overrightarrow{AB} = (1, 1, -1)\), \(\overrightarrow{AC} = (-1, 1, 1)\). [1]

\(\overrightarrow{AB}\times\overrightarrow{AC} = (2, 0, 2)\), so a normal is \((1, 0, 1)\). [1]

\(x + z = 2\) (check: \(A, B, C\) all give 2). [1]

Distance \(= \frac{|0 - 2|}{\sqrt2} = \sqrt2\). [1]

Marking yourself

Total 45 marks. Roughly: 37+ is A+ standard for Exam 1, and 30+ is solid. Fix any Section 1 losses first: those are the cheapest marks. If Q12–Q15 went badly, revisit induction, loci in the complex plane, arc length and planes.
