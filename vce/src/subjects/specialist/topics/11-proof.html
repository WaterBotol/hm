What a proof needs

A proof is a chain of statements, each following from definitions, given facts or earlier steps, ending at the result. Markers want to see the definitions written as algebra and each step justified.

IdeaWrite it as
\(n\) is even\(n = 2k,\ k \in \mathbb{Z}\)
\(n\) is odd\(n = 2k + 1,\ k \in \mathbb{Z}\)
\(a\) divides \(b\) (\(a \mid b\))\(b = ak,\ k \in \mathbb{Z}\)
\(x\) is rational\(x = \dfrac{p}{q},\ p, q \in \mathbb{Z},\ q \ne 0\), in lowest terms if needed
consecutive integers\(n,\ n + 1,\ n + 2\)

Use a different letter for each unknown integer. "Let \(m = 2k\) and \(n = 2k\)" secretly assumes \(m = n\). Write \(m = 2a\), \(n = 2b\).

Direct proof

Assume the hypothesis, then deduce the conclusion step by step.

Prove that the sum of an even integer and an odd integer is odd.

Write each number using its definition with separate letters, add, then rearrange into the form \(2(\text{integer}) + 1\).

Let \(m = 2a\) and \(n = 2b + 1\) where \(a, b \in \mathbb{Z}\).

\(m + n = 2a + 2b + 1 = 2(a + b) + 1\). Since \(a + b \in \mathbb{Z}\), \(m + n\) is odd. \(\blacksquare\)

Prove that for all positive reals \(a, b\): \(\dfrac{a + b}{2} \ge \sqrt{ab}\).

Inequality proofs are cleanest when you start from something obviously true, like a square being non-negative, and work forwards. Here \((\sqrt a - \sqrt b)^2 \ge 0\) expands to exactly what's needed.

For real \(\sqrt a, \sqrt b\): \((\sqrt a - \sqrt b)^2 \ge 0\).

Expand: \(a - 2\sqrt{ab} + b \ge 0\), so \(a + b \ge 2\sqrt{ab}\).

Divide by 2: \(\dfrac{a + b}{2} \ge \sqrt{ab}\), with equality only when \(a = b\). \(\blacksquare\)

Don't start from the result and work to "\(0 \le 0\)" without making every step reversible. Starting from what you're proving and reaching something true proves nothing on its own. Either work forwards, or say clearly that each step is an equivalence (\(\Leftrightarrow\)).

Proof by cases

Split into cases that cover every possibility (odd/even, positive/negative, remainders on division by 3), and prove each.

Prove that \(n^2 + n\) is even for every integer \(n\).

Every integer is odd or even, so two cases cover everything. (A slicker direct proof: \(n^2 + n = n(n + 1)\), a product of consecutive integers, one of which is even.)

Case \(n = 2k\): \(n^2 + n = 4k^2 + 2k = 2(2k^2 + k)\), even.

Case \(n = 2k + 1\): \(n^2 + n = 4k^2 + 4k + 1 + 2k + 1 = 2(2k^2 + 3k + 1)\), even. Both cases hold. \(\blacksquare\)

Proof by contrapositive

To prove \(P \Rightarrow Q\), prove \(\neg Q \Rightarrow \neg P\). Use it when the conclusion's negation gives you something concrete to work with.

Prove that for every integer \(n\), if \(n^2\) is even then \(n\) is even.

Directly, "\(n^2\) even" doesn't easily tell you about \(n\). The contrapositive, "if \(n\) is odd then \(n^2\) is odd", lets you write \(n = 2k + 1\) and square it.

Contrapositive: if \(n\) is odd then \(n^2\) is odd.

Let \(n = 2k + 1\). Then \(n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1\), which is odd.

The contrapositive is true, so the original statement is true. \(\blacksquare\)

Proof by contradiction

Assume the statement is false, deduce something impossible, and conclude the assumption was wrong.

Prove that \(\sqrt 2\) is irrational.

Suppose it is rational in lowest terms. Squaring shows both numerator and denominator must be even, which contradicts "lowest terms". This uses the contrapositive result above (\(p^2\) even means \(p\) even).

Assume \(\sqrt 2 = \dfrac{p}{q}\), with \(p, q \in \mathbb{Z}\), \(q \ne 0\), and no common factor.

Then \(p^2 = 2q^2\), so \(p^2\) is even, so \(p\) is even: \(p = 2k\).

Substitute: \(4k^2 = 2q^2 \Rightarrow q^2 = 2k^2\), so \(q\) is even too.

Both \(p\) and \(q\) are even, contradicting "no common factor". So \(\sqrt 2\) is irrational. \(\blacksquare\)

Prove that there are infinitely many prime numbers.

Assume there are finitely many and build a number that none of them divides. Multiplying all the primes and adding 1 does it: dividing by any of the primes leaves remainder 1.

Assume the primes are \(p_1, p_2, \dots, p_k\) (finitely many). Let \(N = p_1 p_2 \cdots p_k + 1\).

Dividing \(N\) by any \(p_i\) leaves remainder 1, so no \(p_i\) divides \(N\). But \(N > 1\) has a prime factor, which isn't on the list.

Contradiction, so there are infinitely many primes. \(\blacksquare\)

State the method in your first line ("Assume, for contradiction, that…", "We prove the contrapositive…"), and end with a clear conclusion. VCAA marks often split as: correct set-up, correct algebra, correct conclusion. A missing conclusion line can cost the last mark.

Choosing a method: direct when the hypothesis gives you algebra to work with; contrapositive when the conclusion is a "not" or hard to start from; contradiction for "is irrational", "there is no", "infinitely many"; cases when parity, sign or remainders matter; counterexample to disprove a "for all".

Practice

To prove "if \(3n + 2\) is odd then \(n\) is odd" by contrapositive, you would assume

  1. \(n\) is odd
  2. \(n\) is even
  3. \(3n + 2\) is even
  4. \(3n + 2\) is odd and \(n\) is even

Contrapositive: if \(n\) is even then \(3n + 2\) is even. So assume \(n = 2k\). (D is how a contradiction proof would start.)

A proof by contradiction that \(\sqrt 3\) is irrational begins by assuming

  1. \(\sqrt 3\) is irrational
  2. \(\sqrt 3 = 3k\) for an integer \(k\)
  3. \(\sqrt 3\) is an integer
  4. \(\sqrt 3 = \frac{p}{q}\) for integers \(p, q\), \(q \ne 0\), with no common factors

Assume the opposite of the claim: that it's rational, in lowest terms.

A student "proves" \(1 = 2\) by: let \(a = b\); then \(a^2 - b^2 = ab - b^2\), so \((a + b)(a - b) = b(a - b)\), so \(a + b = b\), so \(2b = b\). The error is

  1. dividing by \(a - b\), which is zero
  2. factorising \(a^2 - b^2\)
  3. assuming \(a = b\)
  4. subtracting \(b^2\) from both sides

Since \(a = b\), \(a - b = 0\) and division by zero is invalid.

Which is the best counterexample to "if \(n\) is prime then \(2^n - 1\) is prime"?

  1. \(n = 4\)
  2. \(n = 2\)
  3. \(n = 11\)
  4. \(n = 7\)

\(2^{11} - 1 = 2047 = 23 \times 89\). \(n = 4\) isn't prime, so it doesn't test the claim; 2 and 7 give primes 3 and 127.

To prove that \(n^3 - n\) is divisible by 3 for every integer \(n\) by cases, the most efficient cases are

  1. \(n\) even and \(n\) odd
  2. \(n = 3k\), \(n = 3k + 1\) and \(n = 3k + 2\)
  3. \(n > 0\), \(n = 0\) and \(n < 0\)
  4. \(n\) prime and \(n\) not prime

Divisibility by 3 depends on the remainder mod 3. (Or directly: \(n^3 - n = (n - 1)n(n + 1)\), three consecutive integers.)

Prove that the product of two odd integers is odd.

Let \(m = 2a + 1\), \(n = 2b + 1\). Then \(mn = 4ab + 2a + 2b + 1\). [1]

\(= 2(2ab + a + b) + 1\), which is odd since \(2ab + a + b \in \mathbb{Z}\). [1]

Prove by contradiction that there are no integers \(m, n\) with \(4m + 6n = 1\).

Assume integers \(m, n\) exist with \(4m + 6n = 1\). [1]

Then \(2(2m + 3n) = 1\), so 1 is even. [1]

This is a contradiction, so no such integers exist. [1]

Prove that for all real \(x\), \(x^2 + 1 \ge 2x\), and state when equality holds.

\(x^2 + 1 - 2x = (x - 1)^2\). [1]

A square is never negative, so \((x - 1)^2 \ge 0\), giving \(x^2 + 1 \ge 2x\). [1]

Equality when \(x - 1 = 0\), i.e. \(x = 1\). [1]

Prove that \(\log_2 3\) is irrational.

Assume \(\log_2 3 = \frac pq\) with \(p, q\) positive integers (it's positive since \(3 > 1\)). [1]

Then \(2^{p/q} = 3\), so \(2^p = 3^q\). [1]

The left side is even (\(p \ge 1\)) and the right side is odd. [1]

Contradiction, so \(\log_2 3\) is irrational. [1]

Summary

  • Translate definitions into algebra with separate letters: \(2a\), \(2b + 1\), \(b = ak\), \(\frac pq\).
  • Direct for straightforward deductions; cases for parity/remainders; contrapositive when the "not" is easier.
  • Contradiction: assume the opposite, reach an impossibility, conclude.
  • For inequalities, work forwards from something true like a square \(\ge 0\).
