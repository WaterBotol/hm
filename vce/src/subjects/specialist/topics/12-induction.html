The idea

To prove a statement \(P(n)\) for every natural number \(n \ge n_0\), you show it's true at the start and that truth always passes from one value to the next, like dominoes.

Structure
\[ \begin{aligned} &1.\ \text{Base case: show } P(n_0) \text{ is true.}\\ &2.\ \text{Inductive step: assume } P(k) \text{ is true for some } k \ge n_0, \text{ and prove } P(k + 1).\\ &3.\ \text{Conclusion: by the principle of mathematical induction, } P(n) \text{ is true for all } n \ge n_0. \end{aligned} \]

VCAA marks induction strictly. A typical 4-mark question: 1 for the base case, 1 for clearly stating the assumption for \(n = k\), 1 for using it correctly, 1 for reaching \(P(k + 1)\) and concluding. Write "Assume \(P(k)\) is true, i.e. …" and say where you use it.

Sums

Prove that \(\displaystyle\sum_{r=1}^{n} (2r - 1) = n^2\) for all \(n \in \mathbb{N}\).

For a sum, the step is: sum to \(k + 1\) = sum to \(k\) + the \((k + 1)\)th term. Replace the sum to \(k\) using the assumption, then simplify to the right side with \(n = k + 1\).

Base case \(n = 1\): LHS \(= 1\), RHS \(= 1^2 = 1\). True.

Assume true for \(n = k\): \(\sum_{r=1}^{k}(2r - 1) = k^2\).

Step \(n = k + 1\): \(\sum_{r=1}^{k+1}(2r - 1) = k^2 + (2(k + 1) - 1) = k^2 + 2k + 1 = (k + 1)^2\).

This is the statement for \(n = k + 1\). True for \(n = 1\), and true for \(k\) implies true for \(k + 1\), so by induction it is true for all \(n \in \mathbb{N}\). \(\blacksquare\)

Divisibility

Write the assumption as an equation with an integer: "\(6^k - 1 = 5m\)". Then rewrite the \(k + 1\) expression to make that piece appear.

Prove that \(6^n - 1\) is divisible by 5 for all \(n \in \mathbb{N}\).

From the assumption, \(6^k = 5m + 1\). Write \(6^{k+1} = 6\cdot 6^k\), substitute, and factor out 5.

Base \(n = 1\): \(6 - 1 = 5\), divisible by 5.

Assume \(6^k - 1 = 5m\) for some \(m \in \mathbb{Z}\), so \(6^k = 5m + 1\).

\(6^{k+1} - 1 = 6(5m + 1) - 1 = 30m + 5 = 5(6m + 1)\).

\(6m + 1 \in \mathbb{Z}\), so \(6^{k+1} - 1\) is divisible by 5. By induction, true for all \(n \in \mathbb{N}\). \(\blacksquare\)

Inequalities

Use the assumption, then a second inequality that's easy to justify for \(k \ge n_0\).

Prove that \(2^n > n^2\) for all integers \(n \ge 5\).

From \(2^k > k^2\), doubling gives \(2^{k+1} > 2k^2\). You then need \(2k^2 \ge (k + 1)^2\), which holds once \(k\) is large enough. Check that it holds for \(k \ge 5\).

Base \(n = 5\): \(32 > 25\). True.

Assume \(2^k > k^2\) for some \(k \ge 5\). Then \(2^{k+1} = 2\cdot 2^k > 2k^2\).

\(2k^2 - (k + 1)^2 = k^2 - 2k - 1 = (k - 1)^2 - 2 > 0\) for \(k \ge 5\). So \(2k^2 > (k + 1)^2\).

Hence \(2^{k+1} > (k + 1)^2\). By induction, true for all \(n \ge 5\). \(\blacksquare\)

Recurrence relations and products

A sequence has \(u_1 = 3\) and \(u_{n+1} = 2u_n - 1\). Prove that \(u_n = 2^n + 1\).

The step uses the recurrence: \(u_{k+1} = 2u_k - 1\), and the assumption replaces \(u_k\).

Base: \(u_1 = 2 + 1 = 3\). True.

Assume \(u_k = 2^k + 1\).

\(u_{k+1} = 2(2^k + 1) - 1 = 2^{k+1} + 1\). True for \(k + 1\), so true for all \(n \in \mathbb{N}\) by induction. \(\blacksquare\)

Product notation: \(\displaystyle\prod_{r=1}^{n} a_r = a_1 a_2 \cdots a_n\). The step is \(\prod_{r=1}^{k+1} a_r = \left(\prod_{r=1}^{k} a_r\right) a_{k+1}\). For example, \(\prod_{r=2}^{n}\left(1 - \frac1r\right) = \frac1n\): the step is \(\frac1k\cdot\frac{k}{k + 1} = \frac{1}{k + 1}\).

Common errors: (1) assuming what you need to prove ("assume true for all \(n\)"); (2) not using the assumption at all; (3) forgetting the base case, or checking it at the wrong starting value; (4) writing the \(k + 1\) statement as if it were already known; (5) no conclusion sentence.

Why it works: if some \(n\) failed, take the smallest failing value. It isn't the base case, so the value before it is true, and the inductive step makes this one true. Contradiction. Induction is really the well-ordering of the natural numbers.

Practice

In the inductive step of a proof of \(\sum_{r=1}^{n} r^2 = \frac{n(n + 1)(2n + 1)}{6}\), the expression for \(\sum_{r=1}^{k+1} r^2\) is

  1. \(\frac{k(k + 1)(2k + 1)}{6} + k^2\)
  2. \(\frac{(k + 1)(k + 2)(2k + 3)}{6} + (k + 1)^2\)
  3. \(\frac{k(k + 1)(2k + 1)}{6} + (k + 1)^2\)
  4. \(\frac{k(k + 1)(2k + 1)}{6}\cdot(k + 1)^2\)

Sum to \(k + 1\) = (sum to \(k\), by assumption) + the \((k + 1)\)th term.

Assuming \(7^k - 1 = 6m\), the expression \(7^{k+1} - 1\) equals

  1. \(6(7m + 1)\)
  2. \(42m\)
  3. \(7(6m) - 1\)
  4. \(6m + 6\)

\(7^{k+1} - 1 = 7(6m + 1) - 1 = 42m + 6 = 6(7m + 1)\).

A "proof" shows that if \(P(k)\) is true then \(P(k + 1)\) is true, but never checks a base case. Then

  1. \(P(n)\) is true for all \(n\)
  2. \(P(n)\) is true for all \(n \ge k\)
  3. \(P(n)\) is false for all \(n\)
  4. nothing has been proved

Without a true starting point the chain never starts. Example: "\(n = n + 1\)" passes the step but is never true.

To prove \(n! > 2^n\) by induction, the base case should be

  1. \(n = 1\)
  2. \(n = 4\)
  3. \(n = 2\)
  4. \(n = 3\)

\(1! = 1 < 2\), \(2! = 2 < 4\), \(3! = 6 < 8\), \(4! = 24 > 16\). It's true from \(n = 4\).

Prove that \(\displaystyle\sum_{r=1}^{n} r = \frac{n(n + 1)}{2}\) for all \(n \in \mathbb{N}\).

Base \(n = 1\): \(1 = \frac{1\cdot 2}{2}\). [1]

Assume \(\sum_{r=1}^{k} r = \frac{k(k + 1)}{2}\). [1]

\(\sum_{r=1}^{k+1} r = \frac{k(k + 1)}{2} + (k + 1) = \frac{(k + 1)(k + 2)}{2}\). [1]

This is the result for \(n = k + 1\), so by induction it holds for all \(n \in \mathbb{N}\). [1]

Prove that \(3^{2n} - 1\) is divisible by 8 for all \(n \in \mathbb{N}\).

Base: \(9 - 1 = 8\). [1]

Assume \(3^{2k} - 1 = 8m\), so \(3^{2k} = 8m + 1\). [1]

\(3^{2(k+1)} - 1 = 9\cdot 3^{2k} - 1 = 9(8m + 1) - 1 = 72m + 8 = 8(9m + 1)\). [1]

Divisible by 8, so true for all \(n\) by induction. [1]

Prove that \(\displaystyle\sum_{r=1}^{n} \frac{1}{r(r + 1)} = \frac{n}{n + 1}\) for all \(n \in \mathbb{N}\).

Base \(n = 1\): \(\frac12 = \frac12\). [1]

Assume \(\sum_{r=1}^{k}\frac{1}{r(r + 1)} = \frac{k}{k + 1}\). [1]

\(\frac{k}{k + 1} + \frac{1}{(k + 1)(k + 2)} = \frac{k(k + 2) + 1}{(k + 1)(k + 2)} = \frac{(k + 1)^2}{(k + 1)(k + 2)} = \frac{k + 1}{k + 2}\). [1]

True for \(k + 1\); by induction true for all \(n\). [1]

Prove that \((1 + x)^n \ge 1 + nx\) for all \(n \in \mathbb{N}\) and all real \(x > -1\) (Bernoulli's inequality).

Base \(n = 1\): \(1 + x \ge 1 + x\). [1]

Assume \((1 + x)^k \ge 1 + kx\). Since \(1 + x > 0\), multiply: \((1 + x)^{k+1} \ge (1 + kx)(1 + x)\). [1]

\(= 1 + (k + 1)x + kx^2 \ge 1 + (k + 1)x\), since \(kx^2 \ge 0\). [1]

So true for \(k + 1\); true for all \(n\) by induction. [1]

Summary

  • Base case, "assume true for \(n = k\)", prove \(n = k + 1\) using it, conclusion sentence.
  • Sums: sum to \(k + 1\) = sum to \(k\) + next term.
  • Divisibility: write the assumption as \(= d\,m\), substitute, factor out \(d\).
  • Inequalities: use the assumption, then justify a second inequality for \(k \ge n_0\).
