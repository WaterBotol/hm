Statements and connectives

A statement (proposition) is a sentence that is either true or false, such as "7 is prime" or "every even number is a multiple of 4". A conjecture is a statement that hasn't been proved or disproved yet. Statements are joined with connectives:

ConnectiveSymbolTrue when
not \(P\)\(\neg P\)\(P\) is false
\(P\) and \(Q\)\(P \wedge Q\)both are true
\(P\) or \(Q\)\(P \vee Q\)at least one is true (inclusive or)
if \(P\) then \(Q\)\(P \Rightarrow Q\)every case except \(P\) true and \(Q\) false
\(P\) if and only if \(Q\)\(P \Leftrightarrow Q\)\(P\) and \(Q\) have the same truth value

An implication \(P \Rightarrow Q\) is only false when \(P\) is true and \(Q\) is false. "If \(x > 5\) then \(x > 2\)" is true even for \(x = 1\): a false hypothesis can't break an implication. Students often think \(P \Rightarrow Q\) is false whenever \(P\) is false.

Converse, inverse and contrapositive

Four related statements
\[ \begin{aligned} &\text{Implication:} && P \Rightarrow Q\\ &\text{Converse:} && Q \Rightarrow P\\ &\text{Inverse:} && \neg P \Rightarrow \neg Q\\ &\text{Contrapositive:} && \neg Q \Rightarrow \neg P \end{aligned} \]

An implication and its contrapositive are logically equivalent (always the same truth value). The converse and the inverse are equivalent to each other, but not to the original.

To prove \(P \Rightarrow Q\) you may prove the contrapositive \(\neg Q \Rightarrow \neg P\) instead. Proving the converse proves nothing about the original. "If \(n^2\) is even then \(n\) is even" is easiest via its contrapositive: "if \(n\) is odd then \(n^2\) is odd".

Consider "If a quadrilateral is a square, then its diagonals are equal". Write its converse and contrapositive, and state whether each is true.

Swap the parts for the converse. Swap and negate both for the contrapositive. The contrapositive always matches the original's truth value, so only the converse needs separate checking.

Converse: "If a quadrilateral's diagonals are equal, then it is a square". False: a non-square rectangle has equal diagonals.

Contrapositive: "If a quadrilateral's diagonals are not equal, then it is not a square". True, because the original is true.

Necessary, sufficient, and "if and only if"

In \(P \Rightarrow Q\), \(P\) is sufficient for \(Q\) (knowing \(P\) is enough to guarantee \(Q\)), and \(Q\) is necessary for \(P\) (you can't have \(P\) without \(Q\)).

Equivalence
\[ P \Leftrightarrow Q \quad\text{means}\quad (P \Rightarrow Q) \wedge (Q \Rightarrow P) \]

\(P\) is necessary and sufficient for \(Q\). To prove an "if and only if" statement, prove both directions.

For an integer \(n\): is "\(n\) is divisible by 6" necessary, sufficient, both or neither for "\(n\) is even"?

Test each direction. If divisible by 6 always gives even, it's sufficient. If even always gives divisible by 6, it would also be necessary.

Divisible by 6 \(\Rightarrow\) \(n = 6k = 2(3k)\), so even. True: sufficient.

Even \(\Rightarrow\) divisible by 6 fails for \(n = 4\). So it's sufficient but not necessary.

Quantifiers and their negations

For all, there exists
\[ \forall x\ P(x):\ \text{"for every } x,\ P(x)\text{"} \qquad \exists x\ P(x):\ \text{"there is at least one } x \text{ with } P(x)\text{"} \] \[ \neg\big(\forall x\ P(x)\big) \equiv \exists x\ \neg P(x) \qquad \neg\big(\exists x\ P(x)\big) \equiv \forall x\ \neg P(x) \]

Negating swaps the quantifier and negates the inside. The negation of "all swans are white" is "there is a swan that is not white", not "no swans are white".

One counterexample disproves a "for all" statement. No number of examples proves it. A "there exists" statement is proved by one example, and disproved only by a general argument.

De Morgan's laws trip people up when negating compound statements: \(\neg(P \wedge Q) \equiv \neg P \vee \neg Q\) and \(\neg(P \vee Q) \equiv \neg P \wedge \neg Q\). So the negation of "\(x > 0\) and \(x < 1\)" is "\(x \le 0\) or \(x \ge 1\)". The negation of \(P \Rightarrow Q\) is \(P \wedge \neg Q\), not another implication.

Conjecture: "For all natural numbers \(n\), \(n^2 + n + 41\) is prime." Write the negation and decide which is true.

The negation swaps "for all" with "there exists" and negates "is prime". Since a single counterexample is enough, try values that make the expression factorise. At \(n = 40\) the expression becomes \(40\cdot 41 + 41\).

Negation: "There exists a natural number \(n\) such that \(n^2 + n + 41\) is not prime."

Take \(n = 40\): \(40^2 + 40 + 41 = 40\cdot 41 + 41 = 41^2 = 1681\), which is not prime.

So the negation is true and the conjecture is false. (It works for \(n = 0, 1, \dots, 39\), which shows why checking examples is never a proof.)

Truth tables

A truth table lists every combination of truth values. Two statements are equivalent when their columns match in every row.

\(P\)\(Q\)\(P \Rightarrow Q\)\(\neg Q \Rightarrow \neg P\)\(Q \Rightarrow P\)
TTTTT
TFFFT
FTTTF
FFTTT

The implication and contrapositive columns agree in every row; the converse doesn't.

VCAA multiple-choice questions often give a statement and ask which option is its contrapositive, converse or negation, or which is logically equivalent. Write the structure with \(P\) and \(Q\) first, then match. Watch "not all" (\(\exists\ \neg\)) versus "none" (\(\forall\ \neg\)).

Practice

The contrapositive of "if \(x^2 = 4\) then \(x = 2\)" is

  1. if \(x = 2\) then \(x^2 = 4\)
  2. if \(x^2 \ne 4\) then \(x \ne 2\)
  3. if \(x \ne 2\) then \(x^2 \ne 4\)
  4. \(x^2 = 4\) and \(x \ne 2\)

Swap and negate both parts. (A is the converse, B the inverse, D the negation.) Here the original and contrapositive are both false: \(x = -2\).

The negation of "every student in the class passed" is

  1. every student in the class failed
  2. at least one student in the class did not pass
  3. no student in the class passed
  4. at least one student in the class passed

\(\neg(\forall x\ P(x)) \equiv \exists x\ \neg P(x)\). "Not all passed" means "some didn't".

The statement \(P \Rightarrow Q\) is false only when

  1. \(P\) is false and \(Q\) is true
  2. both are false
  3. both are true
  4. \(P\) is true and \(Q\) is false

An implication only breaks when the hypothesis holds but the conclusion doesn't.

For real \(x\), the condition \(x > 3\) is ____ for \(x^2 > 9\).

  1. sufficient but not necessary
  2. necessary but not sufficient
  3. necessary and sufficient
  4. neither necessary nor sufficient

\(x > 3 \Rightarrow x^2 > 9\) (sufficient), but \(x = -4\) gives \(x^2 > 9\) without \(x > 3\) (not necessary).

The negation of "\(\exists x \in \mathbb{R}\) such that \(x^2 < 0\)" is

  1. \(\exists x \in \mathbb{R}\) such that \(x^2 \ge 0\)
  2. \(\forall x \in \mathbb{R},\ x^2 < 0\)
  3. \(\forall x \in \mathbb{R},\ x^2 \ge 0\)
  4. \(\forall x \in \mathbb{R},\ x^2 > 0\)

Swap \(\exists\) to \(\forall\) and negate \(<\) to \(\ge\) (not \(>\): zero counts).

Which statement is logically equivalent to "if a function is differentiable at \(a\), then it is continuous at \(a\)"?

  1. If a function is continuous at \(a\), then it is differentiable at \(a\).
  2. If a function is not continuous at \(a\), then it is not differentiable at \(a\).
  3. If a function is not differentiable at \(a\), then it is not continuous at \(a\).
  4. A function is differentiable at \(a\) and not continuous at \(a\).

Only the contrapositive is equivalent. A is the converse (false: \(|x|\) at 0), C the inverse, D the negation.

Write the converse, inverse and contrapositive of "if \(n\) is a multiple of 4, then \(n\) is even", and state which are true.

Converse: if \(n\) is even then \(n\) is a multiple of 4 (false, \(n = 6\)). Inverse: if \(n\) is not a multiple of 4 then \(n\) is not even (false, \(n = 6\)). [1]

Contrapositive: if \(n\) is not even then \(n\) is not a multiple of 4 (true, like the original). [1]

Disprove: "for all real \(a\) and \(b\), \(\sqrt{a^2 + b^2} = a + b\)".

A single counterexample suffices. [1]

\(a = 3, b = 4\): \(\sqrt{25} = 5 \ne 7\). So the statement is false. [1]

Let \(P\): "\(m\) and \(n\) are both odd" and \(Q\): "\(mn\) is odd", for integers \(m, n\). Show that \(P \Leftrightarrow Q\).

(\(\Rightarrow\)) \(m = 2a + 1,\ n = 2b + 1\): \(mn = 4ab + 2a + 2b + 1 = 2(2ab + a + b) + 1\), odd. [1]

(\(\Leftarrow\)) Contrapositive: if \(m\) or \(n\) is even, say \(m = 2a\), then \(mn = 2(an)\) is even. So \(mn\) odd forces both odd. [1]

Both directions hold, so \(P \Leftrightarrow Q\). [1]

Summary

  • \(P \Rightarrow Q\) is false only when \(P\) is true and \(Q\) is false.
  • Contrapositive \(\neg Q \Rightarrow \neg P\) is equivalent to \(P \Rightarrow Q\); the converse is not.
  • \(P\) sufficient for \(Q\), \(Q\) necessary for \(P\); "iff" needs both directions.
  • Negating swaps \(\forall \leftrightarrow \exists\) and negates the inside; one counterexample kills a "for all".
