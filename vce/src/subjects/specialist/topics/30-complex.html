Cartesian form

A complex number is \(z = a + bi\) where \(a, b \in \mathbb{R}\) and \(i^2 = -1\). \(\operatorname{Re}(z) = a\) and \(\operatorname{Im}(z) = b\) (the imaginary part is the real number \(b\), not \(bi\)).

Arithmetic
\[ (a + bi)(c + di) = (ac - bd) + (ad + bc)i \qquad \bar z = a - bi \qquad z\bar z = a^2 + b^2 = |z|^2 \] \[ \frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{c^2 + d^2} \]

Divide by multiplying top and bottom by the conjugate of the denominator.

Express \(\dfrac{3 + 4i}{1 - 2i}\) in the form \(a + bi\).

Multiply numerator and denominator by \(1 + 2i\), the conjugate of the denominator, so the denominator becomes the real number \(1^2 + 2^2\).

\(\dfrac{(3 + 4i)(1 + 2i)}{(1 - 2i)(1 + 2i)} = \dfrac{3 + 6i + 4i + 8i^2}{5} = \dfrac{-5 + 10i}{5}\).

\(= -1 + 2i\).

Conjugate properties
\[ \overline{z + w} = \bar z + \bar w \qquad \overline{zw} = \bar z\,\bar w \qquad z + \bar z = 2\operatorname{Re}(z) \qquad z - \bar z = 2i\operatorname{Im}(z) \]

Modulus, argument and polar form

On the Argand diagram, \(z = a + bi\) is the point \((a, b)\). Its distance from the origin is the modulus \(|z| = r = \sqrt{a^2 + b^2}\), and the angle from the positive real axis is the argument. The principal argument \(\operatorname{Arg}(z) \in (-\pi, \pi]\).

Polar form
\[ z = r(\cos\theta + i\sin\theta) = r\operatorname{cis}\theta \qquad a = r\cos\theta,\ b = r\sin\theta \]

Write \(z = -\sqrt3 + i\) in polar form using the principal argument.

Find \(r\), then the reference angle from \(\tan^{-1}\left|\frac ba\right|\), then place it in the right quadrant from the signs of \(a\) and \(b\). Here \(a < 0\), \(b > 0\): quadrant 2.

\(r = \sqrt{3 + 1} = 2\). Reference angle \(\tan^{-1}\frac{1}{\sqrt3} = \frac\pi6\).

Quadrant 2: \(\theta = \pi - \frac\pi6 = \frac{5\pi}{6}\). So \(z = 2\operatorname{cis}\frac{5\pi}{6}\).

\(\tan^{-1}\frac{b}{a}\) only gives the right argument in quadrants 1 and 4. For \(z = -1 - i\), \(\tan^{-1}\frac{-1}{-1} = \frac\pi4\) is wrong; the principal argument is \(-\frac{3\pi}{4}\). Always sketch the point.

Multiplying and dividing in polar form

Moduli multiply, arguments add
\[ r_1\operatorname{cis}\theta_1 \times r_2\operatorname{cis}\theta_2 = r_1r_2\operatorname{cis}(\theta_1 + \theta_2) \qquad \frac{r_1\operatorname{cis}\theta_1}{r_2\operatorname{cis}\theta_2} = \frac{r_1}{r_2}\operatorname{cis}(\theta_1 - \theta_2) \]

Geometrically, multiplying by \(r\operatorname{cis}\theta\) dilates by factor \(r\) and rotates anticlockwise by \(\theta\). Multiplying by \(i = \operatorname{cis}\frac\pi2\) rotates by \(90°\).

Given \(u = 4\operatorname{cis}\frac{5\pi}{6}\) and \(v = 2\operatorname{cis}\left(-\frac{\pi}{3}\right)\), find \(\dfrac{u}{v}\) in polar form with the principal argument.

Divide the moduli and subtract the arguments, then adjust by \(2\pi\) if the result is outside \((-\pi, \pi]\).

\(\frac{u}{v} = 2\operatorname{cis}\left(\frac{5\pi}{6} + \frac\pi3\right) = 2\operatorname{cis}\frac{7\pi}{6}\).

\(\frac{7\pi}{6} - 2\pi = -\frac{5\pi}{6}\), so \(\dfrac{u}{v} = 2\operatorname{cis}\left(-\frac{5\pi}{6}\right)\).

Useful facts
\[ |zw| = |z||w| \qquad \left|\frac zw\right| = \frac{|z|}{|w|} \qquad \bar z = r\operatorname{cis}(-\theta) \qquad \frac1z = \frac1r\operatorname{cis}(-\theta) \]

Exam 1: give exact moduli and principal arguments. "Express in polar form" means \(r\operatorname{cis}\theta\) with \(\theta \in (-\pi, \pi]\). Powers of \(i\) cycle every 4: \(i^{4k + m} = i^m\).

Practice

\(\operatorname{Im}\big((2 - 3i)^2\big)\) is

  1. \(-12i\)
  2. \(-12\)
  3. \(-5\)
  4. \(13\)

\((2 - 3i)^2 = 4 - 12i + 9i^2 = -5 - 12i\). The imaginary part is the real number \(-12\).

The principal argument of \(-2 - 2i\) is

  1. \(\frac{\pi}{4}\)
  2. \(\frac{5\pi}{4}\)
  3. \(-\frac{\pi}{4}\)
  4. \(-\frac{3\pi}{4}\)

Quadrant 3; \(\frac{5\pi}{4}\) is outside \((-\pi, \pi]\), so subtract \(2\pi\).

\(i^{2027}\) equals

  1. \(-i\)
  2. \(i\)
  3. \(-1\)
  4. \(1\)

\(2027 = 4\times 506 + 3\), so \(i^{2027} = i^3 = -i\).

If \(z = 3\operatorname{cis}\frac{\pi}{5}\), then \(\dfrac{1}{\bar z}\) is

  1. \(3\operatorname{cis}\frac{\pi}{5}\)
  2. \(\frac13\operatorname{cis}\left(-\frac{\pi}{5}\right)\)
  3. \(\frac13\operatorname{cis}\frac{\pi}{5}\)
  4. \(-\frac13\operatorname{cis}\frac{\pi}{5}\)

\(\bar z = 3\operatorname{cis}(-\frac\pi5)\); reciprocal: \(\frac13\operatorname{cis}\frac\pi5\).

Multiplying a complex number \(z\) by \(-i\) corresponds to

  1. a rotation of \(\frac\pi2\) anticlockwise
  2. a rotation of \(\frac\pi2\) clockwise
  3. a reflection in the real axis
  4. a rotation of \(\pi\)

\(-i = \operatorname{cis}(-\frac\pi2)\): modulus 1, argument \(-\frac\pi2\).

Find real \(a, b\) such that \(\dfrac{5}{2 + i} = a + bi\).

\(\dfrac{5(2 - i)}{(2 + i)(2 - i)} = \dfrac{5(2 - i)}{5}\). [1]

\(= 2 - i\), so \(a = 2,\ b = -1\). [1]

Let \(u = 1 + \sqrt3 i\) and \(v = 1 - i\). Find \(uv\) in polar form, and hence find the exact value of \(\cos\frac{\pi}{12}\).

\(u = 2\operatorname{cis}\frac\pi3\), \(v = \sqrt2\operatorname{cis}(-\frac\pi4)\), so \(uv = 2\sqrt2\operatorname{cis}\frac{\pi}{12}\). [1]

Cartesian: \(uv = (1 + \sqrt3 i)(1 - i) = (1 + \sqrt3) + (\sqrt3 - 1)i\). [1]

Real parts: \(2\sqrt2\cos\frac\pi{12} = 1 + \sqrt3 \Rightarrow \cos\frac\pi{12} = \frac{1 + \sqrt3}{2\sqrt2} = \frac{\sqrt2 + \sqrt6}{4}\). [1]

Solve \(z^2 = 3 - 4i\) for \(z \in \mathbb{C}\) in Cartesian form.

Let \(z = x + yi\): \(x^2 - y^2 = 3\) and \(2xy = -4\). [1]

Also \(|z|^2 = |3 - 4i| = 5\), so \(x^2 + y^2 = 5\). Adding: \(x^2 = 4\), \(y^2 = 1\). [1]

\(xy = -2\) < 0, so \(z = 2 - i\) or \(z = -2 + i\). [1]

Summary

  • Divide by multiplying by the conjugate; \(z\bar z = |z|^2\).
  • \(r = \sqrt{a^2 + b^2}\); find the argument from a sketch; principal argument in \((-\pi, \pi]\).
  • Polar: multiply moduli and add arguments; divide moduli and subtract arguments.
