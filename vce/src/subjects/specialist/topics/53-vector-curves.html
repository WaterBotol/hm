From vector form to Cartesian

\(\underset{\sim}{r}(t) = x(t)\underset{\sim}{i} + y(t)\underset{\sim}{j}\) traces a path as \(t\) varies. To get the Cartesian equation, eliminate \(t\), then use the domain of \(t\) to restrict \(x\) and \(y\).

Trig eliminations
\[ \cos^2 t + \sin^2 t = 1 \qquad \sec^2 t - \tan^2 t = 1 \]

Find the Cartesian equation of \(\underset{\sim}{r}(t) = (2 + 3\cos t)\underset{\sim}{i} + (2\sin t - 1)\underset{\sim}{j}\), \(t \in [0, 2\pi]\), and describe the path.

Isolate \(\cos t\) and \(\sin t\), then square and add.

\(\cos t = \frac{x - 2}{3}\), \(\sin t = \frac{y + 1}{2}\).

\(\dfrac{(x - 2)^2}{9} + \dfrac{(y + 1)^2}{4} = 1\): an ellipse centred at \((2, -1)\), traced once anticlockwise starting from \((5, -1)\).

Find the Cartesian equation of \(x = 2\sec t\), \(y = 3\tan t\), \(t \in \left(-\frac\pi2, \frac\pi2\right)\).

Use \(\sec^2 t - \tan^2 t = 1\). On this domain \(\sec t \ge 1\), which selects one branch.

\(\frac{x^2}{4} - \frac{y^2}{9} = \sec^2 t - \tan^2 t = 1\).

\(\dfrac{x^2}{4} - \dfrac{y^2}{9} = 1\), \(x \ge 2\) (the right branch only).

Find the Cartesian equation of \(\underset{\sim}{r}(t) = t^2\underset{\sim}{i} + 2t^2\underset{\sim}{j}\), \(t \in \mathbb{R}\).

\(y = 2x\), but \(x = t^2 \ge 0\).

\(y = 2x\), \(x \ge 0\): a ray, not a whole line.

Conics
\[ \frac{(x - h)^2}{a^2} + \frac{(y - k)^2}{b^2} = 1 \ \text{(ellipse)} \qquad \frac{(x - h)^2}{a^2} - \frac{(y - k)^2}{b^2} = 1 \ \text{(hyperbola, asymptotes } y - k = \pm\tfrac ba(x - h)) \]

Curves in 3D

\(\underset{\sim}{r}(t) = x(t)\underset{\sim}{i} + y(t)\underset{\sim}{j} + z(t)\underset{\sim}{k}\). Example: \(\underset{\sim}{r}(t) = \cos t\,\underset{\sim}{i} + \sin t\,\underset{\sim}{j} + t\,\underset{\sim}{k}\) is a helix: a circle in \(x\)–\(y\) while rising steadily in \(z\).

Where does the helix \(\underset{\sim}{r}(t) = \cos t\,\underset{\sim}{i} + \sin t\,\underset{\sim}{j} + t\,\underset{\sim}{k}\), \(t \ge 0\), first meet the plane \(z = \pi\)?

Set \(z = t = \pi\).

\(\underset{\sim}{r}(\pi) = -\underset{\sim}{i} + \pi\underset{\sim}{k}\), the point \((-1, 0, \pi)\).

Squaring to eliminate the parameter can add points that are never reached. Always state the restricted domain/range from the parameter's domain. Also, \(\cos t\) and \(\sin t\) with coefficient \(\omega t\) still give the same circle, just traced faster.

Exam 2 typically pairs this with vector calculus: "find the Cartesian equation of the path, and state its domain", then velocity and speed. Sketches need the starting point and direction of motion shown with an arrow.

Practice

The path of \(\underset{\sim}{r}(t) = 4\cos t\,\underset{\sim}{i} + 4\sin t\,\underset{\sim}{j}\) is a circle of radius

  1. 16
  2. 2
  3. 8
  4. 4

\(x^2 + y^2 = 16\).

The Cartesian equation of \(x = t + 1\), \(y = t^2\) is

  1. \(y = (x - 1)^2\)
  2. \(y = x^2 + 1\)
  3. \(y = (x + 1)^2\)
  4. \(x = y^2 + 1\)

\(t = x - 1\).

The curve \(x = \cos(2t)\), \(y = \cos t\), \(t \in \mathbb{R}\), has Cartesian equation

  1. \(x = y^2\)
  2. \(x^2 + y^2 = 1\)
  3. \(x = 2y^2 - 1\), \(-1 \le y \le 1\)
  4. \(x = 1 - 2y^2\)

\(\cos 2t = 2\cos^2 t - 1\); \(y = \cos t\) restricts \(y\) to \([-1, 1]\).

\(\underset{\sim}{r}(t) = \sin t\,\underset{\sim}{i} + \sin^2 t\,\underset{\sim}{j}\) traces

  1. the whole parabola \(y = x^2\)
  2. the part of \(y = x^2\) with \(-1 \le x \le 1\), back and forth
  3. a circle
  4. the line \(y = x\)

\(x = \sin t \in [-1, 1]\), oscillating.

Find the Cartesian equation of \(\underset{\sim}{r}(t) = 3\cos t\,\underset{\sim}{i} + 5\sin t\,\underset{\sim}{j}\).

\(\cos t = \frac x3\), \(\sin t = \frac y5\). [1]

\(\frac{x^2}{9} + \frac{y^2}{25} = 1\). [1]

Find the Cartesian equation and asymptotes of \(x = 1 + \tan t\), \(y = 2\sec t\), \(t \in \left(-\frac\pi2, \frac\pi2\right)\).

\(\frac{y^2}{4} - (x - 1)^2 = \sec^2 t - \tan^2 t = 1\). [1]

\(\sec t \ge 1\) gives \(y \ge 2\): the upper branch. [1]

Asymptotes \(y = \pm2(x - 1)\). [1]

Find the Cartesian equation of \(\underset{\sim}{r}(t) = e^t\underset{\sim}{i} + e^{-2t}\underset{\sim}{j}\), \(t \in \mathbb{R}\), with its domain.

\(y = (e^t)^{-2} = \frac{1}{x^2}\). [1]

\(x = e^t > 0\), so \(y = \frac{1}{x^2}\), \(x > 0\). [1]

Summary

  • Eliminate \(t\); restrict \(x\), \(y\) from the parameter's domain.
  • \(\cos^2 + \sin^2 = 1\) → circles/ellipses; \(\sec^2 - \tan^2 = 1\) → hyperbolas.
  • Show start point and direction on sketches; 3D curves like helices combine a circle with linear motion.
