Standard forms

\(f(x)\)\(\int f(x)\,dx\)
\(\dfrac{1}{x}\)\(\log_e|x| + c\)
\(\dfrac{1}{ax + b}\)\(\dfrac1a\log_e|ax + b| + c\)
\(\dfrac{1}{\sqrt{a^2 - x^2}}\)\(\sin^{-1}\!\left(\dfrac{x}{a}\right) + c\)
\(\dfrac{-1}{\sqrt{a^2 - x^2}}\)\(\cos^{-1}\!\left(\dfrac{x}{a}\right) + c\)
\(\dfrac{a}{a^2 + x^2}\)\(\tan^{-1}\!\left(\dfrac{x}{a}\right) + c\)
\(\sec^2(ax)\)\(\dfrac1a\tan(ax) + c\)

Find (a) \(\displaystyle\int \frac{1}{\sqrt{9 - x^2}}dx\), (b) \(\displaystyle\int \frac{1}{4 + x^2}dx\), (c) \(\displaystyle\int \frac{1}{\sqrt{1 - 4x^2}}dx\).

Match each to a standard form. For (b), the sheet form has \(a\) in the numerator, so adjust the constant. For (c), factor out the 4 to get \(a^2 - x^2\).

(a) \(\sin^{-1}\frac{x}{3} + c\).

(b) \(\frac12\int\frac{2}{4 + x^2}dx = \frac12\tan^{-1}\frac{x}{2} + c\).

(c) \(\sqrt{1 - 4x^2} = 2\sqrt{\frac14 - x^2}\), so \(\frac12\sin^{-1}\frac{x}{1/2} + c = \frac12\sin^{-1}(2x) + c\).

Substitution \(u = g(x)\)

Look for a function and (a multiple of) its derivative: \(\int f(g(x))\,g'(x)\,dx = \int f(u)\,du\).

Find \(\displaystyle\int x\sqrt{x^2 + 3}\,dx\).

The inside of the root, \(x^2 + 3\), has derivative \(2x\), and \(x\) is outside. Let \(u = x^2 + 3\), so \(x\,dx = \frac12 du\).

\(u = x^2 + 3,\ \frac{du}{dx} = 2x\).

\(\int \frac12 u^{1/2}\,du = \frac13 u^{3/2} + c\).

\(= \frac13(x^2 + 3)^{3/2} + c\).

Evaluate \(\displaystyle\int_0^{\pi/2} \sin x\cos^3 x\,dx\).

Let \(u = \cos x\), \(du = -\sin x\,dx\). Change the \(x\)-terminals to \(u\)-terminals so you never have to substitute back.

\(x = 0 \to u = 1\); \(x = \frac\pi2 \to u = 0\).

\(\int_1^0 -u^3\,du = \int_0^1 u^3\,du\).

\(= \left[\frac{u^4}{4}\right]_0^1 = \frac14\).

Find \(\displaystyle\int x\sqrt{x - 1}\,dx\) using \(u = x - 1\).

Here the \(x\) outside isn't a derivative of the inside. Instead express it in \(u\): \(x = u + 1\), then expand and integrate powers.

\(\int (u + 1)u^{1/2}\,du = \int (u^{3/2} + u^{1/2})\,du\).

\(= \frac25 u^{5/2} + \frac23 u^{3/2} + c = \frac25(x - 1)^{5/2} + \frac23(x - 1)^{3/2} + c\).

Trigonometric powers

Identities for integration
\[ \sin^2(ax) = \tfrac12\big(1 - \cos(2ax)\big) \qquad \cos^2(ax) = \tfrac12\big(1 + \cos(2ax)\big) \]

Even powers: use these identities. Odd powers: split off one factor and use \(\sin^2 + \cos^2 = 1\), then substitute.

Evaluate \(\displaystyle\int_0^{\pi} \sin^2 x\,dx\).

Replace \(\sin^2 x\) with \(\frac12(1 - \cos 2x)\), which integrates directly.

\(\frac12\int_0^\pi (1 - \cos 2x)\,dx = \frac12\left[x - \frac12\sin 2x\right]_0^\pi\).

\(= \frac{\pi}{2}\).

Find \(\displaystyle\int \cos^3 x\,dx\).

Write \(\cos^3 x = \cos x(1 - \sin^2 x)\), then \(u = \sin x\), \(du = \cos x\,dx\).

\(\int (1 - u^2)\,du = u - \frac{u^3}{3} + c\).

\(= \sin x - \frac13\sin^3 x + c\).

Partial fractions

Find \(\displaystyle\int \frac{5x + 1}{(x - 1)(x + 2)}dx\).

From partial fractions, this is \(\frac{2}{x - 1} + \frac{3}{x + 2}\). Each integrates to a log.

\(\int\left(\frac{2}{x - 1} + \frac{3}{x + 2}\right)dx\).

\(= 2\log_e|x - 1| + 3\log_e|x + 2| + c\).

Strategy: (1) standard form? (2) function × its derivative → substitution; (3) power of sin/cos → identity or split; (4) rational → divide, then partial fractions or inverse tan/log forms; (5) product of unrelated functions → integration by parts. In Exam 2, CAS does it, but VCAA still asks you to "show" a substitution step.

\(\int\frac{1}{x^2 + 4}dx\) is an arctan, but \(\int\frac{x}{x^2 + 4}dx = \frac12\log_e(x^2 + 4)\) is a log (numerator is a multiple of the denominator's derivative). And forgetting to change terminals in a substitution gives the wrong value.

Practice

\(\displaystyle\int \frac{3}{9 + x^2}dx\) is

  1. \(3\tan^{-1}\frac{x}{3} + c\)
  2. \(\tan^{-1}\frac{x}{3} + c\)
  3. \(\frac13\tan^{-1}\frac{x}{3} + c\)
  4. \(\tan^{-1}(3x) + c\)

Exactly the form \(\frac{a}{a^2 + x^2}\) with \(a = 3\).

Using \(u = x^2 + 1\), \(\displaystyle\int_0^1 \frac{x}{x^2 + 1}dx\) becomes

  1. \(\int_0^1 \frac1u\,du\)
  2. \(2\int_1^2 \frac1u\,du\)
  3. \(\int_1^2 \frac1u\,du\)
  4. \(\frac12\int_1^2 \frac1u\,du\)

\(x\,dx = \frac12 du\); terminals \(0 \to 1\), \(1 \to 2\).

\(\displaystyle\int \cos^2(3x)\,dx\) is

  1. \(\frac{x}{2} + \frac{1}{12}\sin(6x) + c\)
  2. \(\frac13\cos^3(3x) + c\)
  3. \(\frac{x}{2} + \frac16\sin(6x) + c\)
  4. \(\frac{x}{2} - \frac{1}{12}\sin(6x) + c\)

\(\frac12\int(1 + \cos 6x)dx = \frac x2 + \frac{1}{12}\sin 6x + c\).

\(\displaystyle\int_0^{1/2} \frac{1}{\sqrt{1 - x^2}}dx\) equals

  1. \(\frac{\pi}{3}\)
  2. \(\frac12\)
  3. \(\frac{\pi}{6}\)
  4. \(\frac{\pi}{4}\)

\(\sin^{-1}\frac12 - \sin^{-1}0 = \frac\pi6\).

Using a suitable substitution, \(\displaystyle\int_1^{e} \frac{(\log_e x)^2}{x}dx\) equals

  1. \(1\)
  2. \(\frac13\)
  3. \(\frac{e^3}{3}\)
  4. \(\frac12\)

\(u = \log_e x\), \(du = \frac{dx}{x}\): \(\int_0^1 u^2\,du = \frac13\).

Find \(\displaystyle\int \frac{2x}{(x^2 - 5)^3}dx\).

\(u = x^2 - 5\): \(\int u^{-3}\,du = -\frac{1}{2u^2} + c\). [1]

\(= -\dfrac{1}{2(x^2 - 5)^2} + c\). [1]

Evaluate \(\displaystyle\int_0^{\pi/4} \tan x\,dx\) exactly.

\(\tan x = \frac{\sin x}{\cos x}\); \(u = \cos x\), \(du = -\sin x\,dx\). [1]

\(\int_1^{1/\sqrt2} -\frac1u\,du = \left[-\log_e u\right]_1^{1/\sqrt2}\). [1]

\(= -\log_e\frac{1}{\sqrt2} = \frac12\log_e 2\). [1]

Use the substitution \(u = 2x + 1\) to evaluate \(\displaystyle\int_0^4 \frac{x}{\sqrt{2x + 1}}dx\).

\(x = \frac{u - 1}{2}\), \(dx = \frac12 du\); terminals \(1\) to \(9\). [1]

\(\int_1^9 \frac{u - 1}{2\sqrt u}\cdot\frac12 du = \frac14\int_1^9 (u^{1/2} - u^{-1/2})du\). [1]

\(= \frac14\left[\frac23 u^{3/2} - 2u^{1/2}\right]_1^9 = \frac14\left[(18 - 6) - (\frac23 - 2)\right]\). [1]

\(= \frac14\cdot\frac{40}{3} = \frac{10}{3}\). [1]

Summary

  • \(\frac1x \to \log_e|x|\); \(\frac{1}{\sqrt{a^2 - x^2}} \to \sin^{-1}\frac xa\); \(\frac{a}{a^2 + x^2} \to \tan^{-1}\frac xa\).
  • Substitution: \(u\) = the inside function; change terminals for definite integrals.
  • Even trig powers → double-angle identities; odd powers → split one off and substitute.
  • Rational functions → divide, partial fractions, logs and arctans.
