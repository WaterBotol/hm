Implicit differentiation

When a relation mixes \(x\) and \(y\), differentiate every term with respect to \(x\), treating \(y\) as a function of \(x\). Each \(y\) term picks up a factor \(\frac{dy}{dx}\) from the chain rule.

Key rules
\[ \frac{d}{dx}\big(y^n\big) = ny^{n-1}\frac{dy}{dx} \qquad \frac{d}{dx}(xy) = y + x\frac{dy}{dx} \qquad \frac{d}{dx}\big(f(y)\big) = f'(y)\frac{dy}{dx} \]

Find the equation of the tangent to \(x^2 + y^2 = 25\) at \((3, -4)\).

Differentiate both sides, solve for \(\frac{dy}{dx}\), substitute the point, then use \(y - y_1 = m(x - x_1)\).

\(2x + 2y\frac{dy}{dx} = 0 \Rightarrow \frac{dy}{dx} = -\frac{x}{y}\).

At \((3, -4)\): \(m = -\frac{3}{-4} = \frac34\).

\(y + 4 = \frac34(x - 3)\), i.e. \(y = \frac34 x - \frac{25}{4}\). (Perpendicular to the radius, gradient \(-\frac43\), as expected.)

Find \(\frac{dy}{dx}\) for \(3xy^2 = x + y\).

The left side is a product of \(3x\) and \(y^2\): use the product rule, with the chain rule on \(y^2\). Then collect the \(\frac{dy}{dx}\) terms.

\(3y^2 + 3x\cdot 2y\frac{dy}{dx} = 1 + \frac{dy}{dx}\).

\(\frac{dy}{dx}(6xy - 1) = 1 - 3y^2\).

\(\dfrac{dy}{dx} = \dfrac{1 - 3y^2}{6xy - 1}\).

Find the points on \(x^2 + xy + y^2 = 3\) where the tangent is horizontal.

Horizontal tangent: numerator of \(\frac{dy}{dx}\) is zero (and the denominator isn't). Use that condition together with the original equation.

\(2x + y + x\frac{dy}{dx} + 2y\frac{dy}{dx} = 0 \Rightarrow \frac{dy}{dx} = -\dfrac{2x + y}{x + 2y}\).

Horizontal: \(y = -2x\). Substitute: \(x^2 - 2x^2 + 4x^2 = 3 \Rightarrow x^2 = 1\).

Points \((1, -2)\) and \((-1, 2)\). (Vertical tangents would come from \(x + 2y = 0\): \((2, -1)\) and \((-2, 1)\).)

Differentiate constants to 0 and don't forget the \(\frac{dy}{dx}\) on every \(y\) term. The most common lost mark: \(\frac{d}{dx}(xy) = x\frac{dy}{dx}\) (missing the \(+y\)).

For \(x^2 + y^2 = 25\), express \(\frac{d^2y}{dx^2}\) in terms of \(y\).

Differentiate \(\frac{dy}{dx} = -\frac{x}{y}\) with the quotient rule, substitute \(\frac{dy}{dx}\) back in, and simplify using the original equation.

\(\frac{d^2y}{dx^2} = -\dfrac{y - x\frac{dy}{dx}}{y^2} = -\dfrac{y + \frac{x^2}{y}}{y^2} = -\dfrac{y^2 + x^2}{y^3}\).

\(= -\dfrac{25}{y^3}\): negative on the top half (concave down), positive on the bottom half.

Related rates

When quantities change with time, link their rates with the chain rule: \(\frac{dV}{dt} = \frac{dV}{dh}\cdot\frac{dh}{dt}\).

  1. Name the variables and write the given and wanted rates with units.
  2. Find an equation linking the variables (eliminate extra variables using geometry, like similar triangles).
  3. Differentiate, substitute the instant's values after differentiating.

Water flows at 2 m³/min into an inverted cone with radius 3 m and height 6 m. How fast is the depth rising when the water is 4 m deep?

Similar triangles give \(r = \frac{h}{2}\), so the volume is a function of \(h\) alone. Then \(\frac{dh}{dt} = \frac{dV/dt}{dV/dh}\).

\(r = \frac{h}{2}\): \(V = \frac13\pi\frac{h^2}{4}h = \frac{\pi h^3}{12}\).

\(\frac{dV}{dh} = \frac{\pi h^2}{4} = 4\pi\) at \(h = 4\).

\(\frac{dh}{dt} = \frac{2}{4\pi} = \frac{1}{2\pi} \approx 0.159\) m/min.

A 5 m ladder slides down a wall. Its foot moves away at 0.3 m/s. How fast is the top falling when the foot is 3 m from the wall?

Pythagoras links the foot distance \(x\) and top height \(y\). Differentiate with respect to time.

\(x^2 + y^2 = 25 \Rightarrow 2x\frac{dx}{dt} + 2y\frac{dy}{dt} = 0\).

At \(x = 3\), \(y = 4\): \(\frac{dy}{dt} = -\frac{3(0.3)}{4} = -0.225\). The top falls at 0.225 m/s.

Give units and a sign interpretation ("decreasing at 0.225 m/s"). Never substitute the instantaneous value (like \(h = 4\)) before differentiating, or the variable becomes a constant.

Practice

If \(x^3 + y^3 = 9\), then \(\frac{dy}{dx}\) is

  1. \(-\frac{y^2}{x^2}\)
  2. \(\frac{x^2}{y^2}\)
  3. \(-\frac{x^2}{y^2}\)
  4. \(-\frac{3x^2}{y^2}\)

\(3x^2 + 3y^2y' = 0\).

\(\dfrac{d}{dx}\big(x^2y\big)\) is

  1. \(2xy + x^2\frac{dy}{dx}\)
  2. \(2x\frac{dy}{dx}\)
  3. \(2xy\)
  4. \(x^2\frac{dy}{dx}\)

Product rule.

The radius of a sphere increases at 0.1 cm/s. When \(r = 10\) cm, its volume increases at

  1. \(4\pi\) cm³/s
  2. \(400\pi\) cm³/s
  3. \(\frac{40\pi}{3}\) cm³/s
  4. \(40\pi\) cm³/s

\(\frac{dV}{dt} = 4\pi r^2\frac{dr}{dt} = 4\pi(100)(0.1) = 40\pi\).

The gradient of \(e^y + xy = e\) at the point \((0, 1)\) is

  1. \(-e\)
  2. \(-\frac1e\)
  3. \(e\)
  4. \(0\)

\(e^y y' + y + xy' = 0\): at \((0, 1)\), \(ey' + 1 = 0\).

Find the gradient of the ellipse \(\dfrac{x^2}{16} + \dfrac{y^2}{9} = 1\) at \(\left(2, \dfrac{3\sqrt3}{2}\right)\).

\(\frac{x}{8} + \frac{2y}{9}y' = 0 \Rightarrow y' = -\frac{9x}{16y}\). [1]

\(= -\dfrac{18}{16\cdot\frac{3\sqrt3}{2}} = -\dfrac{18}{24\sqrt3} = -\dfrac{\sqrt3}{4}\). [1]

Find the equation of the normal to \(y^2 - 2xy + 3x^2 = 6\) at \((1, -1)\).

\(2yy' - 2y - 2xy' + 6x = 0 \Rightarrow y' = \dfrac{2y - 6x}{2y - 2x} = \dfrac{y - 3x}{y - x}\). [1]

At \((1, -1)\): \(y' = \frac{-4}{-2} = 2\); normal gradient \(-\frac12\). [1]

\(y + 1 = -\frac12(x - 1)\), i.e. \(y = -\frac12 x - \frac12\). [1]

A spherical balloon is inflated so its surface area increases at 8 cm²/s. Find the rate of increase of the radius when \(r = 5\) cm.

\(S = 4\pi r^2 \Rightarrow \frac{dS}{dr} = 8\pi r\). [1]

\(\frac{dr}{dt} = \dfrac{8}{8\pi r}\). [1]

At \(r = 5\): \(\dfrac{1}{5\pi}\) cm/s \(\approx 0.064\) cm/s. [1]

Summary

  • Differentiate every term w.r.t. \(x\); each \(y\) term gets \(\frac{dy}{dx}\); products need the product rule.
  • Horizontal tangent: numerator of \(\frac{dy}{dx}\) zero; vertical: denominator zero.
  • Related rates: equation in one variable, differentiate, then substitute values.
