Vector basics

A vector \(\underset{\sim}{a} = a_1\underset{\sim}{i} + a_2\underset{\sim}{j} + a_3\underset{\sim}{k}\) has magnitude and direction. \(\overrightarrow{AB} = \underset{\sim}{b} - \underset{\sim}{a}\) (end minus start).

Magnitude and unit vector
\[ |\underset{\sim}{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}, \qquad \hat{\underset{\sim}{a}} = \frac{1}{|\underset{\sim}{a}|}\,\underset{\sim}{a} \]

Two vectors are parallel iff one is a scalar multiple of the other: \(\underset{\sim}{a} = m\underset{\sim}{b}\). Points \(A, B, C\) are collinear iff \(\overrightarrow{AB} = m\overrightarrow{AC}\).

Find a vector of magnitude 6 in the direction of \(\underset{\sim}{a} = 2\underset{\sim}{i} - \underset{\sim}{j} + 2\underset{\sim}{k}\).

Find the unit vector, then multiply by 6.

\(|\underset{\sim}{a}| = \sqrt{4 + 1 + 4} = 3\), so \(\hat{\underset{\sim}{a}} = \frac13(2\underset{\sim}{i} - \underset{\sim}{j} + 2\underset{\sim}{k})\).

\(4\underset{\sim}{i} - 2\underset{\sim}{j} + 4\underset{\sim}{k}\).

Linear dependence

Vectors \(\underset{\sim}{a}, \underset{\sim}{b}, \underset{\sim}{c}\) are linearly dependent if one is a linear combination of the others, i.e. \(\underset{\sim}{c} = m\underset{\sim}{a} + n\underset{\sim}{b}\) has a solution (equivalently, they're coplanar). Otherwise they're linearly independent.

Show that \(\underset{\sim}{a} = \underset{\sim}{i} + 2\underset{\sim}{j} - \underset{\sim}{k}\), \(\underset{\sim}{b} = 2\underset{\sim}{i} - \underset{\sim}{j} + \underset{\sim}{k}\) and \(\underset{\sim}{c} = 4\underset{\sim}{i} + 3\underset{\sim}{j} - \underset{\sim}{k}\) are linearly dependent.

Try \(\underset{\sim}{c} = m\underset{\sim}{a} + n\underset{\sim}{b}\). Solve two component equations, then check the third.

\(i\): \(m + 2n = 4\); \(j\): \(2m - n = 3\). So \(m = 2\), \(n = 1\).

\(k\): \(-m + n = -2 + 1 = -1\) ✓. So \(\underset{\sim}{c} = 2\underset{\sim}{a} + \underset{\sim}{b}\): linearly dependent.

The scalar (dot) product

Dot product
\[ \underset{\sim}{a}\cdot\underset{\sim}{b} = a_1b_1 + a_2b_2 + a_3b_3 = |\underset{\sim}{a}||\underset{\sim}{b}|\cos\theta, \qquad \underset{\sim}{a}\cdot\underset{\sim}{a} = |\underset{\sim}{a}|^2 \]

Non-zero vectors are perpendicular iff \(\underset{\sim}{a}\cdot\underset{\sim}{b} = 0\). The dot product is distributive and commutative.

Find the angle between \(\underset{\sim}{a} = \underset{\sim}{i} + \underset{\sim}{j}\) and \(\underset{\sim}{b} = \underset{\sim}{j} + \underset{\sim}{k}\).

\(\cos\theta = \frac{\underset{\sim}{a}\cdot\underset{\sim}{b}}{|\underset{\sim}{a}||\underset{\sim}{b}|}\).

\(\underset{\sim}{a}\cdot\underset{\sim}{b} = 0 + 1 + 0 = 1\); \(|\underset{\sim}{a}| = |\underset{\sim}{b}| = \sqrt2\).

\(\cos\theta = \frac12\), so \(\theta = \frac\pi3\) (60°).

Find \(m\) so that \(m\underset{\sim}{i} + 2\underset{\sim}{j} - \underset{\sim}{k}\) is perpendicular to \(3\underset{\sim}{i} - \underset{\sim}{j} + 4\underset{\sim}{k}\).

Set the dot product to zero.

\(3m - 2 - 4 = 0\).

\(m = 2\).

Resolutes (projections)

Resolving a in the direction of b
\[ \text{scalar resolute} = \underset{\sim}{a}\cdot\hat{\underset{\sim}{b}}, \qquad \text{vector resolute (parallel)} = (\underset{\sim}{a}\cdot\hat{\underset{\sim}{b}})\,\hat{\underset{\sim}{b}}, \qquad \text{perpendicular part} = \underset{\sim}{a} - (\underset{\sim}{a}\cdot\hat{\underset{\sim}{b}})\,\hat{\underset{\sim}{b}} \]

Let \(\underset{\sim}{a} = 3\underset{\sim}{i} + \underset{\sim}{j} - 2\underset{\sim}{k}\) and \(\underset{\sim}{b} = \underset{\sim}{i} + 2\underset{\sim}{j} + 2\underset{\sim}{k}\). Resolve \(\underset{\sim}{a}\) into parts parallel and perpendicular to \(\underset{\sim}{b}\).

\(|\underset{\sim}{b}| = 3\) so \(\hat{\underset{\sim}{b}} = \frac13\underset{\sim}{b}\). Scalar resolute first, then the vector resolute, then subtract.

\(\underset{\sim}{a}\cdot\hat{\underset{\sim}{b}} = \frac13(3 + 2 - 4) = \frac13\).

Parallel: \(\frac13\cdot\frac13\underset{\sim}{b} = \frac19(\underset{\sim}{i} + 2\underset{\sim}{j} + 2\underset{\sim}{k})\).

Perpendicular: \(\underset{\sim}{a} - \frac19\underset{\sim}{b} = \frac19(26\underset{\sim}{i} + 7\underset{\sim}{j} - 20\underset{\sim}{k})\). Check: dot with \(\underset{\sim}{b}\) is \(\frac19(26 + 14 - 40) = 0\) ✓.

The scalar resolute uses the unit vector \(\hat{\underset{\sim}{b}}\), not \(\underset{\sim}{b}\). Forgetting to divide by \(|\underset{\sim}{b}|\) (or dividing only once in the vector resolute, which needs \(|\underset{\sim}{b}|^2\)) is the classic error.

Exam 1 loves "find the vector resolute of \(\underset{\sim}{a}\) perpendicular to \(\underset{\sim}{b}\)" and "find \(m\) such that... are linearly dependent". Always show the check of the third component.

  1. 5
  2. \(4\underset{\sim}{i} - 2\underset{\sim}{j} - 3\underset{\sim}{k}\)
  3. 9
  4. \(-1\)

\(4 - 2 - 3 = -1\). The dot product is a scalar.

The scalar resolute of \(\underset{\sim}{a} = 2\underset{\sim}{i} + \underset{\sim}{j}\) in the direction of \(\underset{\sim}{b} = 3\underset{\sim}{i} + 4\underset{\sim}{j}\) is

  1. 2
  2. 10
  3. \(\frac{2}{\sqrt5}\)
  4. \(\frac25\)

\(\frac{6 + 4}{5} = 2\).

Which set of vectors is linearly independent?

  1. \(\underset{\sim}{i},\ \underset{\sim}{j},\ \underset{\sim}{i} + \underset{\sim}{j}\)
  2. \(\underset{\sim}{i} + \underset{\sim}{k},\ 2\underset{\sim}{i} + 2\underset{\sim}{k},\ \underset{\sim}{j}\)
  3. \(\underset{\sim}{i} + \underset{\sim}{j},\ \underset{\sim}{j} + \underset{\sim}{k},\ \underset{\sim}{i} + \underset{\sim}{k}\)
  4. \(\underset{\sim}{i} - \underset{\sim}{j},\ \underset{\sim}{j} - \underset{\sim}{k},\ \underset{\sim}{k} - \underset{\sim}{i}\)

D sums to zero; A and B have obvious combinations. For C, \(m(\underset{\sim}{i} + \underset{\sim}{j}) + n(\underset{\sim}{j} + \underset{\sim}{k}) = \underset{\sim}{i} + \underset{\sim}{k}\) needs \(m = 1\), \(n = 1\) and \(m + n = 0\): impossible.

Find the unit vector in the direction of \(\overrightarrow{AB}\), where \(A(1, 2, 3)\) and \(B(3, 1, 5)\).

\(\frac13(2\underset{\sim}{i} - \underset{\sim}{j} + 2\underset{\sim}{k})\). [1]

Find \(p\) such that \(\underset{\sim}{i} + p\underset{\sim}{j} + \underset{\sim}{k}\), \(2\underset{\sim}{i} + \underset{\sim}{j} - \underset{\sim}{k}\) and \(\underset{\sim}{i} + 3\underset{\sim}{j} - 2\underset{\sim}{k}\) are linearly dependent.

Set \(\underset{\sim}{i} + 3\underset{\sim}{j} - 2\underset{\sim}{k} = m(\underset{\sim}{i} + p\underset{\sim}{j} + \underset{\sim}{k}) + n(2\underset{\sim}{i} + \underset{\sim}{j} - \underset{\sim}{k})\). [1]

\(i\): \(m + 2n = 1\); \(k\): \(m - n = -2\) ⇒ \(n = 1\), \(m = -1\). [1]

\(j\): \(-p + 1 = 3 \Rightarrow p = -2\). [1]

Find the vector resolute of \(\underset{\sim}{a} = 4\underset{\sim}{i} - \underset{\sim}{j} + \underset{\sim}{k}\) perpendicular to \(\underset{\sim}{b} = \underset{\sim}{i} + \underset{\sim}{j}\).

\(\underset{\sim}{a}\cdot\underset{\sim}{b} = 3\), \(|\underset{\sim}{b}|^2 = 2\). [1]

Parallel part \(= \frac32(\underset{\sim}{i} + \underset{\sim}{j})\). [1]

Perpendicular \(= \frac52\underset{\sim}{i} - \frac52\underset{\sim}{j} + \underset{\sim}{k}\). [1]

Summary

  • \(|\underset{\sim}{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}\); \(\hat{\underset{\sim}{a}} = \underset{\sim}{a}/|\underset{\sim}{a}|\); \(\overrightarrow{AB} = \underset{\sim}{b} - \underset{\sim}{a}\).
  • Parallel: scalar multiple. Dependent: one is a combination of the others (check all components).
  • \(\underset{\sim}{a}\cdot\underset{\sim}{b} = |\underset{\sim}{a}||\underset{\sim}{b}|\cos\theta\); zero means perpendicular.
  • Vector resolute \(= \frac{\underset{\sim}{a}\cdot\underset{\sim}{b}}{|\underset{\sim}{b}|^2}\underset{\sim}{b}\); perpendicular part \(= \underset{\sim}{a} -\) that.
