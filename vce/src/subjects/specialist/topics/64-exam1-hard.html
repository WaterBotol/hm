2023 VCAA Exam 1 · Question 2 Open in the exam PDF (p. 4) ↗

Find \(b > 0\) given \(\arg\big((b - i)^3\big) = -\frac{\pi}{2}\)

State average for the whole question: 1.5 / 3 (50%).

Find \(b\)

  • \(\arg(z) = 3\arg(b - i)\)
  • \(\arg(b - i) = -\frac{\pi}{6}\) (since \(-\frac\pi2 < \arg(b - i) < 0\))
  • \(b = \sqrt3\)

\(3\arg(b - i) = -\frac\pi2 \Rightarrow \tan^{-1}\left(\frac1b\right) = \frac\pi6\), so \(b = \sqrt3\).

State average 1.5 / 3 (50%); 37% scored full marks.

Mark distribution: 0: 38% · 1: 14% · 2: 11% · 3: 37%

2023 VCAA Exam 1 · Question 3 Open in the exam PDF (p. 4) ↗

Velocity given as a function of position, \(v = \frac{3x + 2}{2x - 1}\): acceleration at a point, limiting velocity

State average for the whole question: 1.4 / 3 (47%).

Acceleration when \(x = 2\)

  • Uses \(a = v\frac{dv}{dx}\), with \(\frac{dv}{dx} = \frac{-7}{(2x - 1)^2}\)
  • \(a = \frac83\times\left(-\frac79\right) = -\frac{56}{27}\)

\(-\frac{56}{27}\) m/s². Many students found \(\frac{dv}{dx}\) and stopped: that isn’t acceleration.

State average 0.9 / 2 (45%); 35% scored full marks.

Mark distribution: 0: 44% · 1: 21% · 2: 35%

Limiting velocity as x grows

  • \(\frac32\)

\(v \to \frac32\) m/s.

State average 0.5 / 1 (50%); 50% scored full marks.

Mark distribution: 0: 50% · 1: 50%

2023 VCAA Exam 1 · Question 8 Open in the exam PDF (p. 8) ↗

Prove by induction a formula for the \(n\)th derivative of \(xe^{2x}\)

State average for the whole question: 2.1 / 4 (52%).

Induction proof

  • Base case \(n = 1\): \(f^{\prime}(x) = (2x + 1)e^{2x}\) matches
  • Assumes true for \(n = k\)
  • Differentiates the \(n = k\) form: \(\left(2^{k+1}x + (k + 1)2^k\right)e^{2x}\)
  • Concludes true for all n by induction

Differentiate \((2^kx + k2^{k-1})e^{2x}\) to get \(\left(2^{k+1}x + (k + 1)2^k\right)e^{2x}\). Lost marks were usually for a missing conclusion or not using the assumption.

State average 2.1 / 4 (52%); 21% scored full marks.

Mark distribution: 0: 16% · 1: 17% · 2: 39% · 3: 9% · 4: 21%

2023 VCAA Exam 1 · Question 10 Open in the exam PDF (p. 10) ↗

Particle moving on a circle: double-angle rewrite, Cartesian path, a time from distance travelled, when position ⟂ velocity

State average for the whole question: 3.2 / 6 (53%).

Write \(5 - 6\sin^2 t\) as \(\alpha + \beta\cos(2t)\)

  • \(2 + 3\cos(2t)\)

\(\alpha = 2,\ \beta = 3\)

State average 0.8 / 1 (80%); 80% scored full marks.

Mark distribution: 0: 20% · 1: 80%

Show the Cartesian equation of the path

  • \(x - 2 = 3\cos(2t)\), \(y - 1 = 3\sin(2t)\)
  • Squares and adds to get \((x - 2)^2 + (y - 1)^2 = 9\)

Use \(6\sin t\cos t = 3\sin(2t)\), then \(\cos^2 + \sin^2 = 1\).

State average 1.4 / 2 (70%); 69% scored full marks.

Mark distribution: 0: 25% · 1: 6% · 2: 69%

Find a from the distance travelled

  • \(a = \frac{\pi}{8}\)

Speed is constant at 6, so \(6a = \frac{3\pi}{4}\), \(a = \frac\pi8\).

State average 0.4 / 1 (40%); 36% scored full marks.

Mark distribution: 0: 64% · 1: 36%

All \(t\) with \(\underset{\sim}{r}(t) \perp \dot{\underset{\sim}{r}}(t)\)

  • \(\underset{\sim}{r}\cdot\dot{\underset{\sim}{r}} = 6\cos(2t) - 12\sin(2t) = 0\)
  • \(t = \frac12\tan^{-1}\left(\frac12\right) + \frac{k\pi}{2},\ k = 0, 1, 2, \dots\)

\(\tan(2t) = \frac12\). Many students gave only one solution or forgot \(t \ge 0\).

State average 0.6 / 2 (30%); 7% scored full marks.

Mark distribution: 0: 44% · 1: 49% · 2: 7%

2024 VCAA Exam 1 · Question 9 Open in the exam PDF (p. 12) ↗

Car with \(v^2\) given in terms of position via \(\arccos\): speed camera trigger, acceleration at \(x = 12\)

State average for the whole question: 1.9 / 4 (48%).

Is the device activated?

  • At \(x = 0\): \(v^2 = 1600 + 336 = 1936\), \(v = 44 \ge 44\), so yes

\(v = 44\) km/h, exactly 10% over 40, so it is activated. Many assumed any speed above 40 triggers it.

State average 0.3 / 1 (30%); 32% scored full marks.

Mark distribution: 0: 68% · 1: 32%

Acceleration at x = 12

  • \(a = \frac{d}{dx}\left(\frac12v^2\right)\)
  • \(= -\frac{336}{\pi\sqrt{400 - x^2}}\)
  • \(-\frac{21}{\pi}\)

\(a = -\frac{336}{16\pi} = -\frac{21}{\pi}\) km/h². Don’t forget the \(\frac12\).

State average 1.6 / 3 (53%); 35% scored full marks.

Mark distribution: 0: 29% · 1: 19% · 2: 17% · 3: 35%

2024 VCAA Exam 1 · Question 10 Open in the exam PDF (p. 13) ↗

Shortest distance between two skew lines with a parameter m

State average for the whole question: 0.8 / 3 (27%).

Values of m

  • Common normal \(\underset{\sim}{d}_1\times\underset{\sim}{d}_2 = \underset{\sim}{i} - 3\underset{\sim}{j} + 5\underset{\sim}{k}\)
  • Distance \(\frac{|5m + 4|}{\sqrt{35}} = \frac{14}{\sqrt{35}}\)
  • \(m = 2\) or \(m = -\frac{18}{5}\)

Project the vector between points on each line onto the common normal. \(m = 2,\ -\frac{18}{5}\). The state averaged 0.8/3.

State average 0.8 / 3 (27%); 14% scored full marks.

Mark distribution: 0: 59% · 1: 14% · 2: 13% · 3: 14%

2025 VCAA Exam 1 · Question 4 Open in the exam PDF (p. 5) ↗

Waiting-time pdf: show the mean is 1/2 using partial fractions; probability for a sample mean of 25

State average for the whole question: 2.7 / 5 (54%).

Show \(E(T) = \frac12\)

  • \(E(T) = \frac{3}{2\log_e 2}\int_0^1\frac{t}{(t + 1)(2 - t)}dt\)
  • Partial fractions: \(\frac{t}{(t + 1)(2 - t)} = -\frac{1}{3(t + 1)} + \frac{2}{3(2 - t)}\)
  • Integral \(= \frac13\log_e 2\), so \(E(T) = \frac12\)

Partial fractions are the key step. Many lost a mark by not showing enough working for a “show that”.

State average 1.5 / 3 (50%); 37% scored full marks.

Mark distribution: 0: 32% · 1: 23% · 2: 9% · 3: 37%

\(\Pr(0.44 < \bar T < 0.5)\)

  • \(\operatorname{sd}(\bar T) = \frac{0.3}{5} = 0.06\)
  • \(\Pr(-1 < Z < 0) = 0.34\)

\(0.84 - 0.5 = 0.34\).

State average 1.2 / 2 (60%); 49% scored full marks.

Mark distribution: 0: 34% · 1: 17% · 2: 49%

2025 VCAA Exam 1 · Question 5 Open in the exam PDF (p. 6) ↗

Two particles collide at t = 1: find c, then a from perpendicular velocities, then a and b from equal acceleration magnitudes

State average for the whole question: 2.1 / 4 (52%).

Show c = −4

  • Equates \(\underset{\sim}{j}\) components at \(t = 1\): \(-1 = 3 + c\)

\(-1 = 2 + c + 1\), so \(c = -4\).

State average 0.9 / 1 (90%); 94% scored full marks.

Mark distribution: 0: 6% · 1: 94%

Two possible values of a

  • From the \(\underset{\sim}{i}\) components, \(b = a - 1\); velocities \((3 + 2a)\underset{\sim}{i}\) and \((b + 2)\underset{\sim}{i} + \underset{\sim}{j}\)
  • Dot product zero: \((3 + 2a)(a + 1) = 0\), so \(a = -\frac32\) or \(a = -1\)

\(a = -1\) or \(a = -\frac32\).

State average 1 / 2 (50%); 30% scored full marks.

Mark distribution: 0: 33% · 1: 37% · 2: 30%

Values of a and b

  • \(|6 + 2a| = 4\) combined with part b: \(a = -1,\ b = -2\)

\(a = -1\), \(b = -2\). Listing extra pairs (e.g. \(a = -5\)) lost the mark.

State average 0.2 / 1 (20%); 25% scored full marks.

Mark distribution: 0: 75% · 1: 25%

2025 VCAA Exam 1 · Question 9 Open in the exam PDF (p. 10) ↗

Rational function with a removable discontinuity: rewrite as \(-x - 1 + \frac{1}{x + 1}\), make a hybrid continuous, sketch with a hole

State average for the whole question: 2.7 / 6 (45%).

Show \(f(x) = -x - 1 + \frac{1}{x + 1}\)

  • Factorises: \(\frac{x(x + 2)(x - 1)}{-(x - 1)(x + 1)} = -\frac{x(x + 2)}{x + 1}\)
  • Rewrites \(-\frac{(x + 1)^2 - 1}{x + 1}\) to get the form

Cancel the (x − 1) factor first, then divide. Check every line actually leads to the given form.

State average 1.2 / 2 (60%); 45% scored full marks.

Mark distribution: 0: 22% · 1: 33% · 2: 45%

k for continuity at x = 1

  • \(k = -\frac32\)

\(k = -1 - 1 + \frac12 = -\frac32\).

State average 0.5 / 1 (50%); 46% scored full marks.

Mark distribution: 0: 54% · 1: 46%

Sketch, labelling asymptotes

  • Asymptotes \(x = -1\) and \(y = -x - 1\) labelled
  • Correct branches through \((0, 0)\) and \((-2, 0)\)
  • Open circle at \(\left(1, -\frac32\right)\)

No asymptote at \(x = 1\): it’s a hole. Many drew one there or forgot the open circle.

State average 1 / 3 (33%); 16% scored full marks.

Mark distribution: 0: 50% · 1: 16% · 2: 18% · 3: 16%
