Linear functions of one variable

aX + b
\[ E(aX + b) = aE(X) + b, \qquad \operatorname{Var}(aX + b) = a^2\operatorname{Var}(X), \qquad \operatorname{sd}(aX + b) = |a|\operatorname{sd}(X) \]

Adding a constant shifts the mean but doesn't change the spread.

Combinations of independent variables

Independent X and Y
\[ E(aX \pm bY) = aE(X) \pm bE(Y), \qquad \operatorname{Var}(aX \pm bY) = a^2\operatorname{Var}(X) + b^2\operatorname{Var}(Y) \]

Variances always add, even for a difference. The mean result holds without independence; the variance result needs it.

\(2X\) (one item doubled) vs \(X_1 + X_2\) (two independent items): same mean \(2\mu\), but \(\operatorname{Var}(2X) = 4\sigma^2\) while \(\operatorname{Var}(X_1 + X_2) = 2\sigma^2\). Independent items partly cancel each other's variation.

If \(X\) and \(Y\) are independent and normally distributed, then \(aX + bY + c\) is also normal. So find its mean and variance, then use the normal distribution.

Apples have mass \(A \sim N(150, 10^2)\) g, independently. A bag holds 6 apples and the bag itself has mass 20 g (fixed). Find the probability the bag weighs more than 950 g.

Total \(T = A_1 + \dots + A_6 + 20\): six independent apples, not \(6A\).

\(E(T) = 6(150) + 20 = 920\); \(\operatorname{Var}(T) = 6(100) = 600\).

\(T \sim N(920, 600)\), sd \(= \sqrt{600} \approx 24.49\).

\(\Pr(T > 950) \approx 0.1103\) (CAS: normCdf(950, ∞, 920, √600)).

Times for runner A are \(N(62, 2^2)\) s and for runner B are \(N(60, 1.5^2)\) s, independently. Find the probability that A beats B (has a smaller time).

Let \(D = A - B\); A beats B when \(D < 0\). Variances add.

\(E(D) = 2\), \(\operatorname{Var}(D) = 4 + 2.25 = 6.25\), so \(D \sim N(2, 2.5^2)\).

\(\Pr(D < 0) = \Pr(Z < -0.8) \approx 0.2119\).

\(\operatorname{Var}(X - Y) \ne \operatorname{Var}(X) - \operatorname{Var}(Y)\). And don't add standard deviations: add variances, then square-root.

Exam 2 MC frequently tests \(2X\) vs \(X_1 + X_2\) and \(\operatorname{Var}(X - Y)\). In extended questions, define the combination (e.g. \(T = X_1 + X_2 + X_3\)) before computing, and state the distribution with both parameters.

  2. 16

\((-2)^2\times4 = 16\); the 3 doesn't affect variance.

  4. 7

\(\operatorname{Var} = 9 + 16 = 25\), sd 5.

  1. \(-6\sigma^2\)
  2. 0
  3. \(6\sigma^2\)
  4. \(-2\sigma^2\)

\(3\sigma^2 - 9\sigma^2 = -6\sigma^2\).

A test score \(X\) has mean 60 and sd 8. Scores are scaled by \(Y = 1.5X - 10\). Find the mean and sd of \(Y\).

\(E(Y) = 1.5(60) - 10 = 80\). [1]

\(\operatorname{sd}(Y) = 1.5\times8 = 12\). [1]

Bolts have length \(N(50, 0.2^2)\) mm and nuts add \(N(8, 0.1^2)\) mm, independently. An assembly is one bolt and two nuts. Find \(\Pr(\text{assembly} > 66.5)\).

\(L = B + N_1 + N_2\): \(E(L) = 66\). [1]

Summary

  • \(E(aX + b) = aE(X) + b\); \(\operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)\).
  • Independent: \(\operatorname{Var}(aX \pm bY) = a^2\operatorname{Var}(X) + b^2\operatorname{Var}(Y)\), always plus.
  • \(\operatorname{Var}(X_1 + \dots + X_n) = n\sigma^2\), but \(\operatorname{Var}(nX) = n^2\sigma^2\).
  • Combinations of independent normals are normal.
