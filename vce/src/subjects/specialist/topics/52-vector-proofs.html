The toolkit

Translate geometry into vectors:

  • Midpoint \(M\) of \(AB\): \(\underset{\sim}{m} = \frac12(\underset{\sim}{a} + \underset{\sim}{b})\). Point dividing \(AB\) in ratio \(m:n\): \(\frac{n\underset{\sim}{a} + m\underset{\sim}{b}}{m + n}\).
  • Parallel / equal length: \(\overrightarrow{PQ} = k\overrightarrow{RS}\) (\(k = 1\) means equal and parallel).
  • Perpendicular: dot product zero. Equal lengths: \(|\underset{\sim}{u}|^2 = \underset{\sim}{u}\cdot\underset{\sim}{u}\).

\(OABC\) is any quadrilateral; \(P, Q, R, S\) are the midpoints of \(OA, AB, BC, CO\). Prove \(PQRS\) is a parallelogram.

Use position vectors from \(O\): \(\underset{\sim}{a}, \underset{\sim}{b}, \underset{\sim}{c}\). Show \(\overrightarrow{PQ} = \overrightarrow{SR}\).

\(\underset{\sim}{p} = \frac12\underset{\sim}{a}\), \(\underset{\sim}{q} = \frac12(\underset{\sim}{a} + \underset{\sim}{b})\), so \(\overrightarrow{PQ} = \frac12\underset{\sim}{b}\).

\(\underset{\sim}{s} = \frac12\underset{\sim}{c}\), \(\underset{\sim}{r} = \frac12(\underset{\sim}{b} + \underset{\sim}{c})\), so \(\overrightarrow{SR} = \frac12\underset{\sim}{b}\).

\(\overrightarrow{PQ} = \overrightarrow{SR}\): one pair of opposite sides is equal and parallel, so \(PQRS\) is a parallelogram. \(\blacksquare\)

\(OABC\) is a rhombus with \(\overrightarrow{OA} = \underset{\sim}{a}\), \(\overrightarrow{OC} = \underset{\sim}{c}\). Prove its diagonals are perpendicular.

Diagonals \(\overrightarrow{OB} = \underset{\sim}{a} + \underset{\sim}{c}\) and \(\overrightarrow{CA} = \underset{\sim}{a} - \underset{\sim}{c}\). A rhombus has \(|\underset{\sim}{a}| = |\underset{\sim}{c}|\).

\((\underset{\sim}{a} + \underset{\sim}{c})\cdot(\underset{\sim}{a} - \underset{\sim}{c}) = \underset{\sim}{a}\cdot\underset{\sim}{a} - \underset{\sim}{c}\cdot\underset{\sim}{c} = |\underset{\sim}{a}|^2 - |\underset{\sim}{c}|^2\).

\(= 0\) since \(|\underset{\sim}{a}| = |\underset{\sim}{c}|\). Non-zero vectors with zero dot product are perpendicular. \(\blacksquare\)

\(AB\) is a diameter of a circle with centre \(O\), and \(P\) is any other point on the circle. Prove \(\angle APB = 90°\).

From \(O\): \(\overrightarrow{OA} = \underset{\sim}{a}\), \(\overrightarrow{OB} = -\underset{\sim}{a}\), \(\overrightarrow{OP} = \underset{\sim}{p}\), with \(|\underset{\sim}{p}| = |\underset{\sim}{a}| = r\).

\(\overrightarrow{PA} = \underset{\sim}{a} - \underset{\sim}{p}\), \(\overrightarrow{PB} = -\underset{\sim}{a} - \underset{\sim}{p}\).

\(\overrightarrow{PA}\cdot\overrightarrow{PB} = -(\underset{\sim}{a} - \underset{\sim}{p})\cdot(\underset{\sim}{a} + \underset{\sim}{p}) = -(|\underset{\sim}{a}|^2 - |\underset{\sim}{p}|^2)\).

\(= -(r^2 - r^2) = 0\), so \(PA \perp PB\). \(\blacksquare\)

In triangle \(OAB\), \(M\) is the midpoint of \(AB\). Show that the point \(G\) two-thirds of the way from \(O\) to \(M\) is \(\frac13(\underset{\sim}{a} + \underset{\sim}{b})\), and explain why all three medians pass through \(G\).

Compute \(G\) on one median; the result is symmetric in all three vertices (with \(O\) at the origin), so it lies on every median.

\(\underset{\sim}{g} = \frac23\underset{\sim}{m} = \frac23\cdot\frac12(\underset{\sim}{a} + \underset{\sim}{b}) = \frac13(\underset{\sim}{a} + \underset{\sim}{b})\).

In general, with an arbitrary origin, this is \(\frac13(\underset{\sim}{o} + \underset{\sim}{a} + \underset{\sim}{b})\), which doesn't depend on which vertex we started from.

The same point lies \(\frac23\) along each median, so the medians are concurrent at the centroid. \(\blacksquare\)

A proof needs a conclusion sentence linking the vector fact back to the geometry ("so \(PQ\) is parallel and equal to \(SR\)..."). Also state \(|\underset{\sim}{a}| = |\underset{\sim}{c}|\) or similar facts as given properties: don't assume what you're proving.

These typically appear as scaffolded Exam 1 parts: express a vector in terms of \(\underset{\sim}{a}\) and \(\underset{\sim}{b}\), then "hence prove". Use earlier parts even if you couldn't do them.

Practice

\(P\) divides \(AB\) in the ratio \(1:2\). Then \(\underset{\sim}{p} =\)

  1. \(\frac13\underset{\sim}{a} + \frac23\underset{\sim}{b}\)
  2. \(\frac23\underset{\sim}{a} + \frac13\underset{\sim}{b}\)
  3. \(\frac12(\underset{\sim}{a} + \underset{\sim}{b})\)
  4. \(\underset{\sim}{a} + \frac12\underset{\sim}{b}\)

\(\underset{\sim}{p} = \underset{\sim}{a} + \frac13(\underset{\sim}{b} - \underset{\sim}{a})\), closer to \(A\).

\(OABC\) is a parallelogram with \(\overrightarrow{OA} = \underset{\sim}{a}\), \(\overrightarrow{OC} = \underset{\sim}{c}\). Then \(\overrightarrow{AC} =\)

  1. \(\underset{\sim}{a} + \underset{\sim}{c}\)
  2. \(\underset{\sim}{a} - \underset{\sim}{c}\)
  3. \(\underset{\sim}{c} - \underset{\sim}{a}\)
  4. \(2\underset{\sim}{c}\)

End minus start.

For a parallelogram spanned by \(\underset{\sim}{a}\) and \(\underset{\sim}{c}\), the diagonals have equal length exactly when

  1. \(\underset{\sim}{a}\cdot\underset{\sim}{c} = 0\)
  2. \(|\underset{\sim}{a}| = |\underset{\sim}{c}|\)
  3. \(\underset{\sim}{a} = \underset{\sim}{c}\)
  4. never

\(|\underset{\sim}{a} + \underset{\sim}{c}|^2 - |\underset{\sim}{a} - \underset{\sim}{c}|^2 = 4\underset{\sim}{a}\cdot\underset{\sim}{c}\): equal iff it's a rectangle.

Prove that the diagonals of a parallelogram \(OABC\) bisect each other.

\(\underset{\sim}{b} = \underset{\sim}{a} + \underset{\sim}{c}\); midpoint of \(OB\) is \(\frac12(\underset{\sim}{a} + \underset{\sim}{c})\). [1]

Midpoint of \(AC\) is \(\frac12(\underset{\sim}{a} + \underset{\sim}{c})\). [1]

Same point, so each diagonal passes through the other's midpoint. [1]

In triangle \(OAB\), \(P\) and \(Q\) are the midpoints of \(OA\) and \(OB\). Prove \(PQ\) is parallel to \(AB\) and half its length.

\(\underset{\sim}{p} = \frac12\underset{\sim}{a}\), \(\underset{\sim}{q} = \frac12\underset{\sim}{b}\). [1]

\(\overrightarrow{PQ} = \frac12(\underset{\sim}{b} - \underset{\sim}{a})\). [1]

\(\overrightarrow{AB} = \underset{\sim}{b} - \underset{\sim}{a}\), so \(\overrightarrow{PQ} = \frac12\overrightarrow{AB}\). [1]

Scalar multiple ⇒ parallel, and \(|PQ| = \frac12|AB|\). \(\blacksquare\) [1]

Summary

  • Midpoint \(\frac12(\underset{\sim}{a} + \underset{\sim}{b})\); ratio \(m:n\) gives \(\frac{n\underset{\sim}{a} + m\underset{\sim}{b}}{m + n}\).
  • Parallel: scalar multiple. Perpendicular: dot = 0. Length: \(|\underset{\sim}{u}|^2 = \underset{\sim}{u}\cdot\underset{\sim}{u}\).
  • \((\underset{\sim}{a} + \underset{\sim}{c})\cdot(\underset{\sim}{a} - \underset{\sim}{c}) = |\underset{\sim}{a}|^2 - |\underset{\sim}{c}|^2\) does rhombus and semicircle proofs.
  • Finish with a geometric conclusion sentence.
