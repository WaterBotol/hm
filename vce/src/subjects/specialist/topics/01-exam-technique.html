Command words in Specialist

PhraseWhat it means
Find / determineGet the answer; show working for anything worth more than 1 mark.
Show thatThe answer is given, so every step must be visible. Start from the left side (or a known fact), not from the answer.
ProveA complete logical argument: state what you assume, justify each step, and finish with a conclusion (\(\blacksquare\) or "as required").
HenceYou must use the previous part.
Hence, or otherwiseThe previous part is the intended route, but any valid method scores.
Write down a definite integralTerminals, integrand and \(dx\) (or \(dt\)) required. You don't evaluate it unless asked.
ExactSurds, \(\pi\), \(e\), logs, fractions. No decimals.
Sketch / plot on an Argand diagramLabel key points, asymptotes, intercepts, and use open/closed circles for boundaries (dashed lines for excluded boundaries of regions).

Writing proofs that score

  • Induction: show the base case explicitly, write "assume true for \(n = k\)", show the \(n = k + 1\) case using the assumption (say where you use it), and conclude for all \(n \in \mathbb{N}\).
  • Contradiction: say "suppose, for contradiction, that...", reach a clear contradiction, then state the result.
  • Counterexample: one specific example, checked explicitly. "For example \(n = 3\)" plus the calculation.
  • Converse / contrapositive: write out the statement you are proving before proving it.

Notation that loses marks

  • Vectors need a tilde (\(\underset{\sim}{a}\)) or arrow in handwriting. \(\underset{\sim}{a}\cdot\underset{\sim}{b}\) is a scalar; \(\underset{\sim}{a}\times\underset{\sim}{b}\) is a vector.
  • Integrals need \(dx\) and brackets: \(\int_0^1(x^2 + 1)\,dx\).
  • Complex numbers: \(\operatorname{Arg}(z) \in (-\pi, \pi]\); polar form \(r\operatorname{cis}\theta\) with \(r > 0\).
  • Statistics: hypotheses use \(\mu\), not \(\bar x\). Define random variables.
  • Don't round intermediate values. Round the final answer to the requested accuracy.

Exam 1 (tech-free) habits

  • Integration techniques must be automatic: substitution, partial fractions, by parts, \(\sin^2\)/\(\cos^2\) identities, inverse-trig forms.
  • De Moivre and roots of complex numbers: draw the roots on an Argand diagram to check spacing \(\frac{2\pi}{n}\).
  • Simplify fully and rationalise only if needed. Check your answer is in the requested form.

Exam 2 (CAS) habits

  • Define functions and vectors on CAS. Use deSolve, crossP, dotP, norm, invNorm, normCdf, but always write the set-up in Section B.
  • For "write down a definite integral" parts, copy the integral you typed, in proper notation.
  • MCQ: eliminate options fast. Many are designed around a single common error (wrong sign, \(\sigma\) vs \(\sigma^2\), \(2X\) vs \(X_1 + X_2\)).

Errors examiners' reports mention every year

  • Induction proofs that never use the inductive hypothesis, or skip the conclusion.
  • Missing \(+c\), or using one constant before both sides are integrated in separation of variables.
  • \(\operatorname{Arg}\) outside \((-\pi, \pi]\), or forgetting the conjugate root in real polynomials.
  • Forgetting the modulus in \(\int\frac1x dx = \log_e|x|\), then not resolving its sign with the initial condition.
  • Using constant acceleration formulas when \(a\) varies.
  • Collide (same \(t\)) vs paths cross (different parameters).
  • Confidence intervals interpreted as probabilities about \(\mu\), and conclusions not in context.
  • Volumes with \(\pi\int(R - r)^2\) instead of \(\pi\int(R^2 - r^2)\).

Reading time plan (15 minutes)

  1. Skim the whole paper and mark each question easy, medium or hard.
  2. In Exam 2 Section B, read each stem and note which area it tests (vectors, DEs, complex, stats, calculus).
  3. Plan your order, banking easy marks first, but always attempt part (a) of every long question.
  4. Mentally solve the first few MCQs so you start fast.
