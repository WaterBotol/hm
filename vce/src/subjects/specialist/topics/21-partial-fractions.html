Rational functions

A rational function is a quotient of polynomials, \(f(x) = \dfrac{P(x)}{Q(x)}\). It's proper if \(\deg P < \deg Q\), otherwise improper. Partial fractions split a proper rational function into simpler pieces you can graph and integrate.

The forms
\[ \frac{px + q}{(x - a)(x - b)} = \frac{A}{x - a} + \frac{B}{x - b} \] \[ \frac{px^2 + qx + r}{(x - a)^2(x - b)} = \frac{A}{x - a} + \frac{B}{(x - a)^2} + \frac{C}{x - b} \] \[ \frac{px^2 + qx + r}{(x - a)(x^2 + c)} = \frac{A}{x - a} + \frac{Bx + C}{x^2 + c} \quad (c > 0,\ \text{irreducible}) \]

Each factor gets a numerator one degree lower than itself: linear factors get constants, irreducible quadratics get \(Bx + C\). A repeated factor \((x - a)^2\) needs both \(\frac{A}{x - a}\) and \(\frac{B}{(x - a)^2}\).

Distinct linear factors

Express \(\dfrac{5x + 1}{(x - 1)(x + 2)}\) in partial fractions.

Multiply both sides by the denominator to get \(5x + 1 = A(x + 2) + B(x - 1)\). Substituting each root kills one term at a time. (Covering up the factor and substituting its root gives the same thing faster.)

\(x = 1\): \(6 = 3A \Rightarrow A = 2\). \(x = -2\): \(-9 = -3B \Rightarrow B = 3\).

\(\dfrac{5x + 1}{(x - 1)(x + 2)} = \dfrac{2}{x - 1} + \dfrac{3}{x + 2}\). Check at \(x = 0\): LHS \(= -\frac12\), RHS \(= -2 + \frac32 = -\frac12\). ✓

Repeated linear factors

Express \(\dfrac{x + 5}{(x + 1)^2(x - 1)}\) in partial fractions.

Set up three terms. Substituting the roots finds two constants; compare coefficients (or substitute another value) for the third.

\(x = 1\): \(6 = 4C \Rightarrow C = \frac32\). \(x = -1\): \(4 = -2B \Rightarrow B = -2\).

\(x^2\) coefficients: \(0 = A + C \Rightarrow A = -\frac32\).

\(\dfrac{x + 5}{(x + 1)^2(x - 1)} = -\dfrac{3}{2(x + 1)} - \dfrac{2}{(x + 1)^2} + \dfrac{3}{2(x - 1)}\).

Irreducible quadratic factors

Express \(\dfrac{3x^2 + 2}{(x - 2)(x^2 + 1)}\) in partial fractions.

\(x^2 + 1\) has no real roots, so it takes a numerator \(Bx + C\). Find \(A\) by substituting \(x = 2\), then compare coefficients.

\(x = 2\): \(14 = 5A \Rightarrow A = \frac{14}{5}\).

\(x^2\): \(3 = A + B \Rightarrow B = \frac15\). Constant: \(2 = A - 2C \Rightarrow C = \frac{2}{5}\).

\(\dfrac{14}{5(x - 2)} + \dfrac{x + 2}{5(x^2 + 1)}\).

Improper fractions: divide first

Express \(\dfrac{x^3 + 2}{x^2 - 1}\) as a polynomial plus partial fractions.

The numerator's degree (3) is at least the denominator's (2), so divide first. The remainder over the denominator is proper and can then be split.

\(x^3 + 2 = x(x^2 - 1) + (x + 2)\), so \(\dfrac{x^3 + 2}{x^2 - 1} = x + \dfrac{x + 2}{(x - 1)(x + 1)}\).

\(x = 1\): \(A = \frac32\). \(x = -1\): \(B = -\frac12\).

\(\dfrac{x^3 + 2}{x^2 - 1} = x + \dfrac{3}{2(x - 1)} - \dfrac{1}{2(x + 1)}\). The polynomial part \(y = x\) is the oblique asymptote.

Forgetting to divide an improper fraction gives nonsense constants that won't check. Always compare degrees first. Also factorise the denominator fully: \(x^3 - x = x(x - 1)(x + 1)\) needs three terms.

Exam 1 often gives the partial fractions form ("show that … \(= \frac{a}{x - 1} + \dots\)") and then asks you to integrate it, giving logs: \(\int \frac{A}{x - a}dx = A\log_e|x - a| + c\). Exam 2 accepts CAS (expand/partfrac), but show the form you used.

Practice

The correct partial fraction form of \(\dfrac{2x - 1}{x^2(x + 3)}\) is

  1. \(\frac{A}{x^2} + \frac{B}{x + 3}\)
  2. \(\frac{A}{x} + \frac{B}{x^2} + \frac{C}{x + 3}\)
  3. \(\frac{Ax + B}{x^2} + \frac{C}{x + 3}\) only if \(A = 0\)
  4. \(\frac{A}{x} + \frac{B}{x + 3}\)

\(x^2\) is a repeated linear factor: it needs \(\frac Ax\) and \(\frac{B}{x^2}\).

If \(\dfrac{4}{(x - 1)(x + 1)} = \dfrac{A}{x - 1} + \dfrac{B}{x + 1}\), then

  1. \(A = 4, B = -4\)
  2. \(A = 1, B = 1\)
  3. \(A = -2, B = 2\)
  4. \(A = 2, B = -2\)

\(4 = A(x + 1) + B(x - 1)\): \(x = 1\) gives \(A = 2\); \(x = -1\) gives \(B = -2\).

Before finding partial fractions of \(\dfrac{x^2 + 1}{x^2 - 4}\), you must

  1. divide, since the fraction is improper
  2. complete the square in the numerator
  3. use \(\frac{Ax + B}{x^2 - 4}\)
  4. nothing: it's already in partial fractions

Equal degrees: \(\frac{x^2 + 1}{x^2 - 4} = 1 + \frac{5}{x^2 - 4}\), then split \(\frac{5}{(x - 2)(x + 2)}\).

In \(\dfrac{x^2 + x + 1}{x(x^2 + 1)} = \dfrac{A}{x} + \dfrac{Bx + C}{x^2 + 1}\), the value of \(C\) is

  1. 0
  2. \(-1\)
  3. 1
  4. 2

\(x^2 + x + 1 = A(x^2 + 1) + (Bx + C)x\). \(x = 0\): \(A = 1\). \(x^2\): \(1 = A + B \Rightarrow B = 0\). \(x\): \(1 = C\).

Express \(\dfrac{7 - x}{(x + 1)(x - 3)}\) in partial fractions.

\(7 - x = A(x - 3) + B(x + 1)\). \(x = -1\): \(8 = -4A \Rightarrow A = -2\). \(x = 3\): \(4 = 4B \Rightarrow B = 1\). [1]

\(-\dfrac{2}{x + 1} + \dfrac{1}{x - 3}\). [1]

Express \(\dfrac{2x^2 + 3}{x(x - 1)^2}\) in partial fractions.

\(2x^2 + 3 = A(x - 1)^2 + Bx(x - 1) + Cx\). [1]

\(x = 0\): \(A = 3\). \(x = 1\): \(C = 5\). \(x^2\): \(2 = A + B \Rightarrow B = -1\). [1]

\(\dfrac{3}{x} - \dfrac{1}{x - 1} + \dfrac{5}{(x - 1)^2}\). [1]

Express \(\dfrac{2x^3 - x^2 - 2x + 3}{x^2 - x}\) as \(ax + b + \dfrac{c}{x} + \dfrac{d}{x - 1}\).

Divide: \(2x^3 - x^2 - 2x + 3 = (2x + 1)(x^2 - x) + (-x + 3)\). [1]

\(\dfrac{-x + 3}{x(x - 1)}\): \(-x + 3 = c(x - 1) + dx\); \(x = 0\): \(c = -3\); \(x = 1\): \(d = 2\). [1]

\(2x + 1 - \dfrac{3}{x} + \dfrac{2}{x - 1}\). [1]

Summary

  • Improper? Divide first. Then factorise the denominator fully.
  • Linear factor → constant; repeated \((x - a)^2\) → \(\frac{A}{x - a} + \frac{B}{(x - a)^2}\); irreducible quadratic → \(\frac{Bx + C}{x^2 + c}\).
  • Substitute roots, then compare coefficients for the rest; check with an easy \(x\) value.
