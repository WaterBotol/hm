Differentiating and integrating vectors

Componentwise
\[ \underset{\sim}{v}(t) = \dot{\underset{\sim}{r}}(t), \qquad \underset{\sim}{a}(t) = \ddot{\underset{\sim}{r}}(t), \qquad \text{speed} = |\underset{\sim}{v}(t)|, \qquad \text{distance} = \int_{t_1}^{t_2} |\underset{\sim}{v}(t)|\,dt \]

Differentiate or integrate each component. Integrating gives a constant vector.

A particle has \(\underset{\sim}{r}(t) = t^2\underset{\sim}{i} + (4t - t^3)\underset{\sim}{j}\). Find its speed at \(t = 1\) and when its velocity is parallel to \(\underset{\sim}{i}\).

\(\underset{\sim}{v} = 2t\underset{\sim}{i} + (4 - 3t^2)\underset{\sim}{j}\). Parallel to \(\underset{\sim}{i}\) means the \(\underset{\sim}{j}\) component is zero (and \(\underset{\sim}{i}\) component isn't).

\(\underset{\sim}{v}(1) = 2\underset{\sim}{i} + \underset{\sim}{j}\), speed \(= \sqrt5\).

\(4 - 3t^2 = 0 \Rightarrow t = \frac{2}{\sqrt3}\) (for \(t \ge 0\)).

A ball is hit from the origin with velocity \(20\underset{\sim}{i} + 15\underset{\sim}{j}\) m/s and acceleration \(-10\underset{\sim}{j}\) m/s². Find \(\underset{\sim}{r}(t)\), the time of flight and the range.

Integrate twice, using \(\underset{\sim}{v}(0)\) and \(\underset{\sim}{r}(0)\). It lands when the \(\underset{\sim}{j}\) component returns to 0.

\(\underset{\sim}{v} = 20\underset{\sim}{i} + (15 - 10t)\underset{\sim}{j}\); \(\underset{\sim}{r} = 20t\underset{\sim}{i} + (15t - 5t^2)\underset{\sim}{j}\).

\(15t - 5t^2 = 0 \Rightarrow t = 3\) s.

Range \(= 20(3) = 60\) m. (Max height at \(t = 1.5\): 11.25 m.)

Collisions vs crossing paths

Collide: same place at the same time: solve \(\underset{\sim}{r}_A(t) = \underset{\sim}{r}_B(t)\) with one \(t\). Paths cross: same place at possibly different times: solve \(\underset{\sim}{r}_A(s) = \underset{\sim}{r}_B(t)\) with two parameters.

\(\underset{\sim}{r}_A(t) = (t + 1)\underset{\sim}{i} + t^2\underset{\sim}{j}\) and \(\underset{\sim}{r}_B(t) = 2t\underset{\sim}{i} + (3t - 2)\underset{\sim}{j}\), \(t \ge 0\). Do they collide? Do their paths cross?

Collision: equate both components at the same \(t\). Crossing: use \(s\) for A, \(t\) for B.

Same \(t\): \(t + 1 = 2t \Rightarrow t = 1\); then \(j\): \(1\) vs \(1\) ✓. They collide at \((2, 1)\) when \(t = 1\).

Crossing: \(s + 1 = 2t\) and \(s^2 = 3t - 2\). Substituting \(t = \frac{s + 1}{2}\): \(2s^2 - 3s + 1 = 0\), so \(s = 1\) or \(s = \frac12\).

Collide at \((2, 1)\); the paths also cross at \(\left(\frac32, \frac14\right)\) (A at \(s = \frac12\), B at \(t = \frac34\)), but they're there at different times.

Minimum distance and circular motion

Distance between particles: \(D(t) = |\underset{\sim}{r}_A(t) - \underset{\sim}{r}_B(t)|\). Minimise \(D^2\) (easier, same minimiser) with calculus or CAS.

Show that \(\underset{\sim}{r}(t) = 3\cos(2t)\underset{\sim}{i} + 3\sin(2t)\underset{\sim}{j}\) has constant speed, and that its acceleration points to the centre.

Differentiate twice; compare \(\underset{\sim}{a}\) with \(\underset{\sim}{r}\).

\(\underset{\sim}{v} = -6\sin(2t)\underset{\sim}{i} + 6\cos(2t)\underset{\sim}{j}\), so \(|\underset{\sim}{v}| = 6\).

\(\underset{\sim}{a} = -12\cos(2t)\underset{\sim}{i} - 12\sin(2t)\underset{\sim}{j} = -4\underset{\sim}{r}\): opposite to \(\underset{\sim}{r}\), so towards the origin. (Also \(\underset{\sim}{r}\cdot\underset{\sim}{v} = 0\).)

Speed is a scalar \(|\underset{\sim}{v}|\); velocity is a vector. "Distance travelled" along a curve is \(\int|\underset{\sim}{v}|\,dt\) (arc length), not \(|\underset{\sim}{r}(t_2) - \underset{\sim}{r}(t_1)|\).

Exam 2's extended vector-calculus questions nearly always include a collide-vs-cross trap and a "write a definite integral for the distance travelled" part. Define your direction conventions in projectile questions.

Practice

If \(\underset{\sim}{r}(t) = \sin t\,\underset{\sim}{i} + e^{2t}\underset{\sim}{j}\), then \(\underset{\sim}{a}(0) =\)

  1. \(\underset{\sim}{i} + 2\underset{\sim}{j}\)
  2. \(-\underset{\sim}{i} + 4\underset{\sim}{j}\)
  3. \(4\underset{\sim}{j}\)
  4. \(\underset{\sim}{j}\)

\(\ddot{\underset{\sim}{r}} = -\sin t\,\underset{\sim}{i} + 4e^{2t}\underset{\sim}{j}\); at 0: \(4\underset{\sim}{j}\).

The speed of a particle with \(\underset{\sim}{v} = 3\underset{\sim}{i} - 4\underset{\sim}{j} + 12\underset{\sim}{k}\) is

  1. 13
  2. 11
  3. 169
  4. \(\sqrt{11}\)

\(\sqrt{9 + 16 + 144} = 13\).

The distance travelled by \(\underset{\sim}{r}(t) = t^2\underset{\sim}{i} + t^3\underset{\sim}{j}\) for \(0 \le t \le 1\) is given by

  1. \(\sqrt2\)
  2. \(\int_0^1 (2t + 3t^2)\,dt\)
  3. \(\int_0^1\sqrt{t^4 + t^6}\,dt\)
  4. \(\int_0^1 t\sqrt{4 + 9t^2}\,dt\)

\(|\underset{\sim}{v}| = \sqrt{4t^2 + 9t^4} = t\sqrt{4 + 9t^2}\) for \(t \ge 0\). A is the displacement magnitude.

\(\underset{\sim}{r}_A = t\underset{\sim}{i} + t\underset{\sim}{j}\) and \(\underset{\sim}{r}_B = (2 - t)\underset{\sim}{i} + t^2\underset{\sim}{j}\), \(t \ge 0\). Which is true?

  1. they collide at \(t = 1\) and \(t = 2\)
  2. they collide at \((1, 1)\)
  3. their paths never cross
  4. they collide at the origin

\(t = 2 - t \Rightarrow t = 1\); \(j\): \(1 = 1\) ✓. At \(t = 2\), A is at \((2, 2)\) but B is at \((0, 4)\). At \(t = 0\) A is at the origin but B is at \((2, 0)\).

Given \(\underset{\sim}{a}(t) = 6t\underset{\sim}{i} - 2\underset{\sim}{j}\), \(\underset{\sim}{v}(0) = \underset{\sim}{j}\), \(\underset{\sim}{r}(0) = 2\underset{\sim}{i}\), find \(\underset{\sim}{r}(t)\).

\(\underset{\sim}{v} = 3t^2\underset{\sim}{i} + (1 - 2t)\underset{\sim}{j}\). [1]

\(\underset{\sim}{r} = (t^3 + 2)\underset{\sim}{i} + (t - t^2)\underset{\sim}{j}\). [2]

\(\underset{\sim}{r}_A(t) = t\underset{\sim}{i} + (4 - t)\underset{\sim}{j}\) and \(\underset{\sim}{r}_B(t) = 2t\underset{\sim}{i} + 2\underset{\sim}{j}\). Find the minimum distance between them.

\(\underset{\sim}{r}_A - \underset{\sim}{r}_B = -t\underset{\sim}{i} + (2 - t)\underset{\sim}{j}\). [1]

\(D^2 = t^2 + (2 - t)^2 = 2t^2 - 4t + 4\). [1]

Minimum at \(t = 1\): \(D^2 = 2\). [1]

\(D_{\min} = \sqrt2\). [1]

Show that for \(\underset{\sim}{r}(t) = e^t\cos t\,\underset{\sim}{i} + e^t\sin t\,\underset{\sim}{j}\), the speed is \(\sqrt2 e^t\).

\(\underset{\sim}{v} = e^t(\cos t - \sin t)\underset{\sim}{i} + e^t(\sin t + \cos t)\underset{\sim}{j}\). [1]

\(|\underset{\sim}{v}|^2 = e^{2t}\big((\cos t - \sin t)^2 + (\sin t + \cos t)^2\big) = 2e^{2t}\). [1]

Speed \(= \sqrt2 e^t\). [1]

Summary

  • Componentwise calculus: \(\underset{\sim}{v} = \dot{\underset{\sim}{r}}\), \(\underset{\sim}{a} = \ddot{\underset{\sim}{r}}\); integrate with a constant vector.
  • Speed \(|\underset{\sim}{v}|\); distance \(\int|\underset{\sim}{v}|\,dt\).
  • Collide: same \(t\). Paths cross: different parameters.
  • Minimum distance: minimise \(|\underset{\sim}{r}_A - \underset{\sim}{r}_B|^2\).
