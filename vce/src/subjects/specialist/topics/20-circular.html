Reciprocal and inverse circular functions and the angle identities are Units 1 and 2 content, but the Units 3 and 4 calculus (derivatives of inverse circular functions, \(\int\frac{1}{\sqrt{a^2 - x^2}}dx\), \(\int\sin^2 x\,dx\)) uses them constantly, and exams test them directly.

Reciprocal circular functions

Definitions
\[ \sec x = \frac{1}{\cos x} \qquad \operatorname{cosec} x = \frac{1}{\sin x} \qquad \cot x = \frac{1}{\tan x} = \frac{\cos x}{\sin x} \]
  • \(\sec x\): undefined where \(\cos x = 0\) (asymptotes at \(x = \frac\pi2 + k\pi\)); range \((-\infty, -1] \cup [1, \infty)\); period \(2\pi\).
  • \(\operatorname{cosec} x\): asymptotes where \(\sin x = 0\) (\(x = k\pi\)); same range; period \(2\pi\).
  • \(\cot x\): asymptotes at \(x = k\pi\); range \(\mathbb{R}\); period \(\pi\); zeros at \(x = \frac\pi2 + k\pi\).

Sketch \(y = \sec x\) from \(y = \cos x\): wherever \(\cos x = \pm1\), \(\sec x = \pm1\) too (turning points); wherever \(\cos x = 0\), draw an asymptote; the "U" shapes open away from the axis. Same idea for cosec from sin.

Pythagorean identities
\[ \sin^2 x + \cos^2 x = 1 \qquad 1 + \tan^2 x = \sec^2 x \qquad \cot^2 x + 1 = \operatorname{cosec}^2 x \]

Divide the first by \(\cos^2 x\) or \(\sin^2 x\) to get the others.

Inverse circular functions

Each circular function is restricted to a one-to-one domain so it has an inverse.

FunctionDomainRange
\(\sin^{-1} x = \arcsin x\)\([-1, 1]\)\(\left[-\frac\pi2, \frac\pi2\right]\)
\(\cos^{-1} x = \arccos x\)\([-1, 1]\)\([0, \pi]\)
\(\tan^{-1} x = \arctan x\)\(\mathbb{R}\)\(\left(-\frac\pi2, \frac\pi2\right)\) (horizontal asymptotes \(y = \pm\frac\pi2\))

\(\sin^{-1} x\) means arcsin, not \(\frac{1}{\sin x}\) (that's cosec). And \(\sin^{-1}(\sin x) = x\) only when \(x \in [-\frac\pi2, \frac\pi2]\): \(\sin^{-1}(\sin \frac{5\pi}{6}) = \frac\pi6\), not \(\frac{5\pi}{6}\).

Find the maximal domain and the range of \(f(x) = 2\cos^{-1}(3x - 1) + \frac{\pi}{2}\).

Whatever is inside \(\cos^{-1}\) must lie in \([-1, 1]\): that gives the domain. The range of \(\cos^{-1}\) is \([0, \pi]\); then apply the dilation by 2 and the translation up \(\frac\pi2\).

\(-1 \le 3x - 1 \le 1 \Rightarrow 0 \le x \le \frac23\). Domain \(\left[0, \frac23\right]\).

Range: \(2[0, \pi] + \frac\pi2 = \left[\frac\pi2, \frac{5\pi}{2}\right]\).

Find the exact value of \(\cos\!\left(\sin^{-1}\frac{3}{5}\right)\) and of \(\tan\!\left(\cos^{-1}\!\left(-\frac{1}{3}\right)\right)\).

Let the inverse be an angle \(\theta\), draw or use Pythagoras, and use the range to fix the sign. \(\sin^{-1}\) gives an angle in quadrant 1 or 4 (cos positive); \(\cos^{-1}\) of a negative gives quadrant 2.

\(\theta = \sin^{-1}\frac35\): \(\cos\theta = +\sqrt{1 - \frac{9}{25}} = \frac45\).

\(\phi = \cos^{-1}(-\frac13) \in (\frac\pi2, \pi)\): \(\sin\phi = \frac{2\sqrt2}{3}\), so \(\tan\phi = \frac{2\sqrt2/3}{-1/3} = -2\sqrt2\).

Compound and double angle identities

Compound angles
\[ \sin(A \pm B) = \sin A\cos B \pm \cos A\sin B \qquad \cos(A \pm B) = \cos A\cos B \mp \sin A\sin B \] \[ \tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B} \]
Double angles
\[ \sin 2A = 2\sin A\cos A \qquad \cos 2A = \cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A \qquad \tan 2A = \frac{2\tan A}{1 - \tan^2 A} \]

Rearranged for integration: \(\sin^2 A = \frac12(1 - \cos 2A)\) and \(\cos^2 A = \frac12(1 + \cos 2A)\).

Find the exact value of \(\cos\frac{\pi}{12}\).

Write \(\frac{\pi}{12}\) as a difference of standard angles: \(\frac\pi3 - \frac\pi4\).

\(\cos\frac\pi3\cos\frac\pi4 + \sin\frac\pi3\sin\frac\pi4 = \frac12\cdot\frac{\sqrt2}{2} + \frac{\sqrt3}{2}\cdot\frac{\sqrt2}{2}\).

\(= \dfrac{\sqrt2 + \sqrt6}{4}\).

Solve \(\cos 2x = \sin x\) for \(x \in [0, 2\pi]\).

Choose the version of \(\cos 2x\) that matches the other function: \(1 - 2\sin^2 x\) turns it into a quadratic in \(\sin x\).

\(1 - 2\sin^2 x = \sin x \Rightarrow 2\sin^2 x + \sin x - 1 = 0 \Rightarrow (2\sin x - 1)(\sin x + 1) = 0\).

\(\sin x = \frac12\): \(x = \frac\pi6, \frac{5\pi}{6}\). \(\sin x = -1\): \(x = \frac{3\pi}{2}\).

Exam 1 favourites: exact values of \(\sec, \operatorname{cosec}, \cot\) at standard angles; simplifying \(\frac{\sin 2x}{1 + \cos 2x} = \tan x\); proving an identity by working on one side only. In "show that" identity proofs, never manipulate both sides at once.

Practice

The range of \(y = \tan^{-1} x\) is

  1. \(\mathbb{R}\)
  2. \(\left[-\frac\pi2, \frac\pi2\right]\)
  3. \(\left(-\frac\pi2, \frac\pi2\right)\)
  4. \((0, \pi)\)

Open interval: \(\pm\frac\pi2\) are horizontal asymptotes, never reached.

\(\cos^{-1}\!\left(\cos\frac{4\pi}{3}\right)\) equals

  1. \(\frac{4\pi}{3}\)
  2. \(\frac{2\pi}{3}\)
  3. \(-\frac{2\pi}{3}\)
  4. \(\frac{\pi}{3}\)

\(\cos\frac{4\pi}{3} = -\frac12\), and \(\cos^{-1}(-\frac12) = \frac{2\pi}{3}\) (range \([0, \pi]\)).

\(\sec^2 x - \tan^2 x\) simplifies to

  1. 1
  2. \(-1\)
  3. \(\cos 2x\)
  4. \(\sec 2x\)

From \(1 + \tan^2 x = \sec^2 x\).

The maximal domain of \(f(x) = \sin^{-1}\!\left(\frac{x}{2} - 1\right)\) is

  1. \([-1, 1]\)
  2. \([-2, 2]\)
  3. \([2, 6]\)
  4. \([0, 4]\)

\(-1 \le \frac x2 - 1 \le 1 \Rightarrow 0 \le \frac x2 \le 2 \Rightarrow 0 \le x \le 4\).

If \(\tan\theta = 2\) with \(\theta \in \left(\pi, \frac{3\pi}{2}\right)\), then \(\sin 2\theta\) equals

  1. \(-\frac45\)
  2. \(\frac{2}{\sqrt5}\)
  3. \(\frac45\)
  4. \(-\frac{3}{5}\)

\(\sin 2\theta = \frac{2\tan\theta}{1 + \tan^2\theta} = \frac{4}{5}\). Quadrant 3 has both sin and cos negative, so their product is positive.

Given \(\cot x = -\frac{3}{4}\) and \(\frac\pi2 < x < \pi\), find \(\operatorname{cosec} x\) and \(\sec x\).

\(\operatorname{cosec}^2 x = 1 + \frac{9}{16} = \frac{25}{16}\); sin is positive in quadrant 2, so \(\operatorname{cosec} x = \frac54\). [1]

\(\tan x = -\frac43\), \(\sec^2 x = 1 + \frac{16}{9} = \frac{25}{9}\); cos negative, so \(\sec x = -\frac53\). [1]

Show that \(\dfrac{\sin 2x}{1 + \cos 2x} = \tan x\).

LHS \(= \dfrac{2\sin x\cos x}{1 + 2\cos^2 x - 1}\). [1]

\(= \dfrac{2\sin x\cos x}{2\cos^2 x}\). [1]

\(= \dfrac{\sin x}{\cos x} = \tan x\) = RHS. [1]

Find the exact value of \(\sin\!\left(2\tan^{-1}\frac{1}{2}\right)\).

Let \(\theta = \tan^{-1}\frac12\), so \(\tan\theta = \frac12\) with \(\theta\) in quadrant 1. [1]

\(\sin\theta = \frac{1}{\sqrt5},\ \cos\theta = \frac{2}{\sqrt5}\). [1]

\(\sin 2\theta = 2\cdot\frac{1}{\sqrt5}\cdot\frac{2}{\sqrt5} = \frac45\). [1]

Summary

  • \(\sec = \frac1{\cos}\), \(\operatorname{cosec} = \frac1{\sin}\), \(\cot = \frac{\cos}{\sin}\); \(1 + \tan^2 = \sec^2\), \(\cot^2 + 1 = \operatorname{cosec}^2\).
  • arcsin: \([-1,1] \to [-\frac\pi2, \frac\pi2]\); arccos: \([-1,1] \to [0, \pi]\); arctan: \(\mathbb{R} \to (-\frac\pi2, \frac\pi2)\).
  • Compound and double angle formulas; \(\sin^2 A = \frac12(1 - \cos 2A)\), \(\cos^2 A = \frac12(1 + \cos 2A)\).
  • For compositions like \(\cos(\sin^{-1} a)\), use a triangle and the range for the sign.
