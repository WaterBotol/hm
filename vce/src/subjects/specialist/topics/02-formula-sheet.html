Logic, functions and identities

Proof

\[ P \Rightarrow Q \equiv \lnot Q \Rightarrow \lnot P \]

Converse \(Q \Rightarrow P\) is a different statement. Induction: base case, assume \(n = k\), prove \(n = k + 1\). Proof · Induction

Calculus

Derivatives to know

Differentiation

Implicit and parametric

\[ \frac{dy}{dx} = \frac{dy/dt}{dx/dt} \qquad \frac{d^2y}{dx^2} = \frac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{dx/dt} \]

Implicit differentiation

Integrals to know

\[ \int\frac{dx}{\sqrt{a^2 - x^2}} = \sin^{-1}\tfrac xa + c \quad \int\frac{a\,dx}{a^2 + x^2} = \tan^{-1}\tfrac xa + c \]\[ \int\sin^2 x\,dx = \tfrac x2 - \tfrac{\sin 2x}{4} + c \quad \int f'(g(x))g'(x)\,dx = f(g(x)) + c \]
