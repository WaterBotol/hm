dy/dx = f(x) and d²y/dx² = f(x)

Integrate directly (twice for second order), adding a constant each time. Each constant needs a condition.

Solve \(\frac{d^2y}{dx^2} = 6x\) given \(y'(0) = 2\) and \(y(0) = 1\).

Integrate once and use the \(y'\) condition, then again and use the \(y\) condition.

\(y' = 3x^2 + c_1\); \(y'(0) = 2 \Rightarrow c_1 = 2\).

\(y = x^3 + 2x + c_2\); \(y(0) = 1 \Rightarrow c_2 = 1\).

\(y = x^3 + 2x + 1\).

dy/dx = g(y): flip it

Inverting
\[ \frac{dy}{dx} = g(y) \;\Rightarrow\; \frac{dx}{dy} = \frac{1}{g(y)} \;\Rightarrow\; x = \int\frac{1}{g(y)}\,dy \]

Then rearrange to make \(y\) the subject. Watch for equilibrium solutions where \(g(y) = 0\).

A cup of coffee at 90°C cools in a 20°C room according to \(\frac{dT}{dt} = -k(T - 20)\). After 5 minutes it is 60°C. Find \(T\) in terms of \(t\).

Flip to \(\frac{dt}{dT}\), integrate to get a log, then exponentiate. Since \(T > 20\) throughout, the modulus can go.

\(t = -\frac1k\int\frac{dT}{T - 20} = -\frac1k\log_e(T - 20) + c\), so \(T - 20 = Ae^{-kt}\).

\(T(0) = 90 \Rightarrow A = 70\). \(T(5) = 60 \Rightarrow 40 = 70e^{-5k}\), \(k = \frac15\log_e\frac74\).

\(T = 20 + 70e^{-kt}\) with \(k = \frac15\log_e\frac74 \approx 0.112\). As \(t \to \infty\), \(T \to 20\).

Separation of variables

Separable DEs
\[ \frac{dy}{dx} = f(x)\,g(y) \;\Rightarrow\; \int\frac{1}{g(y)}\,dy = \int f(x)\,dx \]

Get all the \(y\)'s with \(dy\) and all the \(x\)'s with \(dx\), integrate both sides, and use one constant.

Solve \(\frac{dy}{dx} = y^2\cos x\) given \(y(0) = \frac12\).

Divide by \(y^2\) and integrate: \(\int y^{-2}dy = \int\cos x\,dx\).

\(-\frac1y = \sin x + c\); \(y(0) = \frac12 \Rightarrow -2 = c\).

\(-\frac1y = \sin x - 2 \Rightarrow y = \dfrac{1}{2 - \sin x}\).

Solve \(\frac{dQ}{dt} = 0.8 - \frac{Q}{25}\), \(Q(0) = 5\) (salt in a 100 L tank). What happens long term?

Rewrite as \(\frac{dQ}{dt} = \frac{20 - Q}{25}\), then flip. Since \(Q < 20\) throughout, \(|20 - Q| = 20 - Q\).

\(t = \int\frac{25}{20 - Q}\,dQ = -25\log_e(20 - Q) + c\).

\(20 - Q = Ae^{-t/25}\); \(Q(0) = 5 \Rightarrow A = 15\).

\(Q = 20 - 15e^{-t/25}\). As \(t \to \infty\), \(Q \to 20\) kg, i.e. a concentration of 0.2 kg/L, matching the inflow. ✓

The logistic equation

Logistic growth
\[ \frac{dP}{dt} = rP\left(1 - \frac{P}{K}\right) \;\Rightarrow\; P(t) = \frac{K}{1 + \left(\frac{K}{P_0} - 1\right)e^{-rt}} \]

\(K\) is the carrying capacity (limiting value). Growth is fastest when \(P = \frac{K}{2}\): that's the point of inflection.

Solve \(\frac{dP}{dt} = \frac{P(1000 - P)}{2000}\), \(P(0) = 100\).

Flip and use partial fractions: \(\frac{2000}{P(1000 - P)} = 2\left(\frac{1}{P} + \frac{1}{1000 - P}\right)\).

\(t = 2\log_e P - 2\log_e(1000 - P) + c = 2\log_e\frac{P}{1000 - P} + c\).

\(\frac{P}{1000 - P} = Ae^{t/2}\); \(P(0) = 100 \Rightarrow A = \frac19\).

\(P = \dfrac{1000}{1 + 9e^{-t/2}}\). Limiting population 1000; fastest growth at \(P = 500\).

Logs and moduli: \(\int\frac{1}{20 - Q}dQ = -\log_e|20 - Q|\), with a minus sign from the chain rule. Use the initial condition to decide the sign inside the modulus before dropping it.

Exam 2 regularly asks to "show that" a given solution satisfies a DE, then uses CAS (deSolve) for harder ones. Always state the limiting value when asked about long-term behaviour, and give an equilibrium as a constant solution.

The solution of \(\frac{dy}{dx} = 3y\), \(y(0) = 2\) is

  1. \(y = 2e^{3x}\)
  2. \(y = 3e^{2x}\)
  3. \(y = e^{3x} + 1\)
  4. \(y = 2e^{x/3}\)

Exponential growth: \(y = y_0e^{kx}\).

Which DE is not separable?

  1. \(\frac{dy}{dx} = xy\)
  2. \(\frac{dy}{dx} = e^{x + y}\)
  3. \(\frac{dy}{dx} = x + y\)
  4. \(\frac{dy}{dx} = \frac{\sin x}{y}\)

\(e^{x+y} = e^xe^y\) separates, but \(x + y\) can't be written as \(f(x)g(y)\).

For \(\frac{dP}{dt} = 0.4P\left(1 - \frac{P}{600}\right)\), \(P(0) = 50\), the population is growing fastest when \(P =\)

  1. 600
  2. 300
  3. 50
  4. 150

Maximum rate at \(P = \frac K2 = 300\).

Given \(\frac{dy}{dx} = \sqrt{y}\), \(y(0) = 0\), which is a valid solution?

  1. only \(y = \frac{x^2}{4}\) for \(x \ge 0\)
  2. only \(y = 0\)
  3. \(y = x^2\)
  4. both \(y = 0\) and \(y = \frac{x^2}{4}\) (\(x \ge 0\))

Separating gives \(2\sqrt y = x\), but dividing by \(\sqrt y\) lost the equilibrium \(y = 0\), which also satisfies the DE and condition.

Solve \(\frac{dy}{dx} = \frac{x}{y}\), \(y(0) = 3\), giving \(y\) explicitly.

\(\int y\,dy = \int x\,dx\): \(\frac{y^2}{2} = \frac{x^2}{2} + c\). [1]

\(y(0) = 3 \Rightarrow y^2 = x^2 + 9\). [1]

\(y = \sqrt{x^2 + 9}\) (positive root since \(y(0) > 0\)). [1]

A body at 80°C is placed in a 15°C room and cools according to Newton's law, reaching 50°C after 10 minutes. How long until it reaches 30°C?

\(T = 15 + 65e^{-kt}\). [1]

\(35 = 65e^{-10k} \Rightarrow k = \frac{1}{10}\log_e\frac{13}{7}\). [1]

\(15 = 65e^{-kt} \Rightarrow t = \frac1k\log_e\frac{13}{3}\). [1]

\(t = \frac{10\log_e(13/3)}{\log_e(13/7)} \approx 23.7\) min. [1]

Solve \(\frac{dy}{dx} = e^{-y}\), \(y(0) = 0\).

\(\frac{dx}{dy} = e^y \Rightarrow x = e^y + c\). [1]

\(y(0) = 0 \Rightarrow c = -1\). [1]

\(y = \log_e(x + 1)\), \(x > -1\). [1]

Summary

  • \(f(x)\): integrate. \(g(y)\): flip to \(\frac{dx}{dy}\). \(f(x)g(y)\): separate.
  • One arbitrary constant per integration; use initial conditions.
  • Logistic: \(P \to K\); fastest growth at \(\frac K2\); partial fractions to solve.
  • Check for lost equilibrium solutions when dividing by \(g(y)\).
